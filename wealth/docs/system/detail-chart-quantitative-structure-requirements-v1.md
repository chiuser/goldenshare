# 股票和指数详情页量化结构需求方案 v1

> 2026-11-09。需求及三项展示决定已确认，量化结构与切周期首屏修复已通过管理员本机页面验收。
>
> 下文记录已验收的图表交付。接入主要指数量化结构数据集时，事件改读该数据集，日线和分钟的量化结构副图继续单独读取识别所用的 MACD（12、26、9）。上证普通日线副图继续用日线接口现算的 MACD。普通页的量化结构悬停只列当根时间和事件。读取、展示与验收以[财势乾坤接入方案](../../../lake_console/docs/design/dagster-major-index-quantitative-structure-onboarding-plan-v1.md#9-财势乾坤接入技术方案)和[接入 LLD](../../../lake_console/docs/design/dagster-major-index-quantitative-structure-onboarding-low-level-design-v1.md#8-财势乾坤接入详细设计)为准。

## 1. 目标与现状

将徐小明顶底识别从普通 MACD 副图移到独立的「量化结构」副图，让两组指标可以各自显示，也可以在同一时间范围内同时查看。

上证指数普通日线的 MACD 由技术指标计算内核生成。本机顶底识别日线使用 DG Silver 指数日线技术因子数据集 `index_factor_pro` 的收盘价与不复权 MACD，分钟线使用现有 Gold 数据。识别接口已经返回实际使用的 DIF、DEA 和 MACD 柱值。旧前端要求这些值逐根等于普通 MACD，才能显示识别结果。已有上证日线验收记录中，2024-09-24 的指数日线技术因子数据集 MACD 柱值为 `20.645`，内核结果为 `20.64484765453068`，说明这个要求会拦住有效结果。 [上证日线验收记录](../pages/index-detail/index-detail-low-level-design-v1.md#sse-daily-kline-step-2-result) · [前端校验](../../src/features/index-detail/xxm/adapter.ts) · [识别来源](../../../src/biz/queries/wealth/market/index_detail_xxm/source.py)

## 2. 本轮范围

| 页面或功能 | 本轮要求 |
| --- | --- |
| 指数详情页 | 已加载图表的标签行始终显示「量化结构」。沿用本机九指数、日线及 30、60、90、120 分钟的识别范围与环境门禁。已开通时可点击开启副图，绘图只覆盖该图表首次加载的 K 线窗口。未开通时标签置灰且不可点击。 |
| 股票详情页 | 在现有日线和分钟图的底部标签行加入默认点灭的「量化结构」标签。标签是占位入口，点击保持页面原样。无提示、无副图、无请求，不占副图名额。 |
| 普通行情和已有副图 | K 线、成交量、MACD、KDJ 继续消费各自现有行情数据。上证普通日线向左拖动时，仍按原有规则加载历史 K 线和已接入的图层。 |
| 徐小明识别与预判 | 复用现有 r4.1 识别接口、来源、版本、完成 K 线规则及事件展示标志。右侧下一根预判仍由技术面页签按现有逻辑驱动，与副图开关独立。 |

本轮交付限于页面标签、显示控制和指数识别图层的绘制。股票识别、量化结构历史续页、后端接口和数据源迁移均在本轮范围之外。 [研究当前交接](../../../docs/product/xxm-research-and-implementation-v0.6.md#xxm-current-handoff) · [现有识别门禁](../../src/features/index-detail/model/indexRecognitionAvailability.ts)

## 3. 标签与布局

| 编号 | 验收口径 |
| --- | --- |
| R1 | 首次进入时，成交量、MACD、KDJ 三项点亮，「量化结构」默认点灭。同一标的切换周期时沿用现有选择规则，换标的或刷新后恢复默认。 |
| R2 | 每个页面同时最多显示三个技术指标副图。K 线主图、主图均线、BOLL、趋势通道和独立底轴均不计入。 |
| R3 | 点击已点亮的指标，收起对应副图并释放名额。少于三栏时，点击未点亮的可用指标，点亮标签并打开副图。 |
| R4 | 已有三栏时，点击任意未点亮的可用指标，提示「最多展示3个技术指标，请取消一个后再打开」，当前标签和副图组合保持原样。普通 MACD 和量化结构各计一栏，二者可同时开启。股票占位标签在满栏和未满时均保持静默。 |
| R5 | 两页的底部「量化结构」标签紧跟 KDJ。指数副图紧跟普通 MACD，标题为「量化结构(12,26,9)」。标题、参数、DIF 和 DEA 两条线、MACD 柱、读数及颜色沿用当前 MACD 样式。现有副图的相对顺序、底轴位置、可见时间范围、缩放和十字线同步沿用已确认的显隐基线。 |
| R6 | 指数量化结构打开时，首批有识别数据的 K 线沿用现有主图悬停位置显示顶底识别摘要。关闭后，主图悬停只显示普通行情及原有独立图层信息。右侧「下一根预判」按原技术面页签逻辑工作。 |

显示上限来自本次明确要求。参数 `(12,26,9)` 沿用现有 MACD 标题和识别数据口径。 [现有副图显隐方案](detail-chart-indicator-panel-visibility-implementation-design-v1.md) · [现有布局和底轴基线](detail-chart-indicator-panel-visibility-low-level-design-v1.md)

## 4. 首批数据与页面状态

- **普通 MACD 与量化结构分别取值。** 普通 MACD 从普通行情接口取值。量化结构日线复用 `GET /api/v1/wealth/market/index-detail/xxm-signals`，分钟线复用 `GET /api/v1/wealth/market/index-detail/minute-xxm-signals`。沿用现有识别请求时机、参数、返回字段及权限。识别结果的前端校验去掉和普通 MACD 数值的比较，日线与分钟线均适用。 [识别请求代码](../../src/features/index-detail/xxm/apiClient.ts)
- **曲线、读数和标记使用同一份识别回包。** `points.dif` 和 `points.dea` 画两条线，`points.hist` 画柱并提供 MACD 读数。显示标记使用 `events` 中 `displayOnChart=true` 的事件，以该根的识别 DIF 定位。标的、周期、版本和已完成 K 线的时间仍须校验，按交易日或分钟完成时间对齐，允许两副图的指标数值不同。 [识别回包字段](../../../src/biz/schemas/wealth/market/index_detail_xxm.py) · [现有事件显示规则](../../../src/biz/services/wealth/market/index_detail_xxm/response_projection.py)
- **首屏指首次加载的 K 线批次。** 请求使用首批实际首尾日期和根数。普通上证日线现行页面请求为 500 根，短页按实返根数。同批数据内缩放或拖动时曲线和标记仍随时间轴移动。向左加载的普通历史页没有量化结构曲线、读数或标记，量化结构不会为该页发续页请求。 [现有日线请求量](../../src/shared/charts/dailyChartRequestLimits.ts) · [识别窗口绑定](../../src/features/index-detail/chart/IndexChartWorkspace.tsx) · [普通日线续页](../../src/features/index-detail/controller/useIndexDailyHistory.ts)
- **识别状态在量化结构副图内处理。** 加载中、暂无数据、数据滞后和加载失败沿用现有状态语义。滞后时只画已返回的有效范围，失败时可重试首批窗口。缺数据的时间留空。行情和其他副图继续正常展示。切换标的、周期或日期时只使用当前请求对应的结果，迟到回包不能串图。 [现有识别状态与重试](../../src/features/index-detail/xxm/useIndexXxmLayer.ts) · [现有状态展示](../../src/features/index-detail/xxm/XxmLayerUi.tsx)

## 5. 请求与验证边界

复用现有首批识别请求及其调度。单纯开关标签、被三栏上限拦截或点击股票占位标签，额外行情和识别请求均为零。手动重试只重发当前失败的首批识别窗口。正常验收使用现有页面首批请求，历史边界验证使用普通日线现有续页。验证中断后重开同一案例，按页面原有请求范围复核。上述约束按请求路径推导，实际次数由浏览器网络记录确认。

| 场景 | 通过条件 |
| --- | --- |
| 默认与上限 | 验证默认三项点亮、量化结构点灭。三栏时点击量化结构提示且组合原样，关闭一栏后可开启。再点击此时关闭的普通指标，同样触发上限提示。 |
| 两套数值同时显示 | 上证日线同时开启普通 MACD 与量化结构。用现有真实 API 响应对照同一天的两组读数，并用已有差异样本覆盖普通 MACD 与识别值不同的情况。两组各自正确，识别标记落在量化结构对应时间和 DIF 位置。 |
| 首批与历史 | 上证日线左拖触发现有续页。确认普通历史 K 线仍可看，量化结构在首批时间范围内可看，历史续页区域留空，网络记录无识别续页请求。 |
| 股票占位 | 验证股票日线和已支持分钟图都显示占位标签。三栏全开和关掉一栏时分别点击，均无提示、无状态或布局变化、无新增请求。 |
| 指数分钟与门禁 | 在现有识别支持的分钟周期验证曲线、标记及底轴同步。切到不支持识别的周期、标的或环境时，标签仍在 KDJ 后，置灰且不可点击，不占栏也不发识别请求，普通副图可用。 |
| 标签位置与悬停 | 两页验证标签紧跟 KDJ，指数两副图同时开启时验证量化结构紧跟普通 MACD。对有识别结果的同一根 K 线开关量化结构，核对悬停摘要显隐、普通行情悬停及右侧预判。 |
| 状态与切换 | 验证识别失败只影响量化结构，重试仍用首批范围。切换标的、周期和日期后，旧结果不能显示到新窗口。开关副图时保留当前浏览范围、缩放和主图指标。 |

自动化用例覆盖上限、占位、不同数值、首批边界和请求隔离，真实页面验收核对接口回包、同时间读数、标记位置和底轴。验收结论在完成后登记。
