## 1. 目标与定位

本模块解决两个连续问题：

1. 先把股票分钟线从独立图表实现迁入现有 `DetailChartWorkspace`，使股票日线、股票分钟线、指数日线、指数分钟线共享同一个四窗格图表引擎。
2. 再由这一个共享引擎统一提供 K 线放大、缩小和自适应默认可视根数。

用户可见收益：

1. 点击“放大”后，可见 K 线根数减少，单根 K 线变宽；纵轴按当前可见行情自动适配，因此价格波动在视觉上更舒展。
2. 点击“缩小”后，可见 K 线根数增加，单根 K 线变窄；纵轴继续按当前可见行情自动适配。
3. 股票与指数、日线与分钟线使用完全一致的缩放规则和按钮位置。

这里的“高度变化”不是把蜡烛图像按固定比例拉伸；价格纵轴必须基于可见数据自动计算。

## 2. 范围与边界

### 2.1 本期覆盖

1. 股票日线、股票分钟线、指数日线、指数分钟线四类 Loaded 图表。
2. K 线主图右下角的放大/缩小按钮。
3. 四个 pane 的统一横轴范围：K 线、MACD、成交量、KDJ 必须同步。
4. 默认可视根数按绘图区宽度自适应。
5. 已拖动到历史区间后的缩放锚点、边界限制和按钮 disabled 状态。
6. 共享组件迁移、组件测试、页面回归和 1600×1200 浏览器视觉验收。

### 2.2 本期不覆盖

1. 不修改任何日线或分钟 API、DTO、查询 SQL、Reader、limit 或 cursor 合同。
2. 不自动加载更早历史，不因缩小触发分页。
3. 不开放鼠标滚轮缩放、触控双指缩放或图表库原生自由缩放。
4. 不增加“重置”“适配全部”“当前根数”或缩放百分比等额外功能。
5. 不改变 K 线、指标、趋势通道、坐标轴、Tooltip、十字线的业务字段和颜色。
6. 不改变页面、左右栏和四窗格的既有尺寸比例。
7. 实施阶段不自行修改正式 Figma；按钮视觉以 page `581:516` 的正式组件、几何和现有 Design Token 为唯一依据。

### 2.3 与相邻模块边界

1. 页面 controller 继续负责请求、缓存、Abort 和周期切换，不管理图表可视范围。
2. feature adapter 继续负责领域字段、单位、文案、Tooltip 和指标选择。
3. `DetailChartWorkspace` 唯一负责图表生命周期、可视范围、横轴同步、拖动、缩放和纵轴自动适配。
4. API 只负责提供足够的有限数据；当前日线请求 300 根、分钟请求 500 根，均高于本期 180 根最大可视数量。

## 3. 已冻结的交互口径

### 3.1 根数范围与步长

| 项目 | 冻结值 |
|---|---:|
| 最少可见根数 | 45 根 |
| 最多可见根数 | 180 根 |
| 每次点击变化 | 15 根 |
| 1600px 标准页面默认 | 120 根 |
| 自适应目标密度 | 约 9.5px/根 |
| 自适应默认范围 | 75～150 根 |

规则：

1. “放大”把目标可见根数减少 15，最低不小于 45。
2. “缩小”把目标可见根数增加 15，最高不大于 180，也不能超过已加载数据量。
3. 可见数据少于 45 根时显示全部数据，两个按钮均 disabled，不能为满足最少 45 根而补造空 K 线。
4. 可见数据介于 45 和默认目标之间时显示全部数据；此时可以放大到 45，但不能继续缩小到不存在的数据。
5. 最后一步遇到非 15 整数边界时直接落到 45 或实际最大根数，不要求显示数量始终是 15 的倍数。

### 3.2 自适应默认值

默认值按 K 线真实绘图区宽度计算，不按浏览器总宽度硬编码：

```text
plotWidth = klineHostWidth - 56px 右侧价格轴
rawCount = plotWidth / 9.5px
steppedCount = rawCount 四舍五入到最接近的 15 根
adaptiveDefault = clamp(steppedCount, 75, 150)
initialVisibleCount = min(adaptiveDefault, loadedPointCount)
```

补充规则：

1. 在当前 1600×1200 详情页布局下，绘图区应计算为约 120 根。
2. 无法取得有效宽度时，稳定回退为 120 根，而不是回退到旧的 90 根。
3. 页面初次进入、切换股票/指数、切换日线/分钟频率时重新计算默认值。
4. 用户已经放大、缩小或拖动后，普通容器 resize 不得把用户视图重置回默认值。
5. MA/BOLL/趋势通道等主图图层切换不得重置可视范围。

### 3.3 缩放锚点

1. 初次展示始终以最新一根 K 线为右边界。
2. 当前视图仍贴近最新一根时，放大/缩小继续固定最新一根，只改变左边界。
3. 用户已拖动到历史区间时，放大/缩小保持当前区间中心不变；到达数据首尾边界时整体平移后再 clamp，不能静默缩短目标范围。
4. 四个 pane 每次接收同一 logical range，不允许某个 pane 独立缩放。

### 3.4 纵轴语义

1. `lightweight-charts` 的价格轴保持 `autoScale=true`。
2. 横轴可见范围变化后，K 线、指标线、柱状图和趋势 primitive 都按当前可见区间参与各自纵轴自动适配。
3. 不直接修改 OHLC/指标值，不对画布做 CSS scale，不维护人工价格倍率。
4. 上证趋势通道 primitive 的 autoscale 继续只使用可见 logical range 内的通道端点。

## 4. 控件规则

1. 控件固定在 K 线主图绘图区右下角，不放在页面工具栏或底部指标栏。
2. 控件位于 56px 右侧价格轴左边，不能盖住轴标签；距离绘图区右边与下边均使用 8px 基线。
3. 两个按钮按“缩小、放大”排列，分别使用 Supericons 中 Phosphor 的 `magnifying-glass-minus` 与 `magnifying-glass-plus`，不得使用纯文本 `−`/`＋` 或近似图标替代。
4. 单个按钮 28×28px，间距 4px；图标容器 16×16px，内部矢量约 13×13px 并居中，颜色继承按钮 `currentColor`。
5. 可点击区域就是按钮视觉边界；使用真实 `button type="button"`。图标 `aria-hidden`，缩小按钮的可访问名称为“缩小K线，增加可见根数”，放大按钮为“放大K线，减少可见根数”。
6. disabled 状态必须同时具备原生 `disabled`、45% 弱化视觉和不可点击行为，不能只改变颜色。
7. 45 根时放大按钮 disabled；达到 `min(180, loadedPointCount)` 时缩小按钮 disabled；少于 45 根时两个按钮均 disabled。
8. 点击按钮不得触发图表横向拖动、页面周期切换、请求刷新或指标切换。

## 5. 状态语义

1. Loaded 且有数据：显示两个按钮。
2. Loaded 但数据少于 45 根：按钮仍可见但均 disabled。
3. Loading、Empty、Error、Forbidden：不渲染可操作缩放按钮。
4. Partial：只要 K 线数据存在就显示按钮；某条指标线缺失不阻塞 K 线缩放。
5. 周期/标的切换：旧数据对应的缩放状态不能串到新数据。

本功能不新增 API 异常码。缩放状态只存在于前端内存，不写本地存储，也不进入 URL。

## 6. 数据充足性结论

当前代码已核验：

| 图表 | 当前请求量 | 本期最大可见量 | 结论 |
|---|---:|---:|---|
| 股票日线 | 300 根 | 180 根 | 足够 |
| 指数日线 | 300 根 | 180 根 | 足够 |
| 股票分钟 | 500 根 | 180 根 | 足够 |
| 指数分钟 | 500 根 | 180 根 | 足够 |

因此本期不修改后端返回量。实际历史不足时按真实数据量降级，不请求第二页，也不填充假数据。

## 7. 验收标准

### 7.1 功能验收

1. 1600px 页面首次显示 120 根；允许因浏览器亚像素取整出现绘制宽度差异，但可见根数必须精确为 120。
2. 连续点击放大依次减少 15 根并停在 45；连续点击缩小依次增加 15 根并停在 `min(180, loadedPointCount)`。
3. 四个 pane 的 logical range 每次完全一致。
4. 放大后单根 K 线变宽，缩小后变窄；纵轴随可见行情自动变化。
5. 拖到历史区间后点击缩放，当前观察中心不跳回最新行情。
6. 切换 MA/BOLL/趋势通道不重置缩放；切换标的或周期重置为新数据的自适应默认值。
7. 点击缩放按钮不会发出任何网络请求。
8. 控件使用正式组件节点 `583:534`/`585:550` 的同源放大镜图标、状态和 28/4/60px 几何，不出现纯文本或近似图标漂移。

### 7.2 回归验收

1. 股票日线、股票分钟、指数日线、指数分钟全部使用共享工作台。
2. 股票分钟独立的 chart create/sync/drag 生命周期代码删除，不保留双实现或兼容分支。
3. 日线 Tooltip、分钟 Tooltip、四窗格 crosshair、拖动、时间轴、MA/BOLL、上证趋势通道行为不变。
4. 页面、左右栏、四窗格、底部指标栏尺寸相对迁移前基线偏差不超过 2px。
5. 新增按钮以外不出现新增换行、裁剪、重叠、溢出或图表位移。
