3. 正式计算继续读必要历史前段，从来源实际起点建立状态，响应窗口仅裁剪显示。不把页面1000根当MACD重算起点或整个算法历史上限。

## 4. 最新r4识别规则及处理顺序

本节是唯一识别目标。代码位置、执行顺序和逐项人工预期见LLD§3、§14。阶段名称使用管理员定义，不意味着本轮新增页面功能或API枚举。

### 4.1 当根判断、色段记录与本轮参照资格

- 仅真实完成K线参与判别，柱色取源hist正负。真实反色才结束旧段，反色根归新段，不计入旧段极值；零中性，不分段、不增有色count、不当反色/锁死点。开头全零不借未来建立方向。
- 历史参照仍需累计收盘和DIF极值及各自日期，二者可以不在同一天。但首次钝化的价格和DIF必须来自正在判断的同一根，不能借较早的价格通过当根门槛。
- 当前逻辑色段中，任一根DIF严格低于某参照谷（顶部严格高于参照峰），这个参照本轮永久不能回用；首次钝化前就已突破也一样。后来DIF恢复不重获资格，不能因改当根取值而删掉突破记忆。
- 仅最近两个已结束同色段：近B、远A，按时间而非DIF强弱确定。新结束段入池成为后续参照；历史单根保留。当前段至少两根真实同色柱，零不凑根，但已够根时可零日首次钝化。
- 首次底部当根收盘须严格低于B价格门槛，再按B后A检查所选参照：当根收盘严格低于其谷价、当根DIF严格高于其谷DIF、且本轮未严格击穿。B本根合格不查A；B本根不合格才查A，A须过自身完整资格及B价门槛，最多两个。不要求B必须已永久失效才可首次选A；§5的“B存在任意钝化价格解就不算A”仅约束下一根预测。顶部镜像，首次当根DIF>0限制保留。
- 首次价/DIF相等不成立；已有状态DIF等于原参照不因严格突破规则取消。前DIF=0不走百分比转折，不新增epsilon、两位取数、四舍五入或小峰过滤。

### 4.2 钝化、结构、回转与锁死

| 本根前的事实 | 当根处理顺序及结果 |
|---|---|
| 尚未钝化 | 按§4.1首次条件；本根首次成立只报钝化，不在同根追加1%结构 |
| 已有钝化 | 先核原参照严格突破；未破时保持原参照，价在历史价两侧均可，不重复首次价格资格。再按相邻实际DIF反向达到1%确认结构，否则保持钝化 |
| 已有近B钝化、仍同色或零 | B严格突破时取消前用当根完整资格查A；A未被本轮突破且合格，当根B→A保持钝化，不另报消失/新钝化。A失败才消失，不回切B、不看第三个 |
| 已有未锁死结构 | 原参照严格突破优先，直接从结构消失，不经中间钝化、不救援远参照；未破时相邻DIF同向回转达到1%，顶底统一直接退回钝化，不复查价格、不进入等待；不足1%保持结构 |
| 第一次真实反色 | 先确认旧结构/钝化的原参照未失效。结构仍有效，或该根以独立翻色途径确认结构，则当根收盘为锁死点。已消失结构不因翻色复活；不能先清空新段状态再误判旧结构消失 |
| 已锁死结构 | 历史结构永久保留，后续价格、DIF和新同向信号不追溯撤销它。新色段与已结束历史段进入新循环 |

1%必须保留原运算：`P=上一根实际DIF; delta=s*(D-P); gate=abs(P)*1.0/100`，按原delta/gate比较，包含实际达到门槛的等号。**禁止改成乘0.01或直接用P±gate替代比较，禁止增加epsilon或十进制截取。**顶部钝化向下形成结构、顶部结构向上回转退钝化，底部镜像。前一实际根即使零柱也参加，不跳过；前DIF=0仅禁百分比途径，不禁有效真实翻色。未锁死时可反复结构→钝化→结构，直到锁死或参照失效；仅价格越过原结构段高低点，不额外撤销结构。

旧谷100/−20，已有底部结构DIF−10，本根绿柱收101、DIF−10.2，回转2%且未破−20，直接退底钝化；直接到−21则结构直接消失。旧“收盘不够低所以进入WAITING”撤销。正式_start_rearm此前唯一入口即该底部价格例外；后续须一并清理专属等待状态、恢复/合同/预测/页面消费，不保留无生产者的运行分支。通用有限数值、身份/引用及先校验后替换的安全检查保留。具体字段迁移和事件命名已在LLD§2—5固定为目标设计，本轮不修改运行合同；实施前先回写原合同文书。

### 4.3 阶段、历史事实与TODO

## 5. 下一根预判的已确认方向

本轮不开发预测，不把预测用例计入LLD§14的识别用例。此节替代20根横盘和全域价格细分方案；数学、合同、前端及性能编码设计见LLD§5.4、§6和§11；尚未实施或验收。

1. 只算下一根本周期完成K线，不继续后面19根，不假设多根横盘。
2. 复用当次真实计算结果，先判断可能性；本轮已突破的参照不因下一根DIF回升恢复。今天价格没突破不能排除下一根首次钝化。
3. 近B有钝化价格解就停止，不计算A；仅B确定无可能或无完整解时才算A。数据错误/超时/精度不确定不是无解，没有结构解不等于钝化失效。
4. 已钝化的结构形成/回转不重复首次价格门槛；未锁死结构继续预判考核变化，锁死后不预测撤销旧结构；无底部等待/重新激活途径。
5. 固定已有EMA，直接反求下一根价格的有限边界，再求同一参照各条件共同范围；近远不取并集/差集，不拿中点或几个样本代表范围，不遍历所有有限float。
6. 原EMA及完整delta/gate运算顺序、来源精度、合法零须正确。P±1%只定位，不替代原浮点减法判等；日线先核实际相邻源值，分钟包络完整原比较。来源前像不能仅用理想±0.0005+guard。界外证明、窄临界未决分开，不无限细分、不取中点。
7. 已证明条件正常给出；少量窄临界未决不阻止已有可用范围，必要说明普通显示。只有未决而无确定解不能算无解，也不计算A。已有DULL/B且A未算时，B突破只称近参照失效，不能称总体钝化必定消失；真实收盘仍按同根救援。
8. 内部保留精确开闭，对外在合法范围取最小/最大整数；开整数端点严格排除，无合法整数不等于无解。不新增分币价格域过滤。已证明边界或显示整数与原投影/唯一r4核验不一致时整次失败，禁止删点、挪价或继续返回READY。
9. 完整计算预算400ms，含复制/恢复/求解/核验/最终输出；不靠改规则或漏分支达标。保留现来源校准及日线三位/分钟原精度，不与两位确认混淆。
