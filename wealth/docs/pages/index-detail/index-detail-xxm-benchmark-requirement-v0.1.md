## 3 保留历史的具体例子

下面是说明行为的假设例子，不是市场数据或软件观察：

| 时间 | 算法事实 | 图上保留什么 |
| --- | --- | --- |
| A 日 | 确认顶结构；保存此前正柱段最高收盘价 3500 | A 日紫色“结构”，详情说明顶部方向 |
| B 日 | 当前柱变负，普通状态清空；历史记录继续跟踪 | A 日标记仍保留；B 日无新事件则不补字 |
| C 日 | 收盘 3501，且没有更高优先级竞争事件 | C 日绿色“结构消失”；A 日标记仍保留，详情给出顶部关联 |

若 C 日先出现新的顶部钝化，旧记录按“新顶部钝化”结束，C 日画新钝化，不再补一次旧结构的价格消失。旧结构的详情能查看这个结束原因。

历史记录可以跨很多根柱保留。详情说明“历史寿命尚未验证”；观察窗口结束只是“观察截至某时”，不能显示成已到期或已撤销。没有底部历史撤销事件的本版，不出现“底结构消失”研究标记。

## 4 十字线与详情

复用现有四窗格同步十字线和 Tooltip 避让。选中某根柱时，已有价格信息之外增加研究指标块，字段由后端提供：

1. 当柱普通状态及顶底方向；当柱全部事件。
2. 事件时间、收盘价、DIF、DEA、MACD 柱值，数值不得由标记像素反推。
3. 活动参照或事件参照的日期、价格及 DIF，二者分别说明。
4. 顶部历史记录的结构确认时间、保存价格峰、跟踪状态、结束原因及关联撤销时间。
5. 算法版本及“研究判断”；涉及长保留时说明历史寿命未验证。

同柱普通底部事件与顶部历史撤销可并存，详情必须全部列出；不能只显示列表最后一项。鼠标离开工作台，研究详情随原 Tooltip 一起关闭。

## 5 标记密度与尺寸

沿用当前 CSS 中 28px 指标标题栏，不覆盖绘图区；沿用现有字体、数字字体及四窗格边界。圆点直径 8px；标签 12px、700 加粗、16px 行高；文字右缘距圆点左缘 8px，相邻避让行隔 18px。日线和分钟共用 `XXM_MARKER_STYLE`，使用现有基础字体 token，不增加字体安装、运营配置或页面开关。

标签优先在事件点左侧同一行；重叠时继续在左侧上下避让，顶部优先向上、底部优先向下。只有左边界没有完整文字空间时才用右侧，仍保持 8px 点边间距。同柱按普通事件、历史撤销的固定顺序排列；空间不足时保留全部事件点，用紧凑数量提示代替挤在一起的长文字，详情保留完整事件。文字不覆盖其他事件点；不得为了避让把事件搬到前后柱、静默删除事件或抬高 MACD 数值范围。

在现有 45～180 根可视范围和 1600px 基准、1440px、1280px 下检查文字、标题、轴、九转及趋势图层；共享引擎仍保持统一的 range、drag、crosshair 和 viewport。

2026-10-13 实测发现全站 `body` 最小宽度为 1460px，导致 1280／1440px 的指数页横向滚动。用户已批准“只调整指数详情页”：该页 body 的最小宽度降至 1280px，沿用原主图区＋右侧行情栏；离开指数详情页后恢复全站 1460px 规则。不改其他页面布局、共享图表范围或算法。

## 6 数据状态与失败表达

| 场景 | 研究图层呈现 | 其他行情内容 |
| --- | --- | --- |
| loading | 标题附近“正在加载研究指标” | 已有 K 线继续显示 |
| ready，当前无事件 | 不画事件字；详情可读实际普通状态 | 正常显示 |
| empty，无输入 | “研究指标暂无数据” | 不冒充“没有信号” |
| delayed | “研究指标数据截至…” | 保留实际覆盖范围的结果，不填后缀 |
| error／超时 | “研究指标加载失败”，允许局部重试 | 保留 K 线、趋势、九转和其他指标 |
| 身份、时间或源值对不齐 | 研究图层 error，停止绘制这批标记 | 不改用别的频率、其他指数或研究 CSV 兜底 |
| 其他指数或未支持周期 | 不显示本图层，不发送 XXM 请求 | 沿用现有行情功能 |

未完成柱不显示本版确认事件。持有结构记录、无事件、无数据、算法失败是四种不同事实，不能统称 NONE。

## 7 页面通过标准

四个周期各自使用真实 API 和真实页面，核对事件时间、标记、数值、历史关联及状态。至少覆盖一次同色确认、一次变色确认、一次普通取消、一次历史撤销、一次新顶部事件优先、一次窗口外参照，以及图层失败但 K 线仍可用。

切换周期及标的、缩放、拖动、鼠标离开、重复请求均不能改变旧事件时间或串状态。日线／分钟两类指数 adapter 和两类股票 adapter 一起做共享图表回归。Mock 只用于极端态单测，不作为交付证据。

## 10 密集标注与节点对应修复（2026-10-16）

依据用户在核对7月27日之前的日线密集事件后明确要求“修复一下标注”：原布局可逐行移动到整个pane的远端，取消文字因此脱离自己的圆点。本轮只修文字位置及对应关系，沿用已确认的圆点、字号、字重、短标签及颜色；识别结果、事件日期、真实DIF坐标与纵轴均不改变，日线及60／90／120分钟共用。

文字仍先放在圆点左侧同一行，左边界不足才改右侧。密集时仅在节点附近避让：中心上下偏移最多40px，沿原侧额外水平移动最多48px；优先安排靠近pane上下边界、可用空间更少的事件，再按距离选择可用位置。所有文字保留pane内3px边距，避开其他文字及圆点。同柱空间不足继续用数量标签，所有事件点和详情保留，不把不同日期事件合并。

发生上下或额外水平移位的标签增加同色1px细引线，从文字框靠近节点的边缘连到该节点圆点边缘。先安排全部文字，再选最短的可用直线或折线，避免为引线让路而减少标签。候选折线只在标签和节点附近、pane内绕行；若极密集或重叠圆点导致无无碰撞路线，仍保留原点、文字和指向自身的短连线，不继续远移文字。未移位标签不额外画线；引线先画、圆点和文字后画，全部裁剪在MACD pane内。引线、有限避让参数统一收敛到现有`XXM_MARKER_STYLE`，不新增用户配置、接口字段或共享图表行为。回归以7/13、7/15、7/17、7/20四个实际事件的截图坐标及相邻pane高度为重点，另覆盖边界、同柱、窄屏与四周期真实数据驱动的绘制。
