## 1 用户将看到什么

新增“关键高低点预判”文字区，固定按日线、60 分钟、90 分钟、120 分钟排序。每个周期独立计算，内容包括：数据截至时间、候选高点或低点窗口、窗口内各个收盘端点的确认线，以及前提和失效说明。切换主图周期不改变这四行的计算范围。

文案示例中的 X、Y、A 都是占位符，日期也是格式示意，不是本轮行情预测：

> **日线**：按周一收盘及平收参考情景，周四至周五为底部结构候选窗口。若底部钝化仍有效，周四收盘达到 X 点，或周五收盘达到 Y 点，可分别确认底部结构。中途走势改变后，窗口及确认线会更新。

若尚未钝化，必须说清两阶段条件：

> **120 分钟**：需先收在 A 点以下进入底部钝化。按该入界价随后平收的参考情景，预计周四下午至周五上午为结构候选窗口；两个收盘端点的确认线分别为 X 和 Y。实际入界价不同，需要重新计算。

这里预测的是**在指定情景和收盘条件下，原内核何时可能确认结构**。它不能承诺行情一定达到该点位，也不能承诺市场极值恰好出现在这个窗口。结构确认价可以高于实际最低价、低于实际最高价；不把确认价称为精确最高／最低价。

第一步不显示评分、成功率、买卖或仓位建议，不增加 K 线或图上标记。已有九转、趋势通道、技术结论占位和 XXM 图层保持各自语义。

## 3 推荐的第一步模型：先定参考情景，再给条件价

**这是新增、待确认的预测口径，不是已经还原的徐小明时间预测公式。** 当前内核能识别结构，但仅凭已完成行情，未来中途收盘价未知，不能唯一推出“周四或周五”。因此第一步建议固定一个可复算的参考情景，使时间和点位都有明确依据。

| 当前普通状态 | 参考情景与结果 |
| --- | --- |
| 已钝化 DULL | 保留原内核锁定的参照；从最近实际收盘价开始，逐根假设平收 |
| 尚未钝化 NONE，当前柱段非零 | 在当前方向的原始两段历史池中生成候选入界价；假设下一根进入该价，随后平收；原内核决定是否及何时真正激活钝化 |
| 已确认 STRUCTURE | 显示已确认状态，暂不把同一结构重复预报为新结构；实际出现新钝化后重新生成预测 |
| 零柱、参照不足或无合格情景 | 给出具体原因，继续观察；不强制制造日期或点位 |

顶部与底部均支持，方向取当前非零柱段或已激活钝化的方向。一条预测只对应当前候选的一次结构确认；不模拟多轮高低点交替。方向变化、新钝化或来源修订后重新建候选。

“平收”是假设未来每一根收盘价保持参考价，不是保持 DIF 不变。MACD 仍逐根递推。尚未钝化时，参考价是入界价；已钝化时，参考价是最近实际收盘价。文字必须包含这项假设。第一步不以九转预计到 9 的日期强制指定结构窗口，也不把截图中的高9／低9评分带入预测；两者的关系留待下一阶段研究。

## 4 四个周期的时间窗口怎么计算

### 4.1 用完成柱计数，再映射到交易时间

只用上海时区和正式 SSE 交易日历。未来收盘端点沿用现行 `source.py.ENDPOINTS`，不按自然时间连续加 60／90／120 分钟：

| 周期 | 每个交易日的完成端点 | 周一 15:00 后未来第 3／4 根的示例（假定周二至周五正常交易） |
| --- | --- | --- |
| 日线 | 15:00 | 周四 15:00／周五 15:00 |
| 60 分钟 | 10:30、11:30、14:00、15:00 | 周二 14:00／15:00 |
| 90 分钟 | 11:00、14:00、15:00 | 周二 15:00／周三 11:00 |
| 120 分钟 | 11:30、15:00 | 周三 11:30／15:00 |

90 分钟最后一个现行端点仍为 15:00，不重新定义分桶。跳过午休、周末、节假日及非交易日。未来日历未覆盖时，只能报告无法确定日历窗口，不能用“工作日”代替正式交易日历。

### 4.2 找到参考情景的关键端点

1. 从截至端点的独立状态副本开始，最多推演未来 20 根完成柱。
2. 已有钝化直接推演；NONE 候选必须先由原内核输出同方向 DULL。满足价格条件但尚未达到最少柱数时，不提前认定已钝化。
   在首次激活前柱色改变，或激活后参照／方向改变时，停止该情景；不跨入后面的新柱段捡一个结构充当同一预测。直接反色当根已有旧方向 STRUCTURE 事件时，先保留该事件，再结束情景。
3. 激活后，找到参考情景中首个同方向 **STRUCTURE 或 CANCEL** 事件。前者代表参考情景下开始确认结构；后者代表继续按该情景运行将失去钝化资格。
4. 将这个关键端点及其紧前一根作为待求解目标。每个目标都必须晚于截至端点、晚于模拟钝化激活端点，并且其前缀尚未确认或取消该候选。
5. 对这最多两个目标，按 §5 求实际可确认 STRUCTURE 的收盘区间。无解的端点剔除；剩余两个相邻端点组成窗口，只有一个有解则给单端点窗口。

若关键端点在基准情景下是 CANCEL，改变该根收盘价仍可能避免消失并确认结构；是否可行由原内核验证，不能直接把 CANCEL 日期当成确定失效日期。

20 根内没有可用关键端点，或确认区间为空，显示“参考情景内暂未形成可计算窗口”及原因。上限是工程探测范围，不是结构寿命或可信度门槛；不把第 20 根强行当成预测窗口。

若多个入界情景对应不同窗口，分别保留情景、窗口及条件，不能取一个横跨中间无解端点的大窗口。窗口的两个端点不是两个独立结构；较早端点一旦实际确认，同一候选的较晚端点随即结束。

**窗口随条件变化而更新。** 原内核可能在窗口前因另一条价格路径提前确认，也可能窗口后才确认。新实际完成柱到达时，旧版本保留在验收记录中，页面使用新截至端点重算结果。

## 5 关键点位与结构确认条件怎么计算

### 5.1 先进入钝化的入界价

已钝化时不重新选峰，沿用锁定参照。尚未钝化时仅检查原始最近两个同向完成段，并保留最近价格前置条件及最强合格峰选择：

- 顶部：当前段最高收盘突破最近价及候选价，当前段 DIF 最高值仍低于该候选 DIF 高点。
- 底部：当前段最低收盘跌破最近价及候选价，当前段 DIF 最低值仍高于该候选 DIF 低点。
- 等价、DIF 等于参照、最少柱数不足均不认定首次钝化；价格与 DIF 极值可出现在不同柱。

入界参考价建议取“离最近实际收盘最近、同时跨过所需历史价格边界的四位小数价”。价格前置已满足时可使用最近实际收盘价。该价是否保留 DIF 背离和正确柱色，要经推演与 `step` 校验；不满足就淘汰该情景，不不断增减价格寻找一个想要的结果。候选按原最强 DIF 顺序处理；最后实际参照以原内核的 DULL 事件为准。

每个周期最多两个入界情景，按原始两段池确定，禁止从全历史补第三个峰。若两条情景激活相同参照，按完整输入情景去重；若均可算，分别说明条件，不用未来评分挑一个“更可信”的情景。

3764 例子对应的精确历史价格是 3764.1547；它首先是底部钝化的价格边界。结构低点还需要随后的确认，不能将跌破这个价直接称为底部结构形成。

### 5.2 在窗口内逐端点计算确认线

针对每个目标端点 j，固定同一参考情景在 j 之前的完整假设路径，最后一根收盘价记为 C。不同端点的前序 EMA、DIF 和参照状态可能不同，因此各有自己的点位，不能把下一根确认价复制到三天后。

最后一根指标由 §6 递推，再交给目标端点之前的原内核副本。只接受该候选的同方向 `STRUCTURE` 事件，识别路线与原版相同：

| 路线 | 顶部结构 | 底部结构 |
| --- | --- | --- |
| 同色 DIF 转向 | 有效顶钝化；DIF 单根下降达到前值绝对值的 1%；旧参照未被突破 | 有效底钝化；DIF 单根上升达到前值绝对值的 1%；旧参照未被突破 |
| 直接反色 | 先处理旧 DIF 参照突破；未触发取消且旧状态 DULL，原内核输出旧顶部 STRUCTURE | 镜像规则，原内核输出旧底部 STRUCTURE |

反色确认后普通状态可能已经 NONE，必须查事件，不能仅凭当前状态漏掉结构。零柱、NONE 直接转向和已有 STRUCTURE 都不自动生成新的结构事件。同柱确认之外的顶部历史记录仍由原内核维护，不从历史撤销事件反推结构高低点。

计算结果可以是一个区间、几段区间或空集，而不一定是一条“高于／低于 X”。程序保留各路线及开闭边界；页面按真实条件给点位或区间。不能把有上限的确认区间写成“越高越能确认”，也不能把只在特定前序路径下成立的线写成无条件触发价。

### 5.3 区间求解方法

最后一根标准 DIF 对 C 是一次函数。使用价格极值、DIF 极值／参照、1% 转向门槛、柱色零界等有限分支边界分割 C>0 的范围。日线还要加入源取整导致的分支边界。

在每段内部及边界，用 **原 `step` 的独立副本**判断是否触发目标 STRUCTURE。严格边界分别验证等号和左右邻近值；收集成功区间，不用任意点位网格扫描或假定全范围单调的二分搜索。区间合并不得跨过失败点；允许空集和无界区间，不人为截成上下 10%。

这是为原内核提供假设柱和求解边界，不另写一套 DULL／STRUCTURE 决策。已经钝化时价格不必再次突破历史价，不能把入界条件误加到结构确认上。

关键点位显示保留四位小数；若无界值，直接写“高于／低于”相应边界。显示线须向成功区间内部保守舍入，保留对应比较符号，原始精确边界用于判断和验收。若区间窄于展示精度，显示“临界区间暂不能可靠给出单点”，不四舍五入后宣称一定触发。

## 6 MACD 递推及来源精度

### 6.1 恢复计算起点

现有内核只消费指标，不持有 EMA12、EMA26 的内部状态。预测层从该周期、截至端点之前的完整有序收盘序列恢复 EMA12／26 和内部 DEA；不从当前 K 线可视范围重新暖机，不混用日线与分钟种子，不把报告脚本 import 到正式业务模块。

最近 250 根逐项与同源 DIF、DEA、柱值校准。日线当前冻结源三位小数，误差须处于独立三位四舍五入的范围内；分钟使用浮点来源，绝对误差门槛暂定 1e-8。这些是来源校准容差，不能进入原内核的严格价格／DIF 比较。

校准失败、尾部不足 250 根、取整方式无法确认或来源格式改变时，该周期显示来源／精度待核验，不用固定偏移修补。尤其不能把软件截图的 DIF 差额当作预测层补偿值。

### 6.2 下一根及多根递推

设上一根内部 EMA 为 E12、E26，内部 DEA 为 A；假设下一根收盘为 C：

```text
E12' = (11/13) × E12 + (2/13) × C
E26' = (25/27) × E26 + (2/27) × C
D'   = E12' − E26'
A'   = 0.8 × A + 0.2 × D'
H'   = 2 × (D' − A')
```

内部 EMA／DEA 保留计算精度；提供给识别内核的假设柱按相同来源输出格式处理。日线 DIF／DEA／柱值分别按已核实的源规则取整，不能由已取整 DIF／DEA 重新拼柱值；分钟沿用完整浮点输出。最终确认线以原 `step` 对这些同口径数值的结果为准。

多根情景必须每根都推进内部 EMA、普通状态和历史池。不能只替换最后一根 close，却保留原来 DIF；也不能以“剩余 DIF 距离除以最近速度”代替结构确认时间。[已有研究 §8.30](/Users/congming/github/goldenshare/docs/product/xxm-macd-structure-research-v1.md#830-历史-dif-峰与级别口径消失时间空间均依赖参照与运行速度)中的恒速估算描述的是钝化消失预算，不是本次结构时间预测公式。

## 7 更新、失效与评分准备

每条结果绑定对象、周期、真实截至端点、来源前缀指纹、识别 Spec、预测 Spec、参照身份及完整参考路径。假设未来柱不得写入原缓存的真实点／事件账本，也不得进入正式行情、指标或 Lake。

| 情况 | 处理 |
| --- | --- |
| 新实际完成柱到达 | 用实际输入重建截至状态和预测；原有参考路径失去的部分不得继续当已知事实 |
| 实际结构提前形成 | 用真实内核事件标记已确认，旧未来候选结束；不为了匹配窗口推迟事件 |
| 钝化消失、参照变化、方向变化 | 原候选失效；按最新实际状态评估新候选，不能沿用旧确认线 |
| 数据修订／版本改变 | 作废旧缓存，保存新的前缀身份；验收记录中的旧预测保留，不覆盖成新版本命中 |
| 来源滞后或缺口 | 单列数据截至及状态；不显示为有效的当前预测 |
| 超出 20 根或没有可行区间 | 单列原因；不等于“该周期不会出现结构” |

预判 ID、生成时的状态／假设、时间窗口、点位条件和原 Spec 都保留在结构化输出中，为下一步评分提供对照键。第一步验收保存原预测及后续真实事件，区分：条件满足且确认、条件满足却未确认、前提改变、提前确认、窗口外确认、到期未确认、数据不可评分。

**第一步不在 GET 查询中写数据库，不新增正式预测业务表、调度任务或自动采集历史。** 持续积累正式预测账本及评分模型属于下一阶段单独设计；本阶段只冻结验收样本和输出身份。没有自动评分、不把情景通过率命名为信号可信度。

## 13 请用户确认的新增选择

四周期、上证范围、技术面底部纯文字、评分下一步已是明确需求，不要求重复确认。本文新增的三个实现选择需要本次方案评审：
