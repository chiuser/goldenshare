## 3 修订模型：价格范围与关联条件

继续使用条件推演；不承诺行情必然走到某日或某价。**时间取决于前序价格条件，不能只凭已完成行情推出唯一日期。**

| 当前普通状态 | 计算方式 |
| --- | --- |
| NONE，当前柱段非零 | 下一合法完成端点的收盘 P 在所有正有限价格中求钝化有效范围；各有效 P 都独立递推指标、状态和锁定参照 |
| DULL | 沿用已锁定参照；从下一根开始求结构收盘范围。若下一根无解，目标之前的中间根暂按最近真实收盘平收，明确标注假设 |
| STRUCTURE | 说明已确认时间和方向，等待新钝化，不重复预报同一结构 |
| 零柱／参照不足／无合格范围 | 说明原因，不制造价格或日期 |

NONE 两阶段模型：下一根收盘价 P 是变量，必须落在真实求出的钝化范围内；若目标晚于再下一根，目标前的其他中间根暂按 P 平收。目标当根收盘价 C 再独立变化。**P 可取一个区间内的不同价格，后续条件 C 随 P 改变；“中间平收”仍是明确的参考假设，不覆盖任意中途走势。**

这次修订只预测当前候选的一次结构成立，不模拟多轮高低点交替。未在下一根激活的收盘范围不绕到后续新柱段找另一候选；新真实行情到达后重新评估。九转日期、视频评分和恒速消失估算都不参与指定目标时点。

| --- | --- | --- |
| 日线 | 15:00（日线 API 使用日期表示） | 周二收盘先钝化，周三收盘才可检查结构 |
| 60 分钟 | 10:30、11:30、14:00、15:00 | 周二 10:30 先钝化，11:30 可检查结构 |

### 4.2 从近到远检查完整关联条件

记真实截至状态为 S，下一根端点为 t1，收盘变量为 P，目标端点为 tj、收盘变量为 C。最多检查未来 20 根：

1. NONE 先求 t1 的有效钝化范围 E；同一根由 NONE 激活 DULL 不同时当作结构成立，最早检查 j=2。DULL 从 j=1 开始。
2. 对每个有效 P，原内核在 t1 激活的实际参照才是后续参照；中间价格按 §3 递推。中间发生消失、零柱／换段或提前结构时，这条路径不再作为 tj 的有效前提。
3. 对每个 tj 求完整对应关系 Rj：哪些 P 仍保持该钝化、哪些 C 会让原内核输出同方向、同参照的 STRUCTURE 事件。只靠两个或几个代表 P 无解，不能证明整段无解。
4. 最近有可靠解的端点为唯一目标；同时在DTO保留该端点适用的前置范围Ej及其余P的排除分类。Ej是E的子集时，不能把条件套给整个E；简明正文按§18.4保留必要的具体日期／价格前提，不并列另一个未来日期。
5. 最早只有窄区间或精度疑义时，显示待核验，不跳到更晚端点。仅当更早端点整个允许范围被可靠判定无解，才继续检查下一根。
6. 目标当根先求 C 的有效区间，再判断取消／反色；不能因平收参考价会取消，就漏掉其他能形成结构的 C。

没有结构时点，但 E 已可靠算出时，仍显示“下一根可能出现钝化的收盘范围，后续结构时点暂未找到”。20 根是工程探测上限，不是结构寿命、行情概率或保证等待 20 根就会形成结构。

最近时点表示“存在一组所列条件可以在这里形成结构”，不表示整个 E 都能在这里形成结构。新增真实行情后，用真实 P 代替变量、重建状态及条件，日期可以提前、推后或消失，旧候选不锁定。

## 5 收盘范围、关联关系与结构成立规则

### 5.1 完整求钝化收盘范围

对所有 P>0 的有限价格，从同一真实 S 与内部 EMA 投影 t1，再交原 `step` 副本。仅接受同方向的 DULL/activation 事件；记录原内核实际选择的参照，不自行给某个历史峰强行配资格。

底部必须同时满足：

- 本轮绿色 MACD 柱段继续有效，累计根数达到原 min_bars=2。
- 本轮最低收盘严格低于最近同向历史段低点，也严格低于被选参照低点。
- 本轮 DIF 最低值严格高于被选参照 DIF 低点，即价格创新低而指标没有创新低。

顶部是镜像：本轮最高收盘严格超过最近价和参照价，本轮 DIF 最高值严格低于参照高点，且仍为红柱、根数合格。价格极值和 DIF 极值可发生在不同柱，不能要求同根。

只看原始最近两段历史参照，资格判断和最强合格 DIF 排序沿用原内核。结果按实际参照分组，可有多段不连续价格范围；禁止从全历史补第三段，禁止把两个参照限制误当两个试算价格上限。

**价格范围通常同时有价格创新极值的一侧和背离仍有效的另一侧。**跌得过深可能导致底部 DIF 也创新低；涨得过高可能导致顶部 DIF 也创新高，不能把它们写成“越低／越高越容易钝化”。范围之外要分别说明：未创新极值、指标也创新极值、柱色／最少柱数不合格、参照不足或取整边界待核验。文案不把待核验域说成确定不会触发。

若本轮此前已满足价格创新极值，下一根无需再次跨过历史价格边界；下一根收在该边界上方／下方也可能激活钝化，最终看原 step。3764.1547 只是已保存日线样本的一条历史参考价；不能当作所有周期、所有截至时点的通用钝化线。

### 5.2 每个前置收盘价对应自己的结构条件

对每一个有效 P，都必须用它递推内部 EMA、DEA 与原内核状态，再求目标 C 的有效范围，形成关系：

```text
前置收盘 P 在某个有效范围内
并且目标前的钝化没有消失或提前确认
并且目标收盘 C 落在该 P 对应的范围内
→ 原内核在目标时点输出同方向、同参照的 STRUCTURE 事件。
```

同色路线：顶部 DIF 比上一根下降达到其绝对值的 1%；底部 DIF 比上一根上升达到其绝对值的 1%；前值为零不适用。锁定参照未被突破。直接反色路线：先检查旧 DIF 参照是否突破，未取消且旧状态为 DULL，原内核可输出旧方向 STRUCTURE。零柱不是反色确认；反色后普通状态为 NONE，也要保留真实结构事件。

已有钝化后，收盘回到原历史低点上方／高点下方，并不自动让钝化消失。结构阶段不再强加首次钝化的价格创新极值条件。底部收盘继续走低也不必然消失，关键是 DIF 是否突破锁定参照以及柱段状态。

### 5.3 人能看懂的呈现与完整计算的区别

后端保留完整 P→C 条件关系。页面优先给“对所列前置范围都成立”的统一充分条件：对该范围中的每个 P，C 均满足原结构规则。这取各 P 成功区间的**交集**，不是把它们的并集合成一个万能范围。

若交集为空，不强造统一条件。若两位或四位无法可靠表达交集，保留完整关系、明确说明该交集临界且不提供通用点位。展示全部已核实的钝化范围、唯一目标所适用的前置范围，再用最多三个逐项计算的例子解释差异，明确“例子不覆盖全部价格，实际收盘后重算对应范围”。例子只用于解释，不能决定触发范围、最近时点或成功率；不能把例子写成必须命中的前提价。

| 3764.1547 | 否：价格与参考低点相等，未严格创新低 | 不提供这次候选的后续结构条件 |

### 5.4 精度与边界

保留原始严格开闭边界。页面默认显示两位小数且向成功范围内部舍入；若两位会隐藏有效窄区间或不同路线的空隙，自动提升至四位并注明“此处为边界，保留更多小数”。四位仍无法可靠展示则显示待核验。历史参考价可用“严格低于 3764.1547”解释等号，不用“四舍五入后的 3764”替代判定。

不得用“约”“大概”价格判断触发；示例价格和展示边界要再次交原 step 验证。超出展示充分条件不等于结构绝不会成立；应说明它需要按该前置价分别计算。

## 6 MACD 递推及来源精度

### 6.1 恢复计算起点

现有内核只消费指标，不持有 EMA12、EMA26 的内部状态。预测层从该周期、截至端点之前的完整有序收盘序列恢复 EMA12／26 和内部 DEA；不从当前 K 线可视范围重新暖机，不混用日线与分钟种子，不把报告脚本 import 到正式业务模块。

最近 250 根逐项与同源 DIF、DEA、柱值校准。日线当前冻结源三位小数，误差须处于独立三位四舍五入的范围内；分钟使用浮点来源，绝对误差门槛暂定 1e-8。这些是来源校准容差，不能进入原内核的严格价格／DIF 比较。

校准失败、尾部不足 250 根、非中点舍入口径不相容或来源格式改变时，该周期显示来源／精度待核验；日线未知的中点按 §15.4 排除，不臆定其等号归属，不用固定偏移修补。尤其不能把软件截图的 DIF 差额当作预测层补偿值。

### 6.2 下一根及多根递推

设上一根内部 EMA 为 E12、E26，内部 DEA 为 A；假设下一根收盘为 C：

```text
E12' = (11/13) × E12 + (2/13) × C
E26' = (25/27) × E26 + (2/27) × C
D'   = E12' − E26'
A'   = 0.8 × A + 0.2 × D'
H'   = 2 × (D' − A')
```

内部 EMA／DEA 保留计算精度；提供给识别内核的假设柱按相同来源输出格式处理。日线 DIF／DEA／柱值分别取最近三位值，未知中点及浮点邻域按 §15.4 处理，不能由已取整 DIF／DEA 重新拼柱值；分钟沿用完整浮点输出。最终结构条件以原 `step` 对这些同口径数值的结果为准。

多根情景必须每根都推进内部 EMA、普通状态和历史池。不能只替换最后一根 close，却保留原来 DIF；也不能以“剩余 DIF 距离除以最近速度”代替结构确认时间。[已有研究 §8.30](/Users/congming/github/goldenshare/docs/product/xxm-macd-structure-research-v1.md#830-历史-dif-峰与级别口径消失时间空间均依赖参照与运行速度)中的恒速估算描述的是钝化消失预算，不是本次结构时间预测公式。

## 7 不成立、钝化消失与更新

三种情况必须分开说。**价格不在首次钝化范围内**表示本次钝化前提没有成立；**已经有效的钝化被破坏**表示旧钝化消失；**前置价格改变**通常表示需要重算，不能一概说结构失效。

| 情况 | 算法含义 | 页面用人话说明 |
| --- | --- | --- |
| 尚未钝化，收盘未满足价格创新极值或背离 | 这次激活条件不成立 | “价格没有创新低／高”或“指标也创新低／高，这次不能形成钝化” |
| 已有底钝化，DIF 严格低于锁定参考低点；顶部镜像 | 先 CANCEL，再禁止该候选结构 | “指标突破原参照，原底／顶钝化消失，旧条件不再适用” |
| DIF 恰好等于参照 | 首次激活要求严格背离；已有 DULL 的取消要求严格突破 | 不把两者混写；保留原比较及源精度，不能加 epsilon |
| 出现零柱 | 当前普通候选按原内核清空，不是直接反色结构 | “MACD 到零柱，原候选需重新判断” |
| 直接反色且原内核输出 STRUCTURE | 旧方向结构成立，预测结束 | “已形成底／顶部结构”，不能把所有换色都叫消失 |
| 直接反色先触发参照突破 | CANCEL 优先 | “原钝化消失，本次未形成结构” |
| 前置实际收盘在 E 内、却不在唯一目标的 Ej 内 | 钝化可成立，但这一个目标时点不适用 | “可出现钝化，但不满足所列结构时点的前置条件；收盘后重新计算” |
| 目标收盘 C 不在该 P 的有效区间 | 这一根未形成该结构；不必然取消 DULL | “本根未形成结构；是否仍钝化以最新指标为准” |
| 中间实际走势偏离平收假设，或提前确认 | 旧时间及 C 条件不再直接适用 | “前序走势已改变，条件重新计算”／“结构已提前形成” |
| 统一业务日期切换或该日期内来源修订 | 对应真实状态及来源身份改变 | 更新截至、范围、关联关系和目标；20:00前不因当天分钟收盘而提前切换 |
| 来源滞后、缺口、校准或精度不足 | 不能提供有效当前条件 | 说明等待哪类数据／核验，不当作“无结构” |
| 20 根内无可靠结构条件 | 有界模型内无结果 | 保留已核实的钝化范围，说明后续时点暂未找到，不说永远不会出现结构 |

每条输出绑定对象、周期、真实截至、来源前缀、有效日历、双 Spec、参照及全部关联条件。新行情重算，不覆盖验收记录的旧版本。假设柱、条件关系和示例不得写入原真实事件账本、正式 DB 或 Lake。

第一步只保存验收样本；不在 GET 写业务预测表，不新增自动调度、历史采集、评分或交易建议。评估时区分条件满足且事件一致、条件满足而事件不一致、前提改变、提前／推后形成、未形成、数据不可判断；计算错误不能被“滚动更新正常”掩盖。

关联关系不是“P范围×某个C并集”的矩形。每项由如下确定性结构表达：适用P范围及固定reference/route；一组目标前条件；一组目标当根条件，组合含义为AND，多个relation之间为OR。条件的左右是有限表达式，比较符仅lt/le/eq/ge/gt；表达式只允许有限常量、P/C的仿射式、加减、固定系数乘法、abs及带guard的源三位舍入。系数由§6逐根递推生成；禁止可执行字符串、eval或SQL表达式。分钟不需要舍入节点；日线舍入疑义另列精度排除域。它保留整个P→C规则，前端不计算表达式。

关联例子的结构示意（不是合法完整响应或当前行情，字母是已计算表达式占位）：

```text
activation: t1，P∈(A,B)，参照R
relation: 同一t1范围内，目标前钝化存活；在tj满足 L(P)≤C≤U(P)，route=dif_turn
relation: 同一适用范围内，目标前钝化存活；在tj满足 C≥V(P)，route=color_flip
common: P∈Ej时，C∈交集I即可形成结构（若I为空则不提供）
example: P=p1 → C∈I1；P=p2 → C∈I2；P=p3 → C∈I3
```

状态不变量：

- READY：真实DULL，relations非空、目标非空；activation=null，targetEntryRanges为空，assumption如实给中间路径。
- CONDITIONAL_ENTRY：真实NONE，activation有效，relations和targetEntryRanges非空、目标非空；目标至少为第2根，关联范围必须是激活范围的子集。targetEntryExclusions与Ej划清已核实范围及疑义部分。
- ENTRY_ONLY：真实NONE，activation有效但20根内没有可靠结构关系且无可能更早的精度疑义；目标null，relations/common/examples/targetEntryRanges为空，显示第一阶段范围。有疑义必须为PRECISION_PENDING。
- NO_CANDIDATE：无合法候选／激活范围，目标null，relations为空；理由明确。可返回activation的排除分类，但无有效ranges。
- PRECISION_PENDING：不提供有效结构关系；若激活范围本身已核实，可保留它并标明后续待核验。最早疑义端点不能冒充成功目标。
- CONFIRMED：取原实际事件的confirmedAt/direction，未来字段为空；不因投影校准不足抹掉已确认事实。

### 15.3 P→C关联求解、存活条件与最近性证明

NONE：t1用变量P生成实际DULL；之后目标前每根仍按P平收。每根内部指标都是P的仿射式；日线交给原内核的D/H分别舍入，内部EMA/DEA不舍入。DULL：P退化为当前真实close，下一根目标没有中间路径，不出现“未来必须收在该点”的文字。

锁定R后，中间每根必须维持同色非零、DULL且同参照。底部每根DIF不得严格突破R的低点，顶部镜像；若单根已达到原1%转向，则结构提前成立，不能继续当作后面目标前提。价格创新极值无需重做；零柱、直接反色及取消都终止中间路径。目标当根则允许直接反色输出旧方向事件，按事件而不是最终ordinaryState识别。

固定某个P时，沿用现有单末端求解思想：目标DIF是aC+b(P)，目标hist是1.6(D−A(P))，与参照、前值1%及hist符号界相交。**不能只固定一个P求C后再推广。**完整域按P的参照／极值／前值正负／舍入变化分支，并考虑各C边界的交点；每个分支产生完整关联关系。

分钟采用有限仿射边界：对P域分割，C边界为P的分段仿射函数，可检验每个分支的存在性。日线先将相关前序D/H舍入变化按P分支，目标条件再加入有限三位半刻度及guard界；也允许用上述受限表达式紧凑保留舍入函数，避免将每个刻度重复序列化。紧凑表达式须与全部分支一致，不能用插值替代阶梯条件。

对j=1…20按序检查：该端点的关系存在性由约束消元及完整分支证明；取样仅交叉验证。NONE的j=1只激活。若某P中间结束，剔除对应子域而非全周期；已取消的同一候选不在后续重启新参照。更早全域确定无解才检查后根；更早仅有待核验／不可显示解则PRECISION_PENDING；同一最近端点既有可靠解又有精度排除域时，只展示可靠条件并解释排除，不宣称排除域无解。

统一充分条件按同参照、同路线的完整适用域求各P成功区间的交集。用边界函数的极值和所有分支证明，而非仅取低／中／高三个P；不能人为缩窄前置域来制造“通用”。不同参照／路线需分别标注覆盖域，不说对全部钝化范围都成立。完整relations仍保留全部条件，交集为空时如实给例子。

例子优先保证每个有效参照至少一例（原池最多两个），其余名额按低／中／高内点规则补足，总数≤3；重复价去重。边界内向选点须通过原激活／结构事件重放；若无安全例子不造数。每例都附P自己的全部C区间和route，小空隙保留。

### 18.3 过远的可复算定义（用户已确认）

采用各周期自己的实际波动，不使用全周期统一的“300点”“5%”或主观概率判断。记该周期最新完成收盘为C0，待说明的端点距离asOf为n根合法完成柱：

1. 从截至asOf的同周期完整真实前缀中，取最近60个与该端点**收盘时刻相同、跨度同为n根**的历史样本。日线按n个开市日；分钟按原端点序列，包含其实际跨日与午休顺序，不混入其他频度，不按自然分钟补柱。
2. 每个样本计算`abs(close[i] / close[i-n] - 1)`。升序排列，取第`ceil(0.95 × 60)=57`项，得到q。不得读asOf之后的行情，不因历史回放而借用今天的波动。
3. 该端点的展示参考范围为`[C0 × (1-q), C0 × (1+q)] ∩ 正价格域`。激活用n=1；结构用实际barsAhead。目标跨两根就用两根历史变化，不把单根幅度机械乘2或跨周期复制。
4. 可选区间与参考范围有交集就保留整个已验证区间；不是把原条件裁切成参考范围。单个可选边界在参考范围之外才可标为过远。保护条件仍保留。
5. 样本不足60、存在非正值／缺口或端点不匹配时，不猜一个替代幅度，不删边界来制造简短结果；正文写“近期点位暂未生成”，完整计算状态及原因保留。来源失败仍走原失败规则。

## 32 首次顶部钝化当根DIF条件的预测修订（2026-10-18，拟修订，未实施）

### 32.1 本轮目标与保持范围

管理员选定本轮只细化预测方案和代码级LLD。承接识别LLD§26：仅一次新的TOP DULL／activation额外要求输入当根`bar.dif > 0`；不是要求所有顶部事件或所有未来根的DIF始终为正。底部首次钝化、等待重新钝化、R1参照切换及已有TOP DULL／STRUCTURE转换不追加这项限制。日线、60／90／120分钟共用规则，正式产品仍仅000001.SH。

本节只处理预测计算与解释的必要变化，不新增预测功能、交易建议、评分、概率或参数。不改原20点业务日期、各周期完成端点、20根上限、中间平收假设、来源校准和近期展示筛选。§5.1“顶部是镜像”是现R1的描述；若采用本次拟修订，顶部首次识别还须满足当根DIF正，不能继续把顶部与底部写成完全镜像。

### 32.2 预测价格范围必须增加的条件

从真实截至状态恢复的内部EMA出发，下一根收盘P对应原始投影DIF：

```text
D(P) = b + K × P
b = (11/13) × E12 − (25/27) × E26
K = 2/13 − 2/27 = 28/351 > 0
```

| 周期／状态 | 新增条件及边界 | 明确禁止 |
| --- | --- | --- |
| 60／90／120分钟，NONE准备首次TOP | 原资格与`D(P)>0`取交集；数学分界为`P=-b/K`，严格等号不合格；浮点运算分界邻域沿原精度保护 | 不以当前已知DIF、本段最高DIF或历史参照DIF的零点代替 |
| 日线，NONE准备首次TOP | 对提供给内核的三位DIF检查正值，沿原`source_options`保留所有可能取整值；全正才确定合格，全非正确定不合格，取整导致激活结果不一致则未决 | 不直接用未取整D(P)>0，不把所有微小正值当作0.001，不改日线源值 |
| BOTTOM、等待重入、已有钝化／结构 | 原预测逻辑继续；不增加上述交集 | 不给底部增加镜像负DIF限制，不把首次条件复制到后续结构确认价C |

日线该项资格真正变化在原始DIF的`+0.0005`附近，而非0；现有`daily_rounding_guard=1e-10`使边界附近保留0和0.001两种来源可能值。新分界须包含`+0.0005−guard`、`+0.0005`、`+0.0005+guard`及原浮点误差包络。`-0.0005`两侧的DIF都不为正，不因该负中点单独声称首次资格未决。guard用于预测来源的不确定性，不进入识别内核的严格比较。

### 32.3 对结构时间、收盘条件及状态的影响

NONE先重新求下一根的合格激活范围，再按该范围建立P—C关系，检查20个标准完成端点中最近一个可靠结构解。各关系、共同条件和示例只能关联新的有效激活范围；不能先沿旧范围选日期，再过滤几个示例。原范围全部被排除时，不输出依赖它的结构日期／点位，也不称“钝化消失”，因为该信号尚未激活。

同一真实起点、同一投影下，新激活域只是旧域与当根资格的交集；不得凭空扩大。此项缩小本身不会创造更早的结构解，但实际接入新内核后，真实历史状态和参照也可能变化，所以新旧页面日期不保证只会推后，须按新真实前缀分别核验。

已经激活的TOP DULL仍按原规则求结构，目标DIF为0或负并不因本次限制自动取消；STRUCTURE仍显示真实确认。BOTTOM的重新钝化、初始／最终参照和下一根完整结果域保持。校准失败、未决、暂无激活条件、已有钝化但暂无结构条件继续分开，不增加新status。

### 32.4 排除原因与页面文字的拟定处理

现`DIF_NOT_DIVERGENT`在文字中解释为“指标也创新高”，并参与是否省略远端背离边界的判断。它不能直接替代“当根DIF不为正”，否则会解释错误，并可能错误省略价格边界。

**建议在现`activation.exclusions[].reason`中单独增加`CURRENT_DIF_NOT_POSITIVE`，含义仅为“本次首次顶部钝化的当根DIF资格未满足”。** 这是拟议枚举值，不是新增字段、status、事件或HTTP异常码；当前Python DTO和TS adapter均不接受它。本轮只登记设计及直接消费者，下一步必须完成全部合同消费者审计并确认后才能实施，不擅自修改契约或用旧原因兜底。

近期触及时，后端文字草案：“未触发：{本周期下一完成时点}{收盘范围}，DIF未转为正值，顶钝化条件不成立。”不写“钝化失效”“指标也创新高”。该项不参与现有“远端背离边界省略”；近期筛选、价格／柱色保护项原样保留。全无激活解时沿用`NO_CANDIDATE/NO_ENTRY_RANGE`及“当前没有可形成钝化的收盘条件”，不强造新的状态文案。

### 36.3 计算必须遵守的顺序
