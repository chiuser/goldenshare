## 4. 核算设计中已经可以确定的部分

1. 原始事实只有初始化、逐笔买卖、资金流水和费用修正等用户有效输入；更正保留审计关系，不无痕删除后续结果的依据。
2. 每个账户按日期处理，同日按股票汇总买卖数量与金额，同时保留每一笔明细。成本和资金核算不借助录入时间猜测真实成交先后。
3. 当日卖出成本按日初未分摊含费成本比例分配；再把当日买入含费成本加入未分摊池。动态摊薄成本单独使用累计买入投入减累计卖出净回款，不能替换未分摊成本池。
4. 当日结束数量为零才结束轮次；日内卖出又买回而日末仍持有不拆轮。历史修改后从最早受影响日期重算，不能混用新旧快照和闭环结果。
5. 期间收益金额按各轮期末费用后累计收益减期初对应值计算；初始化按其基线截断；期内已结束轮次保留终值。该金额与同版本日增量加总对账，不额外再加闭环利润。
6. 当前累计、单笔闭环、整轮、期间收益分别命名，不能共用一个没有范围含义的 `profitRate` 在各处自行解释。
7. 转出本身不产生盈亏，不因转出而删除本期已经参与的本金。转出后账户真实可用现金非负校验按已通过的 §9.4 执行；后续买入可用的复用额度按 PRD §12.1.1 第 19 项及本方案第 6 节计算。

## 6. 已确认：混合现金转出后的本期复用本金

### 6.1 问题背景与确认记录

PRD §12.1.1 第 13—17 项要求：闲置现金不计本金、同一期资金复用不重复计本金、真正新增参与的资金才增加本金，不要求用户标明资金来源。同时，账户实际现金可以同时包含“本期还没用来买股票的现金”和“本期卖出回款”。

此前 A—I 案例没有混合现金转出这一步，未明确分配顺序。2026-09-09 用户已选择第一种处理：优先扣本期未参与交易的闲置现金。产品文档已补充第 19 项、案例 J 和 T52，本节不再是待拍板项；不涉及改变转出合法性或让用户填写资金来源。

### 6.2 同一份流水的具体差异

假设同一账户、同一个完整自然周，忽略费用，仅用于说明本金。A、B 均隔日卖出，满足 T+1；周初没有持仓。

| 日期 | 记录 | 操作后现金 |
| --- | --- | ---: |
| 周初 | 现金 20000.00 | 20000.00 |
| 周一 | 买 A，花 10000.00 | 10000.00 |
| 周二 | 卖 A，收到 11000.00，赚 1000.00 | 21000.00 |
| 周三 | 转出 10000.00 | 11000.00 |
| 周四 | 用余下 11000.00 买 B | 0.00 |
| 周五 | 卖 B，收到 12000.00，再赚 1000.00 | 12000.00 |

两种分配下，本周收益均为 `2000.00`，转出合法，所有现金和持仓都一致；不同的只是“本周曾经参与的去重本金”：

| 决策结果 | 如何解释周三转出及周四再买 | 本周本金 | 本周收益率 |
| --- | --- | ---: | ---: |
| 已采纳：优先转出本期未参与交易的闲置现金 | 转出的 10000.00 是一直没买过股票的现金；留下的 11000.00 全部属于本周卖出回款，买 B 不新增本金 | 10000.00 | 20.00% |
| 未采纳：优先转出本期卖出回款 | 卖出回款被转走 10000.00，只剩 1000.00；买 B 的另外 10000.00 是原闲置资金首次参与 | 20000.00 | 10.00% |

第二行仅保留为被否决的反例，不是可选配置或并存算法；实现和验收只能采用第一行。

### 6.3 已确认的规则边界

采用“优先转出本期未参与交易的闲置现金”：本例本周显示 **20.00%**。不因为转出一笔原本就闲置的钱，把本可复用的资金重复计入本金，也不新增录入字段。

每个统计窗口独立识别闲置与复用额度；转出先减少闲置部分，超出的部分才减少仍可用于后续买入的复用额度；已经计入本期的历史参与本金不因转出而删除。后续转入只增加现金，尚未实际买入时不增加本金；若原可复用回款已被转走，不能把后来的新入金凭空视为那笔回款仍留在账户。

原 A—I 及已通过资金转出交互保持不变。下面是规则的技术展开及有限算术验证，不将用户对产品边界的确认扩大为全部算法实现已验收。

### 6.4 单账户全仓期间本金计算步骤

计算范围先固定为“一个具体账户 + 一个日 / 周 / 月窗口”。窗口开始时重新建立三个计算值，均不是新增真实资金账户，也不是收益率持久化明细：

| 计算值 | 含义 | 窗口起点 |
| --- | --- | --- |
| `idleCash` | 本窗口尚未用于股票的闲置现金 | 期初真实现金；不追查窗口之前现金的来源 |
| `reusableCash` | 本窗口卖出所得、仍留在账户且可用于后续买入的回款 | 0；跨期已是现金的部分不携带上期复用标记 |
| `participatingPrincipal` | 本窗口已经参与过的去重成本本金 | 期初仍持有数量对应的未分摊含费买入成本合计；不取市值、动态摊薄成本或已卖出数量的历史投入 |

按业务日期升序读取有效事实。同一日期先汇总资金转入、资金转出、买入含费支出和卖出净回款；每笔费用仍按原始流水保存值求和，不能先合并交易再算最低佣金。以下顺序是固定的日级计算步骤，不是真实成交先后的推断，也不改变 T+1 可卖校验：

1. 当日转入加入 `idleCash`，不改变 `participatingPrincipal`。
2. 当日卖出净回款加入 `reusableCash`，不再增加本金。若极端费用使合计卖出净回款为负，先扣可复用现金，不足部分扣闲置现金；该费用支出不冒充新买入本金。真实余额不足仍须由账户校验阻止，不允许把负现金强行归零。
3. 当日买入含费支出优先消耗 `reusableCash`；不足部分消耗 `idleCash`，且只有这部分增加 `participatingPrincipal`。
4. 当日转出优先消耗步骤 3 后的 `idleCash`，不足部分才消耗 `reusableCash`；不减少 `participatingPrincipal`。
5. 每日核对两类现金均非负，且 `idleCash + reusableCash = 同版本真实账户现金`。下一日承接这两个余额及已参与本金。对有效事实，只改变同日录入排列不得改变结果。

当日有足够真实现金时，“买入优先用复用回款”和“转出优先用闲置现金”分别优先消耗不同部分，不应靠录入先后来选择分母。真实转出能否提交继续按 PRD §9.4 的当前已登记余额检查；这个期间重算器不得绕过该检查，也不能借未登记回款让转出成功。

窗口结束后：`期间收益率 = 同窗口新增收益金额 / participatingPrincipal`。无交易无持仓且本金为 0 是无期间股票收益，不除以 0；存在有效持仓却本金异常为 0 是核算错误，不伪装为空值。日 / 周 / 月分别重放对应窗口，不能从日快照分母直接相加得到周月分母。

“全部账户”分别运行账户计算，再汇总分子、分母。本节还不能直接套用于单股筛选：单股不能获得其他股票的复用本金抵扣，相关范围裁剪及其他股票买卖对可用现金的影响须在后续核验中单独展开，不能把单股分母相加冒充账户分母。
