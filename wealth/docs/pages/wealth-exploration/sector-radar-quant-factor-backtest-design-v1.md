## 1. 结论与硬边界

本研究要验证的不是“哪个参数能把历史曲线画得最好看”，而是：

> 当某个东财行业相对自身历史出现逐渐转热异常时，这个信号是否能更早、更稳定地识别随后真实形成市场热度趋势的行业。

第一轮遵守以下硬边界：

1. 当前实验只研究东财一级行业；申万和跨体系比较继续暂缓，概念和地域留到后续独立研究阶段。
2. 一级行业阶段结束后，分别对二级行业、三级行业、概念和地域开展独立研究；行业层级联合评分只要求一、二、三级行业分别形成可复现、可追溯且通过数据、样本量和无未来泄漏门禁的有限候选，不要求每一层先选出正式胜出参数，也不依赖概念和地域研究。二级和三级的主要比较范围分别是同一一级父行业、同一二级父行业的直属子行业。
3. 首轮历史基线只比较 `B=60/120` 个交易日；250 日周期不进入本轮测算，不做每日自动动态选择。
4. 两种基线使用完全相同的输入因子、权重、平滑参数、趋势窗口和触发阈值，避免混入其他变量。
5. 信号日只使用当日及此前已经发布的数据；验证结果从下一交易日开始计算。
6. 不能用未来平滑热度值继续上升作为唯一成功标准，防止平滑产生机械自相关。
7. 主要成功结果使用未来每日横向客观榜单验证；相对收益和成交延续作为辅助结果分别报告。
8. 回测是有效性研究，不输出买卖、仓位、收益承诺或自动交易结论。
9. 一级行业、二级行业、三级行业、概念和地域分别选择适用于本类全部对象的一套统一参数；不根据单个行业或板块的样本内最优结果配置专属参数。
10. 若两种基线均未通过样本外门禁，结论必须是“不形成正式热度信号”，不能强行选一个上线。

## 2. 研究问题与假设

### 2.1 主研究问题

分别使用 60、120 个交易日历史基线时，“逐渐转热”信号在未来 1、3、5 个交易日内是否具有稳定的榜单延续或榜单确认能力？

### 2.2 候选假设

| 假设 | 预期特征 | 必须验证的代价 |
|---|---|---|
| `B=60` | 参照常态更新快、信号更早、信号数量更多 | 可能对短期噪声过敏、误报更高 |
| `B=120` | 响应速度和稳定性相对均衡 | 可能没有任何一端的明显优势 |
“基线越长”不等于曲线必然越平滑。历史基线决定参照常态的适应速度；每日曲线的平滑程度还取决于状态平滑方法。长基线可能让一个已经持续多日的异常状态维持更久。

### 2.3 选择问题

第一轮需要回答：

1. 哪种基线在样本外具有更高的 1/3/5 日榜单成功率和相对基础概率提升？
2. 哪种基线能在成功率、信号覆盖率、误报率和提前量之间形成更合理的平衡？
3. 结果是否稳定存在于不同年份和行业整体环境，而不是依赖少数行情？
4. 统一参数在不同一级行业中是否保持稳定，而不是只由少数行业的结果支撑？

第一轮不回答“如何自动识别行业整体环境并动态选择基线”。该能力属于后续独立的参数选择模型。

## 3. 研究对象、时间和比较范围

### 3.1 研究对象

第一轮对象池固定为已发布到 `core_serving.wealth_sector_hierarchy` 的当前 31 个东财一级行业代码；开放交易日读取 `core_serving.trade_calendar`，价格和成交读取 `core_serving.dc_daily`，行业名称沿用该 hierarchy 快照。三个来源均为 Prod 只读输入。

这是“当前一级行业代码池”的 60/120 日候选测算，不宣称已经重建历史层级版本。既有数据审计已确认东财三级层级只有当前版本。任一日期不足 31/31 个行业时，整日标记为不可验证并从研究日历排除；不能补零、前向填充或使用残缺横截面。排除日必须逐日记录，不把单日缺口扩散成之后 60/120 个有效发布日全部失效。

本轮实际冻结窗口共有 400 个源交易日、398 个完整发布日和 12,338 行完整输入；`2026-05-18`、`2026-05-20` 因横截面不完整被整日排除。60/120 日共同可评价日为 253 日。

### 3.2 交易日

所有窗口都以已发布交易日计算，不使用自然日。页面和研究统一遵守财势乾坤公共业务日期：

```text
tradeDate = pageContext.tradeDate
```

对于信号日 `t`：

1. 因子、历史基线和趋势条件最多使用 `t` 日盘后已经发布的数据。
2. 次日结果为 `t+1` 的下一个有效交易日。
3. 3 日和 5 日结果分别使用之后 3、5 个有效交易日。
4. 数据延迟时不能混用不同日期事实，必须排除该信号日或明确标记不可验证。

### 3.3 横向比较范围

第一轮一级行业每日横向榜单的比较范围是全部有效东财一级行业。

未来扩展时：

1. 二级行业主要在同一个一级父行业的直属二级行业中比较。
2. 三级行业主要在同一个二级父行业的直属三级行业中比较。
3. 全市场二级、三级同级总榜只作为辅助研究，不替代父级内比较。
4. 子行业数量过少时，不能直接复用“前 20%”二元门槛；应优先报告连续排名分位，并单独设计最小样本门禁。

## 4. 符号与参数

| 符号 | 含义 | 第一轮口径 |
|---|---|---|
| `i` | 某个东财一级行业 | 当时有效身份 |
| `t` | 信号交易日 | 盘后已发布日 |
| `G_t` | `t` 日全部有效东财一级行业 | 横向排名分母 |
| `B` | 自身历史标准化基线 | `60/120` |
| `W` | 趋势判断窗口 | 固定 10 日，作为比较 B 的控制变量 |
| `R` | 图表显示范围 | 产品可选 `20/30/60`，不参与信号选择 |
| `lambda` | EWMA 状态平滑权重 | 第一轮固定一个预注册值，不随 B 改变 |
| `h` | 未来验证窗口 | `1/3/5` 个交易日 |
| `Pcs_t(x)` | 指标在 `G_t` 内的同日横截面分位 | 0～100 |
| `Z_B(x)` | 指标相对行业自身前 B 日的稳健标准分 | 不使用当天和未来 |

第一轮的目标是比较 `B`，因此 `W`、`lambda`、因子集合、权重和触发阈值都必须在回测执行前登记并固定。若修改任何一个控制变量，必须产生新的实验版本，不能覆盖原结果。

## 5. 第一轮因子设计

### 5.1 输入事实

第一轮只使用两个可解释事实域：

| 事实域 | 原始事实 | 目的 |
|---|---|---|
| 价格 | 行业日收益、全部一级行业收益中位数 | 判断相对价格强度 |
| 成交 | 行业成交额、行业自身前 20 日成交额中位数 | 判断成交参与是否放大 |

第一轮不纳入：

1. 资金流。
2. 历史成员扩散。
3. 龙头贡献和集中度。
4. 新闻、公告和讨论热度。
5. 申万行业事实。

### 5.2 原始派生事实

```text
relativeReturn1d(i,t)
  = sectorReturn1d(i,t)
  - median(sectorReturn1d(G_t,t))
```

```text
amountRatio20(i,t)
  = sectorAmount(i,t)
  / median(sectorAmount(i,t-20...t-1))
```

成交额比例进入历史标准化前使用对数：

```text
logAmountRatio20(i,t) = log(amountRatio20(i,t))
```

这样可以降低单日极端巨量对状态输入的支配程度。

### 5.3 自身历史稳健标准化

对于任一输入 `x(i,t)`：

```text
median_B(i,t)
  = median(x(i,t-B...t-1))
```

```text
MAD_B(i,t)
  = median(abs(x(i,k) - median_B(i,t))), k=t-B...t-1
```

```text
Z_B(x(i,t))
  = (x(i,t) - median_B(i,t))
  / (1.4826 * MAD_B(i,t))
```

`1.4826 = 1 / 0.67449`。对于正态分布，绝对偏差中位数约为标准差的 `0.67449` 倍，因此该系数将 MAD 校准到接近普通标准差的尺度。金融数据并不要求服从正态分布；这里使用它是为了获得稳健、可解释的统一尺度，不把它作为业务可调参数。

边界规则：

1. 历史窗口不包含 `t` 日。
2. `MAD=0` 或有效历史不足时不生成伪分数，记录明确无效原因。
3. 极端标准分必须经过预注册的稳健截断，再映射到有界状态区间。
4. 60、120 日分别独立计算，不能用 60 日结果填充 120 日窗口。

### 5.4 第一轮状态输入

为隔离历史基线的影响，第一轮使用固定等权候选：

```text
stateInput_B(i,t)
  = boundedMap(
      0.50 * Z_B(relativeReturn1d(i,t))
    + 0.50 * Z_B(logAmountRatio20(i,t))
    )
```

`0.50/0.50` 只是第一轮研究控制，不代表正式产品权重。第一轮不得边比较 B 边修改价格和成交权重。

### 5.5 状态平滑

```text
heatState_B(i,t)
  = lambda * stateInput_B(i,t)
  + (1 - lambda) * heatState_B(i,t-1)
```

第一轮要求：

1. `lambda` 在 60/120 两种基线中完全一致。
2. 执行前把具体值写入实验登记；首版建议以 `0.30` 作为单一控制候选，但不能把它解释为已验证最优值。
3. 第一轮不同时搜索多个 `lambda`，避免把 B 比较扩展成参数组合搜索。
4. 后续若研究平滑参数，必须新建独立实验，不复用本轮选择结论。

## 6. “逐渐转热”信号事件

### 6.1 信号候选定义

为了让两种基线可直接比较，第一轮为每个 `B` 使用同一候选规则：

```text
turnHotSignal_B(i,t) = true when:

1. heatState_B(i,t) 向上穿越 70
2. heatState_B(i,t-1) < 70
3. 最近 10 日 heatState_B 线性斜率 > 0
4. 最近 10 日相邻变化中，向上变化占比 >= 60%
```

`70` 和 `60%` 是第一轮固定候选阈值，不是正式产品门槛。它们必须在研究期登记后冻结，在校准期和最终保留期不得重新调整。

### 6.2 重置信号

同一轮升温过程不能每天重复记为新信号：

```text
reset_B(i,t) = heatState_B(i,t) < 60
```

行业发出一次转热信号后，只有状态回落到 60 以下，才能再次产生新的向上穿越信号。

原始设计还要求：若一次信号的未来 5 日验证窗口尚未结束，又出现同类触发，只保留首个事件并记录为同一事件簇。当前 v1～v3 实现并没有独立的“5 日事件簇归并”，只实现了“触发后解除 armed、跌破 reset 后重新 armed”的重置语义。因此现有结果均以重置语义为准；R2 执行前必须重新预注册是否增加 5 日事件簇归并，不能把该设计项写成已实现。

### 6.3 信号事件表

当前 `SignalEvent` 实际保留：

| 字段 | 含义 |
|---|---|
| `baseline` | 60/120 |
| `trade_date` | 信号日 |
| `sector_code/sector_name` | 东财一级行业身份 |
| `phase` | 研究期、校准期或历史保留期 |
| `signal_day_rank_pct` | 信号日横向排名分位 |
| `entry_type` | `entry`（提前转热）或 `retention`（高位延续） |
| `success_1d/success_3d/success_5d` | v1 多数日口径下的未来成功标记 |
| `future_1d_rank_pct` | 下一交易日横向排名分位 |
| `future_3d_on_list_days/future_5d_on_list_days` | 未来 3/5 日上榜天数 |
| `future_5d_relative_return_sum` | 未来 5 日相对收益合计 |
| `future_5d_amount_active_days` | 未来 5 日成交活跃天数 |

原设计中的 `factorVersion`、`signalRuleVersion`、`heatStateAtSignal`、`relativeReturnAtSignal`、`amountRatioAtSignal` 和逐事件 `inputCompleteness` 尚未进入当前事件表。实验级配置、输入哈希和排除日已记录在汇总结果中，但不能等同于逐事件字段已经交付。后续类别研究若需要正式事件契约，必须先补齐并测试这些字段。

## 7. 成功结果设计

### 7.1 为什么不能只用未来 heatState

未来 `heatState_B` 与信号使用同一平滑序列。即使原始市场事实没有延续，EWMA 也可能让状态短期维持上升，从而人为提高成功率。

因此：

1. 未来 `heatState_B` 只作为诊断结果。
2. 主要成功标准来自未来每日横向榜单。
3. 价格和成交结果直接使用未来客观事实。

### 7.2 每日横向榜单

每个交易日使用全部有效东财一级行业的同一套横向事实生成独立榜单。第一轮固定采用价格与成交等权的横向分位，不使用任何候选 B：

```text
dailyHorizontalScore(i,t)
  = 0.50 * Pcs_t(relativeReturn1d(i,t))
  + 0.50 * Pcs_t(logAmountRatio20(i,t))
```

```text
dailyRankPct(i,t)
  = Pcs_t(dailyHorizontalScore(i,t))
```

第一轮榜单口径在两种 B 中完全一致。这样，“60/120 日哪个信号更有效”由同一把未来尺子判断，不允许让不同基线拥有不同“上榜”定义。

```text
onList(i,t) = dailyRankPct(i,t) >= 80
```

即进入当日全部一级行业前 20%。横向榜单不使用行业专属历史基线，避免损害行业之间的可比性。

### 7.3 主要成功标准

下表是 v1 首轮登记的多数日成功定义：

| 验证窗口 | 主要成功定义 | 产品含义 |
|---|---|---|
| 次日 `h=1` | `t+1` 进入或保持前 20% | 信号次日得到榜单确认 |
| 未来 3 日 `h=3` | 3 日中至少 2 日进入前 20% | 不只是单日进入，而是形成短期持续 |
| 未来 5 日 `h=5` | 5 日中至少 3 日进入前 20% | 热点在一周内具备多数日延续 |

信号日未上榜和已经上榜必须分开报告：

1. **进入成功**：信号日不在前 20%，未来窗口达到成功门槛。
2. **留存成功**：信号日已在前 20%，未来窗口继续达到成功门槛。

不能把进入和留存合并后只报一个平均值，因为两者的基础成功概率不同。

v2 和 v3 已对该口径作研究性拆分，当前实际报告口径为：

1. **提前转热**：次日上榜、3 日内至少一次上榜、5 日内至少一次上榜，同时保留 3 日多数上榜和 5 日多数上榜。
2. **高位延续**：次日留榜、3 日多数留榜、5 日多数留榜。
3. 两类事件分别使用满足同一信号日状态的自然基础概率和匹配非信号日对照，不能再共用混合总体基础概率。

因此，v1 表格是历史首轮口径，不再单独代表当前 v2/v3 的全部主要结果定义；后续 R2 必须在执行前重新冻结本类别的主结果和辅助结果。

### 7.4 排名改善结果

二元前 20% 会丢失接近门槛的变化，因此同时报告：

```text
forwardAvgRankPct_h(i,t)
  = mean(dailyRankPct(i,t+1...t+h))
```

```text
rankPctImprovement_h(i,t)
  = forwardAvgRankPct_h(i,t)
  - dailyRankPct(i,t)
```

一个行业从后 50% 提升到前 25%，即使没有进入前 20%，仍然记录为排名明显改善，而不是完全丢失信息。

### 7.5 未来相对收益

```text
forwardRelativeReturn_h(i,t)
  = sectorReturn(i,t+1...t+h)
  - median(sectorReturn(G,t+1...t+h))
```

分别报告：

1. 中位数。
2. 均值及稳健置信区间。
3. 正相对收益比例。
4. P10/P25/P75/P90 分布。
5. 最大不利相对变动。

相对收益只用于理解热度语言是否有现实价格对应，不把它包装为买卖收益预测。

### 7.6 成交参与延续

分别报告未来 1/3/5 日：

1. `amountRatio20` 的中位数。
2. `amountRatio20 > 1` 的交易日占比。
3. 是否继续温和放大。
4. 是否为信号日单日巨量后迅速回落。

价格和成交结果不提前合并成一个二元“盈利成功”。第一轮保留独立结果，避免不同业务含义相互抵消。

## 8. 对照组

任何成功率都必须和基础概率比较。第一轮至少建立以下对照：

| 对照 | 定义 | 用途 |
|---|---|---|
| 全部可验证行业日 | 所有满足数据门槛的一级行业交易日 | 计算自然基础成功率 |
| 匹配非信号日 | 同一行业、相近东财一级行业整体环境但没有触发信号的日期 | 控制行业和整体环境差异 |
| 当日涨幅规则 | 当日相对收益进入前 20% | 判断复杂模型是否优于简单涨幅榜 |
| 当日成交规则 | 当日成交活跃进入前 20% | 判断复杂模型是否优于简单放量榜 |
| 未平滑状态规则 | 相同输入但不使用 EWMA | 判断平滑是否只是制造表面连续性 |

匹配非信号日应优先按以下条件匹配：

1. 同一行业。
2. 相近年份或相邻历史区间。
3. 相近的全部一级行业当日收益中位数分位。
4. 相近的一级行业横截面收益离散度分位。

匹配规则必须在执行前登记，不能看到结果后更换对照样本。

第一轮不读取市场宽基指数。上述整体环境只由同日东财一级行业事实计算，不参与热度、信号和横向排名，只用于对照与稳健性解释。

## 9. 回测评价指标

### 9.1 主要指标

```text
successRate_B,h
  = successfulSignalEvents_B,h
  / validSignalEvents_B,h
```

```text
baseRate_h
  = successfulControlEvents_h
  / validControlEvents_h
```

```text
lift_B,h
  = successRate_B,h / baseRate_h
```

第一轮必须分别输出：

1. 次日成功率和 Lift。
2. 3 日成功率和 Lift。
3. 5 日成功率和 Lift。
4. 进入成功率与留存成功率。

### 9.2 覆盖与提前量

| 指标 | 定义 | 解释 |
|---|---|---|
| 信号数量 | 独立信号事件数 | 防止极少样本制造高成功率 |
| 信号密度 | 每 100 个可验证行业日产生的事件数 | 比较不同 B 的敏感度 |
| 趋势捕捉率 | 新榜单持续事件中，前 1/3/5 日出现转热信号的比例 | 衡量是否漏掉大量真实趋势 |
| 平均提前量 | 信号日至首次满足榜单确认之间的交易日数 | 衡量发现是否足够早 |
| 误报率 | 信号后 5 日未达到榜单成功且排名恶化的比例 | 衡量噪声代价 |

### 9.3 稳定性和路径指标

1. 未来平均排名分位改善。
2. 未来相对收益分布。
3. 成交参与延续率。
4. 信号日后最大排名回撤。
5. 信号日后最大相对价格回撤。
6. 不同年份和东财一级行业整体环境下的成功率、Lift 与信号密度。
7. 各行业事件数量和结果贡献，防止少数行业支配总结果。

### 9.4 统计不确定性

1. 所有成功率和 Lift 必须同时提供置信区间，不能只给点估计。
2. 时间序列和相邻行业日存在相关性，优先使用按时间块或事件簇的 bootstrap，不把每行当作完全独立样本。
3. 单个行业事件不足时不强行给行业专属结论，保留“不足以判断”。
4. 若不同 B 的置信区间高度重叠，不得写成“某个 B 明显更优”。

### 9.5 当前实现覆盖

第 9 节定义的是完整研究评价目标，当前 v1～v3 只完成了其中一部分：

| 评价项 | 当前状态 | 说明 |
|---|---|---|
| 信号数量、1/3/5 日成功率、自然基础概率、点估计 Lift | 已完成 | 已拆分提前转热和高位延续 |
| 成功率置信区间 | 已完成 | v1/v2 提供成功率区间 |
| 匹配对照和保守 Lift 区间 | 已完成 | v3 使用一对一匹配并给出保守区间 |
| 季度分块、逐行业排除、简单规则反例 | 已完成 | v3 已交付 |
| 排名改善 | 未交付 | 当前只保留下一日排名和未来 3/5 日上榜天数，未输出平均排名改善 |
| 相对收益路径 | 部分完成 | 只保留未来 5 日相对收益合计，未输出 1/3/5 日分布、P10/P25/P75/P90 和最大不利变动 |
| 成交参与路径 | 部分完成 | 只保留未来 5 日成交活跃天数，未输出 1/3/5 日中位数、温和放大和单日脉冲识别 |

这些未完成项可以在 R2 事前计划中择取必要部分，但不得在未获批准时为“补齐一级行业”重新执行回测。

## 10. 历史基线选择规则

不能简单选择样本内成功率最高的 B。候选基线必须同时比较：

1. 1/3/5 日主要成功率和 Lift。
2. 信号数量和趋势捕捉率。
3. 平均提前量。
4. 误报率。
5. 排名改善、相对收益和成交延续。
6. 跨年份、跨行业整体环境稳定性。
7. 样本外表现和置信区间。

候选结论示意：

| 结果 | 含义 |
|---|---|
| 60 日成功率略低，但提前量和捕捉率明显更好 | 可能适合作为早期信号，但需明确误报代价 |
| 120 日成功率更高，但信号显著更少且确认更晚 | 需要结合覆盖率与提前量判断，不按成功率单独取胜 |
| 120 日在多项指标上稳定占优 | 可能成为简洁默认，但仍需样本外支持 |
| 两种 B 均没有相对对照组的稳定 Lift | 暂不形成正式信号 |

第一轮只允许形成全体一级行业统一基线建议。后续的二级行业、三级行业、概念和地域各自独立选择一套类别统一参数；不在同一批历史样本中边发现个体差异边为单个板块配置专属参数。

## 11. 时间切分与防过拟合

### 11.1 覆盖门槛

执行前必须先确定：

1. 东财一级行业日行情的共同有效起止日。
2. 60/120 日预热期后，各候选还剩多少可验证信号日。
3. 未来 5 日结果是否完整。
4. 每日有效一级行业数量是否稳定。
5. 价格和成交事实是否使用同一交易日。

代表行业拥有长历史不能替代全部一级行业共同覆盖。

### 11.2 时间切分

按时间顺序划分：

1. **研究期**：验证数据、实现候选公式、登记异常案例。
2. **校准期**：确认固定阈值、控制变量和报告结构。
3. **最终保留期**：只执行一次，用于样本外结论。

禁止随机打乱交易日。首轮使用既有生产覆盖结论冻结 `2024-12-20..2026-08-14`，按两种基线共同可评价日期顺序以 `50%/25%/25%` 划分研究期、校准期和最终保留期；最终保留期必须完全晚于研究期和校准期。

### 11.3 Walk-forward

除固定最终保留期外，还要使用滚动或扩展窗口回放：

1. 每个信号点只使用当时可见历史。
2. 基线窗口随交易日滚动。
3. 不能使用完整历史的中位数或 MAD 回算早期信号。
4. 数据修订必须形成新的输入版本和回测版本。

### 11.4 行业整体环境报告

至少按以下东财一级行业横截面维度分组报告，不要求第一轮构建自动环境选择模型：

1. 全部一级行业当日收益中位数正/负。
2. 一级行业横截面收益离散度高/低。
3. 一级行业成交活跃比中位数高/低。

这些分组只用于检查稳健性，不用于运行时动态选择 B。

### 11.5 当前时间验证状态

1. v1 按时间顺序做了 `50%/25%/25%` 切分，并在当时只查看一次历史保留段。
2. v2、v3 随后复用了并查看了同一个 `2024-12-20..2026-08-14` 窗口，因此该窗口现在只能作为历史探索证据，不能再称为未见样本外证据。
3. 当前计算按交易日滚动使用过去窗口，没有用完整未来历史反算早期状态；但尚未形成独立的 walk-forward 参数选择报告。
4. 行业整体环境因子已用于 v3 匹配对照，尚未形成第 11.4 节定义的完整环境分组报告。
5. 一级行业前瞻验证已经暂缓。未来若恢复，必须重新冻结 `2026-08-14` 之后的未见完整交易日，并重新获得执行批准。

## 14. 灵活配置与计算边界

### 14.1 已确认原则

未来应具备版本化配置能力，但本轮不实现自动动态选择：

1. 基础价格和成交事实每日固定生产。
2. `B/W/lambda/权重/阈值` 通过结构化配置表达。
3. 单板块的研究结果可以按其所属对象类别的统一配置现用现算并缓存，但不允许为该板块私自换参数。
4. 正式横向榜单中的同一对象类别必须使用同一配置，保持可比性。
5. 只允许一级行业、二级行业、三级行业、概念和地域五个对象类别之间使用不同配置，不做单板块专属配置。
6. 配置必须带版本、生效日期和参数哈希，禁止回溯覆盖历史结论。

### 14.2 推荐计算形态

本节是未来产品化建议，不是当前实现。当前只有离线只读研究脚本，没有配置中心、在线现算、缓存或盘后正式物化链路。

```text
每日基础事实物化
  ↓
版本化研究配置
  ↓
按需计算纵向因子与信号
  ↓
按 tradeDate + sector + configHash 缓存
  ↓
正式默认配置可盘后物化
```

该形态兼顾研究灵活性和正式页面稳定性。技术可行性、单行业延迟、整榜延迟、缓存命中率和生产资源消耗必须在未来技术方案中用真实数据测量，本文件不提前确定实现架构。

## 15. 验收门禁

### 15.1 方法门禁

1. 两种 B 只有历史基线不同，其余控制变量一致。
2. 信号日不存在未来数据泄漏。
3. 同一事件不被连续交易日重复计数。
4. 主要成功结果不依赖未来平滑热度线自证。
5. 进入成功和留存成功分开。
6. 所有成功率有基础概率、Lift 和置信区间。

### 15.2 数据门禁

1. 每个结果可追溯到行业、交易日和来源事实。
2. 缺失不补零、不前向填充。
3. 历史不足不降级复用更短 B。
4. 信号日和未来结果日的横向比较范围完整。
5. 预热期、排除日和源修订明确记录。

### 15.3 结论门禁

1. 不根据样本内最高成功率直接选 B。
2. 不用极少事件得出行业专属结论。
3. 不忽略信号数量、覆盖和提前量，只报告成功率。
4. 不把相对收益结果包装成投资建议。
5. 样本外未通过时不得进入正式产品模型。

### 15.4 当前门禁对账

1. 60/120 日比较保持了相同输入、权重、平滑和趋势参数；无未来泄漏测试已通过。
2. armed/reset 防止持续高位逐日重复触发，但独立的 5 日事件簇归并尚未实现，因此第 15.1.3 项只部分通过。
3. 提前转热和高位延续已经拆分，自然对照和匹配对照均按同类状态构造。
4. 完整横截面、缺失不补数、历史不足不降级和排除日登记已通过。
5. “所有成功率和 Lift 均有统一置信区间”只部分通过；不能将 v3 的关键匹配 Lift 区间扩写为全部指标已覆盖。
6. 结论门禁已遵守：当前不选择正式一级行业参数，不进入生产模型。

## 19. 后续研究路线与任务顺序

### 19.1 统一参数原则

后续研究把对象分为五个独立类别：一级行业、二级行业、三级行业、概念和地域。

1. 每个对象类别必须独立完成数据覆盖、参数选择、信号验证和样本外评价。
2. 每个对象类别在探索期可以保留事先批准的少量候选，但最多产生一套正式统一参数；类别之间可以不同，同一类别内不得因具体板块而变化。
3. “找到合适参数”必须表示候选通过事先登记的样本外门禁，不是从历史最高成功率中强行选一个。
4. 若某类别没有候选通过，结论必须是“暂无可用统一参数”，不得直接复用一级行业参数。
5. 五类研究都以未来 `1/3/5` 个已发布交易日是否继续热为主要目标，进入成功和高位延续必须分开评价。
6. 探索阶段可以在未进入样本外评价前主动停止并保留研究结论；只有宣称“正式统一参数”时，才必须完成事先登记的未见样本门禁。

### 19.2 R1：一级行业探索（已暂停，未形成统一参数）

1. 已完成 R1-H1 历史稳健性补充：匹配对照、时间分块、逐行业排除和简单规则反例；结果见 `sector-radar-quant-factor-backtest-result-v3.md`。
2. 提前转热主实验比较 `B=60/120` 且触发阈值为 55，阈值 60 作为更严格的次实验；高位延续单独使用阈值 70 评价。
3. 一级行业前瞻样本验证已按当前研究决策暂缓；保留原定义作为恢复条件：若后续恢复，只能使用 `2026-08-14` 之后未见过的完整交易日，不使用残缺横截面，不补数，且必须再次获得执行批准。
4. 只在稳健性、样本外成功率、Lift、信号覆盖和行业分布同时通过时，形成一级行业统一参数结论。

#### R1-H1：历史稳健性补充实验登记

R1-H1 只使用已冻结的 `2024-12-20..2026-08-14` 历史输入，不读取新增生产日期，不声称是新的未见样本外证据。

1. 候选固定为提前转热 `60/55`、`120/55`、`60/60`、`120/60` 和高位延续 `60/70`、`120/70`；各触发阈值的重置位仍固定为低 10 分。不继续扩大历史参数网格。
2. 匹配对照必须为同一行业、同一信号类型的非信号日，具备完整未来 5 个已发布交易日结果。候选对照按“年份差、市场日收益中位数分位差与收益横截面离散度分位差之和、交易日距离、日期”确定性排序，按信号日升序做一对一无放回匹配。
3. 市场日收益中位数由同日 31 个一级行业涨跌幅计算；收益横截面离散度使用同日涨跌幅的中位绝对偏差。两者均在全部可验证日期上转换为时间分位，只用于对照匹配。
4. 时间分块固定为自然年季度，每个候选分别报告各季度的事件数、信号成功率、匹配对照成功率和 Lift；小样本分块只报告不下结论。
5. 逐行业排除固定为每次删除一个一级行业的信号与对应匹配对照，重算成功率与 Lift；报告 31 次删除后的最小值、最大值和 Lift 方向保持比例，不产生行业专属参数。
6. 简单规则反例只使用第 8 节已定义的三项：当日相对收益前 20%、当日成交活跃度前 20%、相同历史基线与输入但不使用 EWMA 的状态信号。前两项按每个符合条件的可验证行业日计数；未平滑状态保留与候选相同的阈值、10 日趋势、向上变化占比和重置规则。
7. 提前转热固定报告次日上榜、3 日内上榜、5 日内上榜、3 日多数上榜和 5 日多数上榜；高位延续固定报告次日留榜、3 日多数留榜和 5 日多数留榜。匹配对照、时间分块、逐行业排除和简单规则必须使用同一成功定义。
8. R1-H1 只判断历史结果是否依赖对照选择、少数时段、少数行业或平滑机械性；不使用该历史窗口宣布正式胜出参数。

### 19.3 R2：二级行业统一参数研究

当前状态：尚未启动。下一动作只能是提交首轮探索计划供评审；计划必须列明对象池、父级内比较规则、小同组门禁、有限候选、执行复杂度和停止条件，获得批准后才能读取新数据或执行回测。

1. 对当前已发布二级行业做独立数据覆盖审计，登记父行业、直属子行业数和可验证交易日。
2. 二级行业在同一一级父行业的直属二级行业范围内计算榜单与未来继续热结果；全市场二级行业总榜只作辅助分析。
3. 所有二级行业共用同一组候选参数，按父行业分层汇总成功率、Lift 和覆盖；不为不同父行业或具体二级行业分配不同参数。
4. 对直属子行业数过少的父行业单独设置可比性门禁，不机械复用前 20% 二元阈值。

1. 对当前已发布三级行业做独立数据覆盖审计，核验二级父子闭包和可验证交易日。
2. 三级行业在同一二级父行业的直属三级行业范围内计算榜单与未来继续热结果；全市场三级行业总榜只作辅助分析。
3. 所有三级行业共用同一组候选参数，按父行业分层汇总结果；不为不同父行业或具体三级行业分配不同参数。

### 19.5 R4：概念板块统一参数研究

1. 概念板块单独完成对象池、交易日、涨跌幅和成交额覆盖审计。
2. 全部有效概念板块使用同一套候选参数，不按单个概念配置专属历史基线或阈值。
3. 概念板块的数量、重叠成分和生命周期与行业不同，必须独立设计对照组、覆盖门禁和样本外验证，不得以复制一级行业参数代替回测。
4. 输出一套概念统一参数或“暂无可用参数”结论，主要验证目标为未来 `1/3/5` 日是否继续热。

### 19.6 R5：地域板块统一参数研究

1. 地域板块单独完成对象池和数据覆盖审计。
2. 全部有效地域板块使用同一套候选参数，不按单个地域配置专属参数。
3. 地域板块独立验证未来 `1/3/5` 日继续热的成功率、Lift、覆盖和稳定性，不直接复用行业或概念参数。
4. 输出一套地域统一参数或“暂无可用参数”结论。

### 19.7 R6：行业层级联合评分研究

R6 只在 R1、R2、R3 分别得到可复现、可追溯的有限候选后启动；候选不必在单层已经成为正式胜出参数，但必须通过数据、样本量和无未来泄漏门禁。R6 与概念、地域研究没有数据依赖。

1. 以一条完整的“一级行业 → 二级行业 → 三级行业”路径作为评分对象，不做无父子关系的跨行业拼接。
2. 每一级先使用自身类别的有限候选参数计算热度与信号，再将各层级的样本外“未来继续热”概率校准到统一可比尺度。
3. 联合评分必须同时反映父级方向是否持续、子级在直属同组中是否走强，以及三层信号是否方向一致。
4. 不直接把三个原始热度值简单相加。联合公式、权重和阈值必须在独立实验中预注册，并与“只看三级行业”的简单基线比较增量价值。
5. 只有联合评分在未见样本上对未来 `1/3/5` 日继续热的预测明显好于单层基线，才能进入产品化评审。
6. 单层历史成功率最高的参数不必然是最终参数。若另一个单层候选与上下级信号组合后能稳定提高目标发现率、准确率或提前量，它可以在联合评分阶段获得更高优先级。
7. 一、二、三级候选的组合数、联合权重候选数和总执行次数必须在 R6 执行前单独列出并获得批准；不得将所有历史参数做无边界笛卡尔积搜索。

### 19.8 阶段停止门禁

1. 前一阶段未得到可复现结果时，不以其参数为后一阶段的默认正确答案。
2. 二级、三级、概念和地域都要新建实验登记和结果文档，禁止覆盖一级行业实验。
3. 上述研究完成前不进入个体板块专属参数、申万行业或跨体系比较。
4. 本路线只定义研究顺序和门禁，不承诺任何候选一定能形成正式产品参数。
5. 任何新一轮回测、参数扩展或层级联合实验都必须在执行前获得用户批准；上一轮的批准不自动授权下一轮。
6. 执行中如果实际组合数、数据量、运行时间或临时产物超过已批准上限，必须停止并重新报告，不得自行扩容继续。

### 19.9 探索性回测执行原则

本项目属于方法未定的探索性研究。执行中要对数据异常、参数敏感性、简单规则反例和层级信号协同保持敏感，但这种敏感度不得转化为无限调参。

#### 19.9.1 递进研究目标

每个对象类别都按以下顺序评价：

1. **能发现目标板块**：对事后真正形成持续热度的板块，信号能覆盖多少；主要看趋势捕捉率和漏报。
2. **能准确发现目标板块**：已发信号中有多少在未来 `1/3/5` 日确实继续热；主要看成功率、Lift、误报率和样本量。
3. **能尽早发现目标板块**：在板块正式进入热门榜单或形成明显趋势前可以提前多少个已发布交易日；提前量不得通过显著牺牲准确率获得。

最终目标是在保持较高后续持续成功率的前提下，尽可能提前给出可观察的板块信号；不以信号数量或某个样本内最高成功率单独决策。

#### 19.9.2 执行前审批清单

每一轮执行前必须形成可供审批的计划，至少列出：

1. 本轮唯一主研究假设和需要回答的问题。
2. 对象池、父子比较范围、数据来源、时间区间、完整性门禁和排除规则。
3. 候选参数维度、每个维度的取值、参数组合总数、对照规则总数和实际计算执行次数。
4. 预计输入行数、主要扫描轮数、预计运行时间、峰值内存、临时产物大小和是否需要新的生产只读导出。
5. 主要成功标准、简单规则基线、样本量与稳定性门禁、淘汰条件和本轮停止条件。

上述清单未获得用户批准时，不得读取新数据、启动回测或产生新参数结论。

#### 19.9.3 有限尝试与防跑偏规则

1. 每轮计划必须声明当轮最大参数组合数和最大执行次数；实际执行不得超出。
2. 看到结果后可以记录新假设，但不得在同一轮追加参数或反复回放；新假设必须形成下一轮独立计划并重新审批。
3. 每轮只处理一个主假设家族，禁止同时扩张 `B/W/lambda/权重/阈值/因子集合`并从大网格中挑最高值。
4. 所有已执行候选、淘汰候选和失败理由必须保留，不得只展示当前最优结果。
5. 可以择优保留未完全通过门禁的探索性候选，但必须标记“待验证”，不得改写为已验证正式参数。
6. 如果在已批准范围内找不到高成功率且具备足够覆盖的通用参数，必须允许结论为“本轮未找到”，不为了得到胜者而扩大搜索。
