## 字体事实

1. 页面正文计算字族为 `-apple-system, system-ui, SF Pro Display, PingFang SC, Microsoft YaHei, Segoe UI, sans-serif`。
2. 行情数值 token 含 `DIN Alternate`，当前浏览器可能以 `Roboto Mono` 或后续字族回退；若 Figma 无法使用 DIN，必须按计划登记 `FONT_RENDERING_GAP_OPEN`，不允许改变已量测的宽度、字号或行高来伪造一致。

## 交互证据边界

页面默认态与全部几何量测仍只使用 `1600 x 1200` 基线。鼠标离开态已经由用户在真实页面完成操作并取证：tooltip、十字线与日期标签均为不存在状态。该离开态截图使用当时的 `761 x 800` 视口，只证明交互可见性，不替代 `1600 x 1200` 的布局尺寸基线。自动化浏览器桥仍不能可靠发出 leave/out 事件，但不再构成 M0 阻塞。
