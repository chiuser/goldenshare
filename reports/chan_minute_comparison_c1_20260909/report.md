# C1：简单形态有局部线索，尚未证明三买有额外价值

日期：2026-09-09。状态：设计先冻结、计算与独立复核完成；探索性结果，不发布策略或概率。

**结论：本轮没有产生通过门槛的方法。简单突破回踩在上证30/60分钟出现值得保留的正向线索，但不能宣布有效；三买相对简单形态的额外价值，因共同背景样本过少，仍无法可靠判断。** “没有证明三买更好”不等于“已经证明简单方法更好”。

依据：[原方案第18节](../../docs/product/chan-signal-prediction-and-profit-experiment-plan-v1.md)。只测一个固定版本，无调参、F1/S1过滤、账户回测、正式数据访问或新盲测。

## 1. 本轮怎样比较

- 原A三买原始93个、冷却82个全部保持；事件从原变化账本重建，原入场/次日收益逐字段对齐。不重新用最后一张图标记过去。
- 简单形态：收盘突破前5完整交易日最高价，随后最多8根30分钟/4根60分钟柱，首次回到突破位±0.25倍前20日平均TR内、收盘仍在突破位上方且比前柱收盘低。等待中收盘跌回突破位或最低价跌穿容差下界，候选失败。突破柱不同时算回踩，每日最多启动一个候选。
- 普通时点：不要求买点，按相同指数、频率、年份、盘中时刻、20日趋势正负、20/60日相对波动高低匹配。背景只配权，不过滤买点；同层普通柱不足20时标记无推断支持。
- 两方法各自沿用20交易日冷却，全部原始事件另存。两者直接对照只用共同背景层、采用相同固定权重，不能把不同背景的总均值当成增量价值。

输入固定2021-09-09—2026-09-08、43560根；2021年75个交易日只初始化。下一日可评分信号时点2022-01-04—2026-09-07，1134个交易日；结果至9月8日。2026年只截至9月8日，并非完整年度。

Q=下一交易日收盘/信号后下一根完整柱开盘−1。以下百分数是无成本指数价格变化，不是账户收益；上涨率R另以信号收盘为分母。

这六个点估计虽都偏向简单方法，但样本只有每侧1—8次，**不能据此宣布简单方法战胜缠论**。两方法本来就少，再按背景对齐，共同覆盖非常低；本轮对增量问题的辨别能力不足。

按方案，固定共同层和目标权重，重采样缺少任一方法的某层就记为缺失，不把它当0、也不临时删层。各块长有效比例均不足90%，所以这12项直接比较指标不输出置信区间。它们是“无法可靠区分”，不是12项检验全部失败，也不是证明两种方法等效。本轮不为获得区间而看完结果再合并背景层。

## 5. 哪些线索值得留，哪些不能过度解读？

### 上证简单形态：局部线索比只看一次暴涨更扎实，但仍未通过

| 观察 | 上证30分钟 | 上证60分钟 |
| --- | ---: | ---: |
| 冷却样本数 | 37 | 29 |
| Q正值率 | 54.05%（20/37） | 58.62%（17/29） |
| Q中位数 | +0.061% | +0.148% |
| 不含2024年的平均Q | +0.162% | +0.285% |
| 只诊断：去掉最大赢家后平均Q | +0.100% | +0.151% |
| 2022/23/24/25/26平均Q | +0.051/+0.189/+0.443/+0.106/+0.374% | +0.079/+0.695/+0.302/-0.091/+0.546% |

上证30分钟各年原始均值都为正，但2025年仍弱于同背景基线；上证60分钟2025年本身为负。其它指数也不一致：沪深30060分钟去掉2024年后平均Q变为-0.058%，中证50030分钟整体为负。上证两组是看完六组后发现的线索，不能据此宣称预先选中的赢家。

全部逐年、逐日期删除、去掉2024年、最大赢家影响在metrics中。删除仅做敏感性，原冷却序列不补位；基线同步删除相应日期，直接比较缺失目标层就明确不可比较。

### 并非总是三买晚、简单形态早

93个原始三买中，只有24个能在前后一个交易日长度内找到一对一邻近简单信号；三买较晚13次、较早11次、同时0次。六组邻近配对数量8/1/6/2/4/3。其余69个未配对，也保留；时间邻近不代表同一个中枢或同一结构。不能把两类方法简单理解为同一个机会的早/晚版。

### 一个按时间顺序取出的例子，不挑盈利案例

上证60分钟的第一个冷却简单信号：

1. 2022-02-09 10:30收盘3465.397，高于前5日高点L=3462.123，启动候选。此时ε=11.50446，即ATR20约46.01785。
2. 后续第4根柱为2022-02-10 10:30，最低3469.139，落在[L−ε,L+ε]范围内；收盘3476.011，高于L、低于前柱3479.946，于是触发。
3. 只能以之后一根柱开盘3476.38作为入场代理，不能假想按3462.123成交。
4. 持有至下一交易日收盘，Q=-0.386%，期间MAE=-0.490%、MFE=+0.684%。形态成立仍会亏，并无确定性。

另一个明确失败是2024-01-26 15:00信号，次交易日2024-01-29入场代理2910.6072，次日终点Q=-0.936%；容差允许了小幅下影穿越，但收盘站回并没有保证后续上涨。本轮没有据此收紧容差。

## 6. 工程与分析验证

- 原A固定manifest及32个产物哈希通过，585个含初始化买卖组事件由变化账本重建；原始/冷却B3身份、R/Q/MAE/MFE逐字段等于原报告。
- 独立DuckDB日聚合/窗口公式核验40824个可评分柱的突破参考、ATR、趋势、波动；另按日终点及后续价格路径独立核验同样40824组R/Q/MAE/MFE。
- 独立批量交叉点枚举与有界窗口扫描重建1269个候选和545次触发，状态、结束原因和时间一致。每个单元2022/2024年底前缀、未来OHLC扰动均不改变此前背景和简单事件。
- 支持样本的分层基线、上涨率差/Q差，以及共同层数、两侧样本数和同权重点估计，全部经过另一条SQL聚合/连接复算。连接以单元内唯一柱序号为键，不扩行。
- 新增30项隔离测试，研究与架构护栏共236项通过；测试覆盖等号/容差、失败/到期、初始化、冷却边界、空背景/空共同层、共同权重、缺失重采样、邻近匹配与SQL复核。合成等值样本发现的浮点边界差异在实际运行前处理并补入设计，没有按实际成绩调参数。
- 计算约14.44秒，逐组六组落盘；44项计算产物哈希写入[manifest](manifest.json)。报告在计算完成后补写，不重写计算manifest。全部输入与复用源码运行前后一致。

分析可信度：**可带限制分享**。以上验证支持“实现遵守本轮规则、计算一致”，不支持“方法已经有效”。主要限制是低样本/低共同覆盖、重复使用历史、分层仍可能有残余差异、指数相关、历史行情不是逐时发布版本，以及未模拟可交易产品和费用。未发现需要改写本轮数字的未解决核验错误。

文档治理：范围仅原product研究方案与研究README；设计与本轮实现/产物对账，无新增主文档索引或产品契约。CodeGraph已用于研究依赖核验；开发准入促使设计先行，分析验证促使保留不同分母、缺失共同层和反例。未执行生产/DG检查，文档检查不代替分析正确性或策略验证。

## 7. 本轮止步于什么位置？

不采用三买或简单形态为产品规则，不运行买卖账户回测，不扫描新参数。原“比较是否存在额外价值”的实验已跑完，但其统计问题尚未得到肯定答案；不能把工程完成写成研究证明成功。

保留上证简单形态这个弱候选，并暂停继续给三买加过滤条件。是否另行研究样本设计/冷却与目标周期的关系，需要单独讨论，不能事后修改本轮主口径，更不能以此自动启动下一轮。

文件导航：各单元目录的`events.json`保存全部事件与支持标记，`candidates.json`保存候选终态，`contexts.json`/`labels.json`保存背景和收益，`pairs.json`保存邻近配对，`verification.json`保存独立核验；汇总与敏感性见[metrics.json](metrics.json)。代码入口见[研究README](../../scripts/research/index_market/README.md)。
