# S1结构验证：当前上层状态不能直接当作次日趋势过滤器

日期：2026-09-09。状态：逐柱回放、结构快照与原事件对账完成；描述性验证，不是新过滤策略回测。

**结论：本轮没有找到可直接采用的上级方向/确认条件。更明确的问题是时间尺度和状态语义：结构尾部未完成，历史中枢可能很久没有更新，不能把这些标签直接读成“现在的大势”。** 这仅针对本次固定实现、配置及样本，不是证明所有缠论方法无效。

## 1. 范围与验证方式

仍是原A的三指数×30/60分钟、2021-09-09—2026-09-08保存行情，共43560根；2021年窗口内部分仅初始化。恢复原A全部585个含初始化买卖组事件，并逐字段相等。在93个评估期原始B3触发时保存结构，其中82个属于原20交易日冷却集合。

不采用上一轮F1过滤，不只研究F1保留的71个；不更改信号、入场、预测周期或收益。Q仍是下一根完整柱开盘至下一交易日收盘的无成本指数价格代理。没有卖点、止损、费用、账户资金曲线或新的概率模型。

“上层”在这里指同一频率内部：笔→线段→更高层线段/中枢。不是30分钟配60分钟，也不是分钟配日线，程序结构层级不自动等于严格缠论走势级别。

逐根柱输入后立即将结构转换成值快照，再继续输入后续行情；收益标签在回放后才接入。不读取最后一幅全历史图来解释过去，不保留可被后续重画修改的对象引用。

## 2. 第一条可否定的想法：“要求上级已经确认”

93个原始三买的真实状态如下：

| 观察对象 | 原始93个 | 冷却82个 |
| --- | --- | --- |
| 事件归属线段 | 67下行未确认、7上行未确认、19尚无归属 | 60下行未确认、6上行未确认、16尚无归属 |
| 当前最后线段 | 75下行未确认、18上行未确认 | 67下行未确认、15上行未确认 |
| 当前更高层线段 | 44下行未确认、49上行未确认 | 37下行未确认、45上行未确认 |
| 最新高层中枢 | 72未确认、17已确认、4缺失 | 64未确认、15已确认、3缺失 |

**在原触发时点要求“事件归属线段已确认”或“当前更高层线段已确认”，保留数都为0。** 这是状态可用性的直接结论，不是做了一次零交易盈利回测；“等以后确认再买”属于另一种入场规则，本轮没有测试。

这不意味着引擎一定有bug。源码允许把末尾剩余元素暂画成未确认线段；其中60/93个事件的当前高层线段仅包含1条下级线段，明确不是已经完成的稳定结构。全部93个事件的parent引用与当前范围归属一致，没有发现悬空指针导致本轮分类错误。

“最近一个已经确认的历史线段”是另一个对象。它可以存在，但其方向描述过去一段走势，不能替代当前未完成段。比如过去确认了下跌段，后面可以正在反弹；反之亦然。

## 3. 第二条想法：“高层向上才看多”

以下是固定六组内按触发时高层方向分类的描述统计，全部高层段均未确认；不是过滤策略收益，未增加显著性检验或挑选规则。

| 指数/频率 | 高层向上：数量 / 平均Q | 高层向下：数量 / 平均Q |
| --- | ---: | ---: |
| 上证30分钟 | 10 / +0.085% | 6 / +0.030% |
| 上证60分钟 | 4 / -0.934% | 5 / -0.029% |
| 沪深30030分钟 | 9 / -0.125% | 7 / +1.431% |
| 沪深30060分钟 | 5 / +0.692% | 7 / -0.137% |
| 中证50030分钟 | 12 / +0.572% | 6 / -0.162% |
| 中证50060分钟 | 5 / -1.378% | 6 / -0.638% |

没有跨六组统一的“向上更好”。看起来支持的组也不稳：

- 沪深30060分钟去掉2024年后，上行组5例平均+0.692%，下行组4例平均+0.843%，排序反转。
- 中证50030分钟去掉2024年后，上行组8例平均-0.539%，下行组6例平均-0.162%，排序同样反转。
- 沪深30030分钟的下行组+1.431%含2024-09-26的一次大涨，不能解释成“高层下行才应该买”。这是小样本和反转行情对均值的影响。

最近确认线段方向、两中枢相对位置等其它预先固定分类，也按原始/冷却、全年/逐年/不含2024年保存，没有把最高均值的一格选作新规则。

## 4. 第三条想法：“在高层中枢上方就比较安全”

这个位置能够计算，但首先要问：这个中枢距现在有多远？

93个样本中有89个存在高层中枢。其中枢末端至信号日间隔的中位数为**84个交易日**，范围1—488日；冷却口径79个有中枢，结果相同。计算方法是SSE交易日序号之差，不是自然日。

另一个尺度证据：当前高层线段自身从起点至终点跨越0—400个交易日，中位数21日。它可能很短，也可能跨越很久，不具有固定的“次日背景”时间跨度。

最新中枢可能有意义，但“最新”不等于“最近”。其确认标志与内部线段是否确认也是不同字段；不能把内部元素都确认，直接改写成高层中枢已确认。

### 对照两个已知案例

| 当时可知信息 | 沪深30030分钟，2024-09-26 10:30 | 沪深30060分钟，2024-10-10 11:30 |
| --- | --- | --- |
| 信号收盘 | 3439.5664 | 4068.8818 |
| 事件归属线段 | 尚未形成 | 尚未形成 |
| 当前高层线段 | 下行、未确认 | 下行、未确认 |
| 最新高层中枢区间 | 3624.002—3674.609 | 3935.016—4064.362 |
| 该中枢末端 | 2024-05-20 | 2023-07-31 |
| 当前价格相对中枢 | 下方 | 上方 |
| 后续次日Q，仅用于评估 | +7.663% | -4.504% |

两例分别属于不同周期，不作为严格配对实验；它们足以说明：**“上方=安全，下方=危险”不能作为无条件判断。** 若简单要求上方，会错失前例、保留后例；若简单要求高层向上，这两例又都会被排除。

另一个反例：中证50060分钟2024-10-10大亏-6.127%，其当时当前高层线段却标为上行未确认，端点还停在2024-03-19。读取这个方向标签不等于掌握了10月的即时趋势。2026-01-30的-4.269%漏判案例，则处于高层下行、价格在历史高层中枢上方，单独一个条件无法覆盖这些不同情形。

## 5. 源码核验说明

本轮使用固定提交`429d6ed3043e27c93a003ba2b10e70a05575e1f5`，运行前后验证第三方文件哈希和干净状态，未改源码或参数。

- `KLine/KLine_List.py::cal_seg_and_zs`分别维护`seg_list`、`segseg_list`和`segzs_list`；它们不是同一对象。`cal_seg`也允许给尾部笔分配尚不存在的下一段序号。
- `Seg/SegListComm.py::collect_left_as_seg`保留未确认尾段；`Seg/Seg.py`在元素不足3个时将段标为未确认。不能因字段名含“线段”就认为结构已完成。
- `BuySellPoint/BSPointList.py::treat_bsp3_after/before`分别从后段前部、前段末尾的笔级中枢产生3a/3b。**本报告记录的高层中枢不是产生原三买的直接参考中枢。** 本轮没有追踪并重新解释每个三买的具体生成中枢，不混淆这两个问题。
- 归属线段同时按当前起止笔范围与parent引用核对，93例一致；缺失保留为缺失，没有用最后一条线段填充归属。

源码路径/全部哈希及展开配置在[manifest.json](manifest.json)中，可定位到固定第三方版本，不依赖在线文档推测实现。

## 6. 判断与后续方向

本轮不支持直接采用三个简单用法：在原触发时强求上级确认、直接以高层方向筛选、直接以相对历史高层中枢位置判断安全。其中确认条件在本批原时点不可用；另外两项没有表现出通用、稳定的区分关系，不等于证明它们在所有样本上都无效。没有验证延迟确认入场，也没有否定多周期方法。

建议停止给当前三买叠加这些高层标签。若继续，应先将背景时间尺度拉回信号附近，审计最近几笔的高低点演进，例如回落低点是否抬高、反弹是否突破前一高点，并先确认这些判断何时可知。那是下一项独立假设，本轮没有生成筛选策略或试参数。不能在已经看过的这些案例上调整到“都能解释”后，就宣称找到有效方法。
