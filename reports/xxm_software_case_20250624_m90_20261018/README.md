## 为什么仍不能决定是否要求当根DIF大于0

“首次顶钝化时要求当根DIF>0”和“要求所比较的历史DIF>0”这两种待核规则，在本图日期的90分钟计算结果相同：均在14:00产生顶钝化，之后仍有钝化。模型14:00 DIF约2.995、所比较的历史DIF约23.498，均为正；图片末端软件DIF5.585也为正。图上有钝化与两种解释都不冲突。
