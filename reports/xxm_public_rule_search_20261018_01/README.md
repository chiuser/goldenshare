# 首次顶钝化是否要求DIF大于0：公开资料查找结果

2026-10-18。依据[原方案§12.31](../../docs/product/xxm-direction-algorithm-plan-v0.1.md)和[识别LLD§25.12](../../wealth/docs/pages/index-detail/index-detail-xxm-implementation-and-low-level-design-v0.1.md)，本轮查徐小明本人文章及交易师官方说明。

**结论：仍未找到直接回答，不能据此修改首次顶钝化的计算条件。** 原来的两种解释——要求当根DIF大于0、要求所比较的历史DIF大于0——都没有在本轮得到作者或官方文字确认。也不声称只可能有这两种规则。2024/9/24—25两条输出仍是疑点，不能宣布已经判错或修正。

## 2. 两类容易混用的说法没有采用

1. [2016年12月15日直播](https://blog.sina.com.cn/s/blog_4d89b8340102x6nh.html)的9:34提到DIF不再为负，9:51再提15分钟钝化。前一句没有交代同一指标周期，后一句没有说明顶部或底部，也没有给出首次顶钝化的条件。这两句不能拼成我们需要的规则。页面发布时间为12月14日，实际直播标题是12月15日，分别记录。
2. [2018-07-31《周三操作策略》](https://www.homeway.com.cn/4128648/article108674.html)搜索摘要列出0.082和4.888，作者说的是MACD值，并在后文谈底部钝化。正文打开失败，仅存摘要中的短摘录；不将其改写成“DIF必须为负”，也不从底部推出顶部的条件。

还查了2017年8月24日直播、2021年12月20日策略、官方课程介绍和新增选股公式的说明。它们也未直接回答当前问题。逐条可读范围、日期和限制在[sources.json](sources.json)。别人的总结、改写公式、无法确认发布者身份的视频标题均未作为规则依据。

## 3. 对当前研究和代码的影响

- [既有比较](../xxm_top_zero_axis_discrimination_20261018_01/README.md)和[6/24的90分钟图](../xxm_software_case_20250624_m90_20261018/README.md)结论不变：有些普通例子两种解释都能算对，不能用它们分出哪一种正确。
- 不追加“首次顶钝化当根DIF>0”，也不追加“历史DIF>0”；不改取参照、结构消失、重新钝化和预测规则。
- 不把官网的“重复”扩大成过滤所有密集钝化；不因选股和预警相差一根而平移指标窗标记。
- 不新增软件已确认标记，不重跑全历史，不访问数据库或Lake。计算代码、参数、接口、前端和依赖都没有改动；2020年前的日线验收TODO保留。

## 4. 下一步只围绕缺少的那句话或那个例子

需要能明确区分“当根DIF”与“所比较的历史DIF”的作者说明，或者首次出现顶部钝化时、软件当根DIF小于或等于0的明确记录。普通收盘图只显示最后仍有钝化时，可能两种解释都已给出相同状态，不再要求用户反复找这种图。

若拿到明确记录，先核对指数、周期、MACD参数、首次出现时刻及软件读数，再与既有计算逐项比较，更新原方案和LLD后才讨论编码。若仍只有概括定义或不清楚的截图，这一项继续保留未确认；不为了结束研究自行选择一种算法。本轮不需要用户再找6/24、4/8的60分钟或早年视频。
