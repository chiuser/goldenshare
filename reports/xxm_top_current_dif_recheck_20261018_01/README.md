## 发现并纠正的一处核查错误

第一次运行已完成8个单元，随后把旧研究模拟事件与现版事件整条比较，因编号不同而失败，记录保留于[第一次尝试](attempt_01.json)。旧研究使用a1及f0bf6d…版本，现版为r1及533a9b…；事件／关联编号包含版本和Spec哈希，不能要求跨版相同。

未改旧预期或忽略编号。按实际代码中的编号公式，用独立hashlib分别验证旧／新版事件、原结构和重新钝化关联编号；时间、状态、类型、路径和参照全部相等。当前BASE与两候选的完整模拟事件（包括编号）也完全相同，重新钝化关联指向真实父记录。完成单元从SHA文件读回，未重复计算整轮。原因及修正见[比较方式记录](comparison_correction.json)，最后状态见[execution.json](execution.json)。

1. 将修订限定在首次TOP钝化的当根DIF资格；不对BOTTOM做对称修改，不要求已激活钝化持续保持正DIF，不改原两段历史／单根占位／价格资格和参照排序。

3. 预测需同步设计。当前`forecast_entry`提前切分价格范围，还没有为新增的当根DIF条件设置独立分界；日线舍入、分界上的包含关系和排除原因也需一起审计。`forecast_detector.clone`构造的是产品类，不能把研究子类直接喂给现预测器就声称候选预测已通过。详见[只读代码核查](forecast_readonly_audit.json)，本轮没有运行或验收预测。
