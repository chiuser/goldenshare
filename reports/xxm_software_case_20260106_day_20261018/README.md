| 原冻结候选 | 1/6输出 | 与新软件当日阳性 |

## 3 “次日约4087点消失”的独立算术核对

以已有前缀收盘独立做50位Decimal的EMA(12,26)与DEA(9)递推，再与真实`recover_projection`结果对照。1/6未取整DIF约30.0338177793、DEA12.1672089128、MACD35.7332177329，三位显示与源／图相同。下一根DIF是收盘价C的线性函数：

`DIF_next(C) = (2/13 − 2/27) × C + (11/13 × EMA12 − 25/27 × EMA26)`。
