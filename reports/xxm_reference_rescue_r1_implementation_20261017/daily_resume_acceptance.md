## 为什么2020年以后完整仍不能通过正式验收

当前`source.read_daily`的过滤只有代码`000001.SH`、完成日期上界及1000行批次游标，没有2020年下界。`assert_continuous`据实际首日／末日对照完整SSE开市日集合。因此数据库出现2017年片段后，正式来源范围就从2017年开始，而非只检2020年以后。

异常链是`IndexDetailXxmQueryService.load_entry → _load_series → source.assert_continuous`。这不是模型超时、指标字段缺失、个股停牌或2020年以来的数据仍没补齐；不通过改算法、延长预算、改预期或临时截到2020取得通过结果。
