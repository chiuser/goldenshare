## 这条确认解决了什么

结构反向后，不能把所有情况都强制改成“消失并等待”。本轮候选分两种情况：

| 当根条件 | 候选输出 | 与已有材料的关系 |
| --- | --- | --- |
| 收盘与DIF仍符合重新钝化资格 | 直接钝化，不新增绿色；后来满足条件可再次形成结构 | 与8月中旬两紫之间有黄、无绿相容 |
| 当根收盘等条件尚不满足，原参照仍可用 | 结构消失；保存参照，等待后来真正满足条件的收盘 | 与7/10讲解“结构消失、尚未出新钝化”相容 |

资格统一使用现有负柱／根数要求、**当根**收盘严格低于原参照价和最近价格门槛、负柱段最低DIF严格高于原参照DIF。真正跌破参照DIF仍优先失效。未新增日期特判、补偿、阈值或产品开关。

人工辨认确认的是静态标记顺序，没有精确游标；8/14、8/15的逐根日期来自封存行情回放，不能升级成原软件精确日期或内部执行次序已获证明。原始确认另存[software_observations.json](./software_observations.json)。
