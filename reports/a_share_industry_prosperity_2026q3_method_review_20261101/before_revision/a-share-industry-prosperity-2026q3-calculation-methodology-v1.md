## 2. 公司、行业与有效样本

1. 主键先按证券代码/报告期保证唯一，再通过可靠身份信息合并历史代码。完整公司名称仅作候选匹配；同名但报表冲突、名称缺失或身份不明不得自动合并。
2. 行业成员只取指定快照、指定层级及行业类型，关联`con_code`到证券代码，禁止跨快照或层级产生重复。未知归属单列；行业合计对全体样本的差额应可解释。
3. 上市公司名单按报告期存续资格处理，不能只保留今天`list_status='L'`的公司。新上市企业有历史报表不等于历史上已可投资。
4. 经营统计允许上市母子公司分别出现，报告其重复经济活动限制；公司身份去重不能消除母子公司合并范围重叠。
5. 定义指标有效集`S(k,t)`，同比集`S(k,t)∩S(k,t-4)`。分析收入和应收的联合关系时，两项、两期都有效才进入同一集合。
6. 零值与NULL区分。字段不适用、未披露、源未提供、版本冲突、关联失败分别记录，不统一填零。
7. 覆盖报告包括记录数、唯一代码数、身份确认公司数、有效字段数、同比有效数、预测历史完整数，以及行业内缺失。此前旧报告的10家/70%等规则不自动沿用；阈值须在试算中说明依据并冻结。
8. 覆盖审计先统计数量。本轮不计算收入权重覆盖或缺失公司的市场价值贡献，这类金额计算留在正式测算范围；本轮不因有行就宣称代表性充分。

## 3. 日期、金额和季度转换

- 研究标准季末为3/31、6/30、9/30、12/31，非标准期末另列，不混入同比序列。
- 报告期、公告日、抓取日、估值日分别保存；人民币财报以元计算、展示可换亿元，非人民币报表必须按已确认规则转换或单列。
- 利润表和现金流表为年初累计：`Q1=Q1累计；Q2=H1-Q1；Q3=9M-H1；Q4=全年-9M`。两端必须同公司、同合并范围、同币种、可比版本，缺一端则单季缺失。
- 余额是时点值，不差分为季度经营量。季度比率从季度金额重新计算，不能将累计比率相减。
- 滚动四季流量`TTM=上年全年+本年累计-上年同期累计`；本年/上年季末平均余额用于匹配TTM周转。需检查并购与重述导致的不可比。
- 源直接提供单季值时须单独标识。年报`q_dtprofit`是第四季度候选直接值，可与累计差分交叉核对；冲突不能靠任选一个或填补缺失来掩盖。直接值覆盖、差分覆盖、二者重叠及冲突分别统计。

## 4. 需求与盈利

设同一有效集中的收入为R，成本为C，合并净利润为N，归母净利润为P，扣非归母利润为D。

| 指标 | 公式与条件 |
| --- | --- |
| 行业同比 | `ΣR(t)/ΣR(t-4)-1`；分子分母同样本，基期须正 |
| 增速变化 | 本季单季同比-上季单季同比，单位百分点；另列两季共同样本结果 |
| 两年复合增速 | `(ΣR(t)/ΣR(t-8))^(1/2)-1`；两端同样本且正值 |
| 毛利率 | `(ΣR-ΣC)/ΣR`，仅适用普通经营收入与成本匹配行业 |
| 营业利润率 | `Σoperate_profit/ΣR` |
| 合并净利率 | `ΣN/ΣR` |
| 归母/扣非归母利润率 | `ΣP/ΣR`、`ΣD/ΣR`，分别命名，不能冒称合并净利率 |
| 亏损比例 | 归母利润<0公司数/归母利润有效公司数 |
| 改善比例 | 本期收入/利润/利润率高于同期的公司数/两期有效公司数 |

非金融收入优先研究`revenue`；金融收入研究`total_revenue`及分业务指标。必须检查公司类型与业务分类，不能将`revenue`为空的金融企业填零，或用`total_revenue`对所有行业随意兜底。

利润基期非正、近零或符号变化时，报告金额、利润率、扭亏/减亏/转亏/增亏。近零判断须有金额规模依据，试算前冻结；不为排名保留极端增长百分比。

利润率变化贡献使用对称分解：`Δ(R×m)=ΔR×(m1+m0)/2+Δm×(R1+R0)/2`。若分解的是毛利，就用毛利率；不得拿归母利润率分解营业利润。税费、少数股东损益和非经营项目另作桥接。

## 5. 回款、库存、营运资金

| 指标 | 公式/限制 |
| --- | --- |
| 经营现金流率 | `Σn_cashflow_act/ΣR` |
| 销售收现/收入 | `Σc_fr_sale_sg/ΣR`；含税等会计范围差异，不能直接称回款百分比 |
| 利润现金转化 | `ΣOCF/ΣN`，仅利润为正时；同时展示金额，金融不通用 |
| 应收周转天数 | `平均应收/同期间收入×期间天数`；累计9M以年初/期末平均、270天；单季以季初/季末平均、90天 |
| 存货周转天数 | `平均存货/同期间营业成本×期间天数`；不能把全部存货称为产成品 |
| 应收与收入增速差 | 同一批公司同期应收同比-收入同比，单位百分点 |
| 简化经营资金占用 | 应收账款+存货-应付账款；仅为局部观察，不命名为完整净营运资金 |
| 额外资金占用 | `Δ简化经营资金占用/Δ收入`，仅收入增量正且非近零时，展示每增加100元收入的占用 |
| 应计利润观察 | `(合并净利润-OCF)/平均总资产`，同期间且样本匹配，增长及税费时点可能影响解释 |

默认360天惯例，累计3/6/9/12个月对应90/180/270/360天，不能与实际日数混用。TTM使用360天、对应期末与上年同期余额均值。合同资产、合同负债、应收票据、应收款项融资单列；源字段如存在包含关系，未核实前不相加。

库存周期四象限只提出假设：收入升/库存升可能补库存，收入降/库存升可能积压；价格、周转、订单或实物量须进一步验证。不能由货币金额直接证明数量周期。

## 6. 资本效率和财务风险

- 资本开支观察使用`c_pay_acq_const_fiolta`，其范围包括固定、无形及其他长期资产，不代表全部投资，也不包含所有并购。
- `OCF-上述资本开支`命名为该口径的现金结余，不冒称严格FCFF；不直接使用源`free_cashflow`而不核对定义。
- 合并ROE=`N/平均含少数股东权益`；归母ROE=`P/平均归母权益`。杜邦分解须保持利润、权益和合并范围一致；亏损/负权益单列。
- 合并杜邦：`N/R × R/平均总资产 × 平均总资产/平均合并权益`。TTM流量与对应四季余额匹配。
- ROIC需定义税后经营利润、投入资本、现金扣除、租赁和税率口径；源`roic`仅在定义及覆盖核验后使用，不用合并ROE代替。
- 杠杆同时观察负债/资产、可识别有息债务、短期到期压力及现金。应付账款不等于有息债务，资产负债率不等于违约概率。
- 金融专项指标如缺少资产质量、息差、偿付能力或可比保险准则，明确限制该行业结论，不拿普通企业比率替代。

## 7. 行业规模、广度和趋势标签

行业规模用金额合计，典型公司用中位数，改善范围用公司比例。龙头按基期收入排序，观察前3家公司贡献及剔除后结果；不是按本期表现挑选龙头。行业净增量接近零时不用不稳定贡献百分比，改报金额。

事实表现用收入和利润增减对应“增收增利、增收不增利、减收增利、双降”，金额不变和缺失单列。

变化方向结合需求、利润率、广度和现金。第一次方向改变称边际变化，连续两季才讨论持续改善；信号矛盾保留分化结论。具体容差由数据精度和历史波动的试算结果提出后冻结，不继承旧方案的任意百分点阈值。

## 8. 第四季度与全年预测算法

### 8.1 候选基准

对每个公司/可比行业分别预测：

1. 季节简单基准：`Q4hat(2026)=Q4(2025)`。
2. 近期同比延续：`Rhat_Q4=R_2025Q4×(1+g_2026Q3)`；可比Q3有效且正基期。利润不机械照搬收入增速。
3. 历史季节比：历史年`k=R_Q4/R_9M`，在可比有效年份取稳健中心，`Rhat_Q4=k×R_2026_9M`；至少3个有效历史年才作为候选，5年以上才讨论较稳定季节性。异常年分别展示纳入/排除的敏感性，不按预测效果事后删年。
4. 经营因素：收入预测×适配的季度利润率，再处理费用、非经常性损益和已知减值；扣非与归母分开，正常年末费用不得重复扣除。OCF采用自身历史季节及回款/营运资金情景。

使用不少于3年/5年的条件是本研究候选模型的资格规则，不保证统计可靠。行业企业众多不能增加行业自身年度独立观测数。无足够历史时使用简单基准和情景，不强行拟合多变量宏观回归。

### 8.2 检验与选择

在历史年份的三季报信息截止点逐年向前检验；每次只用此前可用数据训练。分别报告Q4、全年MAE、相对简单基准误差、偏差和方向命中。利润可能为零/负，不能依赖MAPE；金额误差可按预先固定的历史收入规模归一化。

模型选择使用更早训练/验证期，保留最近完整年度作未参与选择的检验；候选方法接近时保留简单模型或训练期确定的组合，不按最终2026结果选模型。预测区间的覆盖评估须按行业年度误差考虑相关性，不能把数千家公司当成数千个独立宏观年份。

已披露业绩预告/快报作为独立约束，说明来源及截止日；与报表重复的信息不能二次计入。上下行情景不预置发生概率，历史不足时不发布统计置信区间。

## 9. 估值和投资价值排序

1. 先验证金额单位：财报元、`total_mv/circ_mv`源定义为万元、`total_share`万股；执行时核对生产字段及本地源文档，估值前统一成元及股。
2. 行业预测PE=`同一公司集合的可比总市值/预测全年归母净利润`，不是个股PE平均。亏损公司合计口径与仅盈利公司口径分列，净利润合计非正时不报普通PE。
3. A/H、B股等股本与定价范围必须匹配全公司利润。缺其他类别价格时可明确采用“A股价格折算全股本”的情景估值，但不能称真实全公司市场价值；身份重复及上市子公司需单独揭示。
4. PB匹配归母账面权益，负权益单列；金融需与可持续ROE、资产质量共同分析。周期行业以可比正常周期利润验证，历史区间不完整时不宣称周期低估。
5. 历史分位使用同一方法重算并注明样本变化；仅有若干年末/十月末截面不能称日频历史估值分位。当前最新修订盈利也不能替代历史已知盈利。
6. 分红指标先核对`dv_ttm`定义和单位，实际现金分红与未来股息预测分开；不将已除息现金重复计入未来回报。
7. 初始四个维度各25%：估值吸引力、未来盈利、经营质量、下行风险。先在适用同类行业中比较，分项明细、方向及取值规则须在试算后冻结，当前不具备自动出榜条件。
8. 维度使用的指标应尽量避免重复；跨行业结构差异、负值、极值及缺失须有明确处理。缺少维度不自动重分权重，标记“暂不综合排序”。
9. 各维度权重在15%—35%间、总和100%的预先规定组合做名次敏感性；同时改变利润预测和目标估值假设。报告稳健名次范围，不把得分转成收益概率。
10. 6—12个月估值情景如计算回报，使用届时适用的盈利口径与估值倍数、期间可获得分红、摊薄和币种，逐项说明；不只拿2026预测PE直接推出2027收益。
