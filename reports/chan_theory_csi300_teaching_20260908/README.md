# 沪深300缠论教学案例：执行口径

本目录是教学附件，不是交易策略、预测验证或产品能力。研究日期：2026-09-08。

## 数据与执行边界

- 只读正式 Lake 的 `silver/index_daily`，对象 `000300.SH`。
- 冻结时间窗口：2024-01-01 至 2025-12-31；2024 年作前置数据，2025 年作教学展示。
- 预检：485 个日分区文件、26,058,635 字节；上限 600 个文件、32 MiB 源文件、600 行过滤结果。
- DuckDB 一次投影读取 OHLC；1 GiB 内存、4 线程、禁止磁盘 spill；查询超时 30 秒。
- 内存逐日追加计算；运行预算 60 秒，不访问任何行情 API，不运行 Dagster，不写数据库或 Lake。
- 使用现存历史文件，未取得当年的数据修订版本；仅证明截断输入条件下的结构回放，不是严格 point-in-time 预测检验。
- 计算源为 Vespa314/chan.py，固定提交 `429d6ed3043e27c93a003ba2b10e70a05575e1f5`；不安装其依赖，不修改其代码。
- 教学配置将 `divergence_rate` 设为 1.0，使程序比较力度；这是解释性约定，不是调参所得优势。其他重要配置写入 manifest。

## 图表约定

- 交付形式：Markdown 教材内的静态 PNG，不发布网站。
- 问题：从当时已知的日线，如何生成结构，以及末端结构如何变化？
- 粒度与单位：每根蜡烛是一交易日日线，纵轴指数点；横轴等距交易日，不是等距自然日。
- 价格轴不从零开始；用于辨认局部结构，不用于表现累计收益。
- 原始 OHLC 用细蜡烛；笔用蓝色实线或橙色虚线区分当帧 `is_sure` 状态，并辅以文字。不把实线解释为永久不变。
- 中枢只称“该实现的日 K 笔级中枢”，不冒充严格递归级别认定。
- 案例按结构事件选择，不按随后收益选择；保留未完成结构和撤换记录。
- 验证：数据完整性、前缀重放一致性、数字与图对应、图片实际渲染检查。均不等于理论正确性或投资有效性验证。

## 复现

使用现有 Python 3.12+ 和 Pillow、现有 DuckDB CLI，以及自行准备的上述固定提交源码目录。不要为复现自动安装或升级环境。

```bash
python3 -B reports/chan_theory_csi300_teaching_20260908/build_cases.py --chan-source /absolute/path/to/chan.py
```

脚本仅写本目录的生成附件；输入源路径、文件大小与校验值记录在 `manifest.json`。`source.json` 是本次读取的指数 OHLC 快照，`frames.json` 是每个收盘时点的结构快照，`evidence.json` 汇总教材所用事件。
