## 需避免的误判

创业板模型3/11—12红柱段最高收盘3349.5287，在3/11出现，超过2/26单根历史3344.9823；3/12当根收3317.5225却低于这个历史价。当前选择器用段内累计最高收盘，因此够格；如果软件另有当根价格条件，也可能导致3/12不标，不能仅凭无字就确认零轴条件。模型更早段价3388.3407尚未破，虽DIF58.457更强也不合格，实际所用为2/26的12.380；不把模型参照当软件已知参照。

深成指4/13当根收14407.8639超过3/12单根历史14374.8711，价资格不依赖上一日累计高点；但DIF-0.002极近0。软件若显示正DIF或无法读清符号，该根不能作二选一证据，应看前后图／实际软件数值，不改源凑符号。

深成指当根条件到4/14才激活。届时价格14639.9522已超过更早2/26—3/2段14503.7865，选择DIF124.162；历史条件在4/13已锁3/12的59.454。4/15 DIF91.217介于59.454和124.162之间，所以前者取消、后者维持；4/16 DIF140.087超过两者，另一条件才取消。该后果的数值余量大于4/13的微小负值，但其他参照选择规则也可能产生不同后果，仍需图核全过程，不独立证明唯一算法。

两模型所用最近历史段在首次日都是单根，原软件实际取法、版本／读数仍须原图核实；已被旧证据反对的统一两根历史过滤不因这里又成为单根而重新启用。本步只提供可证伪候选，不新增参数或实现候选规则。
