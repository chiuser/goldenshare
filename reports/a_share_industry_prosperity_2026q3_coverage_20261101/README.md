# 财务指标重同步后的数据审计与剩余需求

核验时间：2026-11-01 10:16—10:22，Asia/Shanghai。环境：Prod，只读。研究范围：2024Q1—2026Q3；沿用已发布东财固定层级，使用最新公司归属。只检查管理员保留的研究内容，不将已取消指标列为缺口。

方法及权限边界见[本轮范围](00_scope.md)，研究计算依据见[计算口径](/Users/congming/github/goldenshare/docs/product/a-share-industry-prosperity-2026q3-calculation-methodology-v1.md)。本文不表示已完成行业景气、全年预测或投资价值测算。

## 1. 结论

2024年前三季财务指标的主要历史缺口已补上，可以恢复扣非利润的跨年研究及第四季度累计差分输入。当前最明确的新增数据需求是2026Q3最新公告的财务指标：样本内仍缺191个累计扣非，已用TushareMCP证实至少3家源端已能取得、Prod尚无对应记录。

行业一级、二级所需归属可由现有数据完整形成，不需要补历史分类或批量回填成员；当前基础估值在剔除管理员指定的6个代码后全部有效。基础财报和固定资产已具备分析条件，缺报及少量数值版本冲突应单列，不需要先启动大规模整理。

## 2. 样本及比较方式

- 当前股票名单按10/30存续、状态L/P、排除B股前缀，再剔除管理员明确的6个代码，得到5,571个研究代码。
- 中芯国际仍保留在总体缺报说明中，按管理员提供的11月更新安排标为待披露/待更新，不填零、不当成需修复的同步遗漏。本轮未独立核对其公告日程。
- 全库代码数与样本数分别呈现。历史数据可能含旧代码、已退市公司和新上市公司的上市前报表，不能将全库去重代码数视为当时上市公司的覆盖率。
- 10/31旧审计的参考样本为9月末5,572个代码。本轮样本已变，不能将旧193个缺扣非与当前191个直接解释成补齐2家公司；全库2026Q3非空数量实际上未变。

### 4.3 基础三表缺报

## 5. 全年预测输入与少量一致性问题

严格只使用2024、2025两个第四季度，在当前样本内：

| --- | ---: |
| 收入 | 5,399 |
| 归母利润 | 5,400 |
| 经营现金流 | 5,388 |
| 累计扣非可差分出Q4 | 5,418 |
| 上述四项同时齐全 | 5,376 |

因此，扣非历史已具备纳入基础预测研究的条件，不再维持“2024前三季几乎不可用”的旧结论。两个年度只能用于简单参考和情景，不能宣称稳定季节规律。

尚有两类小范围问题：

1. 直接Q4扣非与全年减9M差额超过1元：2024年10个、2025年11个代码/年份。重叠比较分别为5,420和5,499个，差异样本数量很少，但需核对公告版本和项目含义；不能自行挑选有利结果。10/31旧审计的13个是旧覆盖/旧样本，不与本次21个直接比较好坏。当前取20个身份和公告日期样本供定位，未导出全市场金额。
2. 更新标识优先规则选到扣非NULL，但其他版本有值：2024H1两例、2024Q3一例，涉及920038.BJ和920165.BJ。当前未修改既定版本规则或用其他版本自动填值。正式研究前可只核对这几个代码/报告期。

这两项属于已有数据版本/口径核验，不是要求大规模补历史。

## 6. 行业数据已足够本次一级、二级研究

固定表`core_serving.wealth_sector_hierarchy`生产版本仍为`eastmoney_dc_industry_hierarchy.cn_a.v1`，31/128/337个节点，完整。

当前5,571个代码，在10/30直接成分记录中的一级/二级/三级覆盖分别5,555/5,554/5,567。进一步核对发现：

- 5,567个有三级归属的代码，沿固定树向上都能唯一找到一级和二级，没有上级冲突。
- 直接一级缺失的16个、直接二级缺失的17个，都在这批三级可上溯代码中。
- 其他4个代码（南方精工、泰嘉股份、华锐精密、长鹰硬科）虽缺三级，但各自已经有唯一的直接一级和二级归属。
- 直接记录存在时，与三级沿固定树得到的一级/二级没有不一致。

因此，在研究查询中使用已有直接归属与固定树上溯结果，可以覆盖全部5,571个代码：一级5,555+16，二级5,554+17。无需退回10/29快照，也无需补四家三级数据，因为本报告只分析一级与二级。

这里只证明数据关系闭合、可用，不声称已审计所有公司现实业务归属的正确性。没有写入或补配`dc_member`，后续汇总保留来源层级标记并防止同公司重复计入。

## 7. 其他保留数据

### 基础估值

剔除指定6个代码后，10/30的5,571个代码全部有正的价格、市值和总股本；PB 5,512个、PE TTM 3,867个、PS TTM 5,568个、TTM股息率3,736个非空。

基础估值可直接研究，不需要追加当日估值补齐。亏损公司PE为空、负权益和分红资格等情况应分别处理，不能把所有NULL当缺数，也不能填零后排名。股息率仅作为有有效资料公司的补充。

### 固定资产及营运数据

样本内2026Q3：固定资产合计、总资产/负债/归母权益输入均有5,566个，应收账款5,465个、存货5,416个、应付账款5,471个、经营现金流5,566个、指定长期资产资本开支5,559个。

固定资产合计`fix_assets_total`保留；2024以来各季已有较广覆盖。对贵州茅台、工业富联、中国建筑的三个9M报告期做了9条有界检查：合计字段均存在，2026Q3旧`fix_assets`均为空，2024/2025同两字段非空且相等。此样本支持持续使用合计字段，但不证明所有公司所有年份项目完全一致，缺失按指标有效样本处理，不拼接旧新字段。

这些项目不要求新增数据集。营运项目对不适用行业不套用；2024平均余额需要更早数据时不计算，完整同比从2025开始，不扩展旧年份。

## 8. 仍需要什么，以及不需要先做什么

| 类别 | 具体事项 | 是否为新数据需求 |
| --- | --- | --- |
| 首要 | `fina_indicator`最新2026Q3，优先核对10/31公告批次；源端至少3家已证实可取 | 是，有限的新公告窗口，非全历史重拉 |
| 已有缺报 | 5个基础财报缺报对象；中芯按管理员说明待更新，其余4家保留缺失说明 | 不自动转补录任务；先限定可比样本 |
| 少量核验 | 21个Q4差异、3个版本选择缺值单元 | 使用已有数据核验，不批量整理 |
| 行业与估值 | 现有固定树/成分可闭合一级二级；已批准排除后基础估值齐全 | 不需要新增数据或修库 |
| 固定资产等 | 按同字段、同期间及共同有效样本计算 | 不需要先补齐全部NULL |
| 宏观佐证 | 待重点行业确定后，少量匹配的PPI、产销量、工业增加值或出口资料 | 可选公开资料，不是先行入库或模型任务 |

建议先补最新财务指标公告批次并重计覆盖，然后完成这些有限核验即可进入正式计算设计。若191个剩余缺口中仍有无法获取的数据，就明确其公司和行业影响，不默认扩成数据治理工程。本轮未算缺失金额权重，正式行业结果仍需展示有效样本范围。
