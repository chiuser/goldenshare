# 退市股票周线源可获取性抽样

2026-10-02 实测结论：抽查的五只退市股票，在当前 Prod 使用的 stk_weekly_monthly 和 stk_week_month_adj 中均为空，但在 Tushare 的 weekly 接口中均有历史周线。不能据此认定“Tushare 没有退市股票数据”，也不能直接将它们归为可通过现行任务补齐的缺口。

管理员口径：本周暂不处理；若源端没有历史，不列为建议补齐项。本轮据实际可获取性重新区分“物理覆盖差异”和“可执行补齐任务”，不修改物理审计原始事实，不用五只股票推断全部退市股票。

## 样本结果

| 股票 | 退市日 | 当前未复权接口 | 当前复权接口 | weekly 历史行数 | 对应原缺失周数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 000005.SZ 星源 | 2024-04-26 | 0 | 0 | 1,488 | 656 |
| 000961.SZ 中南 | 2024-07-11 | 0 | 0 | 1,179 | 732 |
| 002089.SZ 新海 | 2024-04-18 | 0 | 0 | 831 | 674 |
| 300090.SZ 盛运 | 2020-08-25 | 0 | 0 | 473 | 473 |
| 600090.SH 济堂 | 2022-07-07 | 0 | 0 | 1,193 | 597 |

当前两个接口只传 freq=week、ts_code，不传日期或 fields，查询对象历史；全部返回成功空数组，无接口报错。对照 300114.SZ 同样请求，各返回 726 条，证明本轮对象历史查询可以正常返回数据。

weekly 只传 ts_code，并显式请求 ts_code/trade_date/close，五个样本全部返回数据，均未触及 6,000 行上限；对照 000001.SZ 返回 1,767 条。样本原缺失周数来自最新全历史 Raw 未复权覆盖审计，weekly 总行数还含 2010 年之前的历史，不等同于待补齐行数。

把 weekly.trade_date 投影到同一个 ISO 周的周五，仅用于审计比较，五个样本分别覆盖全部 656、732、674、473、597 个原缺失周，合计 3,132 周。此检查证明这些历史周期在备用接口有记录，没有核对整条 OHLC，也没有进行任何字段转换或生产写入。

## 清单处理

这五只股票不列入“现行接口可直接补齐任务”，单独标记为：当前接口不可回补，备用 weekly 有历史，待源适配评估。不能标成源端完全不可获取，也不能删除历史覆盖差异的原始证据。

今后已验证在所查源端无数据的记录，单列“已查接口源不可获取”，不混入建议回补任务；未验证股票则列“源可获取性待查”，不直接宣称全量可补或全量无源。本轮五只样本均有备用源，尚没有证明这些股票在 Tushare 全部接口都没有历史。

weekly 的日期是每周最后交易日；现行两个周期接口和 Prod 周线数据集使用自然周五键。不能直接把 weekly 返回日期按原字段灌入同一数据集。当前验证也只证明备用接口这批历史记录可读，没有验收前后复权恢复方式；不能据此宣称复权缺口同样可以直接补齐。是否使用它恢复 Prod 历史需另行完成源语义、数值、日期归一化及数据集契约评估，本轮没有变更现行数据源。

## 证据与执行

- stock_week_delisted_source_probe_20261002.json：12 次当前接口对象查询（五只样本加一个对照），6 次 weekly 查询（五只样本加一个对照）。
- stock_week_delisted_source_availability_20261002.csv：五只样本×三个接口，15 行响应数量和日期范围。
- stock_week_delisted_sample_classification_20261002.csv：五只样本的分类及原缺失周期对齐结果。

沿用 tushare-contract-validation 技能，读取当前 market_equity.py 周线 source/date_model、request_builders.py 的过滤/日期参数语义，以及本地源文档 0336、0365、0144。现行两数据集分别绑定 stk_weekly_monthly 和 stk_week_month_adj；weekly 是本轮额外读取的备用接口，不是现行写入链路。

本轮使用 Tushare MCP 只读查询；上市状态、退市日和物理缺失周来自刚完成的 Prod 只读审计快照。没有新增 DB 查询、任务或数据库写入，没有改应用代码、数据集契约、配置、架构边界和依赖矩阵，没有提交或推送 Git。CSV/JSON 解析、成功响应校验、对象对照和日期集合检查通过。
