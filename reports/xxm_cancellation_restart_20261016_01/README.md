# 真正钝化失效后是否必须先红后绿：第一项研究

日期：2026-10-16。上证日线、60／90／120分钟；依据当前 a1 内核、已冻结完整来源和用户此前给的原图／讲稿。仅研究，不修改产品。

**结论：不能增加“任何一次底钝化消失后，都必须先红柱、再两根绿柱”的统一门禁。** 当前内核确有反例，而既有2026-08-03日线原图已经提供一处相应的软件观察。原参照失效与整个可用参照池失效必须分开；前者允许另一个旧参照随后取得资格，后者在当前连续绿柱段内无法恢复。该结论不等于已证明原软件所有选峰／切换公式。

## 3 为什么8/6讲稿仍有道理，但不能无条件泛化

原[8/6讲稿](../xxm_software_indicator_crosscheck_20261015/sources/20240806_user_transcript.txt)9:04—9:13说钝化消失后，要反弹有红柱、再下出两根绿柱并创新低。原ASR有错字，未独立核听；这是市场情境说明，并没有给出“即使另一个更低DIF参照尚可用也禁止重启”的完整公式。

截至2024-08-06收盘，当前模型四周期活动参照恰好都是各自池中最低DIF：日线-31.670、60分钟-21.461599、90分钟-22.116415、120分钟-22.869134。若这些最低参照也被段DIF跌破，池内其他参照同样不能成立。这与作者当时说短期没有新钝化的情境相容；四周期源上下文已保存在各账本`suppliedEvidenceContexts`。**这是解释讲稿的模型推论，不是确认作者软件选中的隐藏参照；原8/6没有60分钟截图，不能借此验收60分钟软件结果。**

代码层有一个可证明的局部性质：同一连续绿柱段内，`wave.dif`记录段最低DIF，只能不变或降低，历史池不会变化。若某时`wave.dif <= min(pool.dif)`，之后就不可能满足任一候选要求的`wave.dif > reference.dif`。这只证明当前绿柱段内不能重新钝化；**零柱也会结束当前段，不能借该证明推出跨零柱后必须出现红柱**。冻结真实样本未出现以零柱替代红柱的重启；精确零柱规则留作独立待核项。

## 4 对产品和技术面预测的处理

- 保持当前`step`的真实CANCEL优先清空活动参照、后来按最近两段及最强合格参照重新选择；不加全局冷却锁，不复活已突破的旧参照。
- A组结构消失后的固定参照等待继续保持原语义，与本项换参照首次激活分开。
- 技术面克隆同一个内核：原钝化的失效价只对应原参照；失效后是否有新钝化，要重新判断其他参照，不能一律输出“必须等红柱”或复用旧结构确认条件。
- 现有首次激活、失效、预测、DTO及页面均不改。额外展示参照耗尽／重选解释若以后要做，须另有页面与合同方案，本轮不新增功能。
