# 同段重新钝化：时序与价格资格的第二轮核查

日期：2026-10-16。用户授权继续研究，沿用[第一轮](../xxm_cancellation_restart_20261016_01/README.md)的16例及同一a1内核。产品算法、接口、页面和参数均未修改。

## 1 这次比上一轮多确定了什么

前轮“8次在取消时另一参照已取得资格”只能描述取消那一刻。本轮从每例原绿柱段起点逐根回溯，记录另一参照**首次**合格时点，得到：

| 周期 | 取消后才合格 | 与取消同根首次合格 | 取消前已合格 |
| --- | ---: | ---: | ---: |
| 日线 | 1 | 0 | 0 |
| 60分钟 | 4 | 3 | 1 |
| 90分钟 | 0 | 2 | 1 |
| 120分钟 | 3 | 1 | 0 |
| 合计 | 8 | 6 | 2 |

“首次合格”是按照当前价格／DIF工作假设计算的事后诊断，**不是软件实际切换时刻**，也不是预测成功率。每条诊断沿用完整前缀真实状态，没有用后来走势修改原事件。详见[日线](run_01/details_day.json)、[60分钟](run_01/details_m60.json)、[90分钟](run_01/details_m90.json)、[120分钟](run_01/details_m120.json)。

两例“提前合格但原参照仍保留”均在2018年12月18—19日的60／90分钟，超出用户此前寻找视频的2024年9月至2026年9月范围，**不要求另找旧年份素材**。它们只证明当前代码确有锁定路径。2025-12-16的90分钟属于“同根竞争”，即使补到此图，也只能先辨认取消／重选的优先次序，不能单凭它证明软件在所有活动期间一直锁定。

所有精确值均来自本系统，90分钟原软件分桶／隐藏参照仍未在该日核齐。新参照来自11/14—11/25；原参照来自12/5单根负柱。历史池、两根、严格比较与MAIN_SPEC保持，不修改源、EMA或精度来贴合结论。

若输入／参照按本表，三种处理顺序都能得到收盘有钝化，却有不同中间标记：

| 待区分的处理顺序 | 11:00柱应看到什么 | 14:00柱应看到什么 |
| --- | --- | --- |
| 当前工作模型：先取消，下一根才可新激活 | 原钝化消失 | 新钝化 |
| 先切换为较低DIF参照，旧钝化延续 | 没有该次消失 | 没有该次新激活；状态仍钝化 |
| 同柱先取消、再激活 | 同柱有消失和新钝化 | 没有该次新激活；状态仍钝化 |

这张表是条件性可观察分歧，不是另跑一个在线候选引擎，更不是已确认原软件采取其中之一。仅“当天收盘有钝化”不能排除任一项。

## 3 同一例还暴露了价格资格的独立待核项

16例中有15例新DULL当根close仍低于新参照与最近价门槛；只有上述90分钟12/16 14:00，**本根收盘3826.3425已经高于新参照价3823.2960，段最低收盘3821.7300却仍低于它**。

当前普通首次激活用的是段最低收盘，因此会新DULL；若改成必须本根收盘创新低，在相同输入／参照下14:00与15:00均不能新激活。A组结构消失后的固定参照重入按已确认设计使用本根收盘，不能据此把普通首次选峰也擅自改为相同口径。

如果未来图能清晰显示11:00绿色、14:00新黄色，且该日90分钟分桶和参照价核对成功，它将同时支持“先取消下一根重选”及“普通首次激活允许沿用段内已知低收盘”。如果黄色就在11:00，或者根本没有绿色，则支持其他时序。**不能只凭收盘状态反推上述细节，也不能用本文精确模型参照冒充软件实际参照。**

## 4 新找到的一手文字能证明多少

作者[12/16盘中直播](https://blog.sina.com.cn/s/blog_4d89b8340103021s.html)13:06、13:55谈到钝化及下跌速度，没有明确给出90分钟11:00的已完成事件。[当日午评](https://blog.sina.com.cn/s/blog_4d89b8340103021u.html)仅泛指分钟线有底钝化。[盘后策略](https://blog.sina.com.cn/s/blog_4d89b8340103021w.html)明确列出60／90／120分钟都有新底钝化，补强收盘状态，却没有定位绿色和黄色分别属于哪根。

因此13:55的实时判断不能拿来判定14:00尚未完成柱，也不能强行归到已完成11:00。原12/16视频全文已经取得，本轮重新读了相应上下文，依旧只支持收盘状态；未重复调用历史上返回额度不足的字幕服务。盘中页发布时间是12/15下午、正文业务日是12/16，两者分开保存。[来源与缺失记录](primary_sources.json)只保留有界摘要及原链接，没有复制整篇文章。

## 5 当前结论与后续范围

1. 统一“真正取消后必须先红再绿”限制依然不采纳；已有日线反例继续有效。
2. 当前内核的规则已经可逐根解释并复现；**原软件同根取消／重选顺序、普通激活是否用段内低收盘，尚不能唯一识别**。本轮未发现足以修改产品的新增独立软件证据。
3. 早期主研究§5.31已经把12/16的90分钟补图请求暂停。上一轮把它列回“优先”没有同时带出这条历史边界；本轮恢复暂停，**不再要求用户重复找图**。若以后自然获得这张图，先核数值／分桶再辨中间标记；这不是当前开发阻塞或强制找图任务。
4. 本轮没有能替代此图的2024—2026年新节点；不扩大标的／年份或随意多跑参数来宣称原软件已明确。其他研究项另行安排，不能用本项有限结论替它们背书。
