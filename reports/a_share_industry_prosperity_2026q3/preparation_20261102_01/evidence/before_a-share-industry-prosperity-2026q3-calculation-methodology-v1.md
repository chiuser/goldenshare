### 1.3 每个指标用什么样本

- `U_h`：行业h的固定当前候选代码集合。`S(k,t)`：其中指标k在期间t有效的集合。
- 同比统一取两期交集；连续趋势的本季、上季及两期同期共用同一交集。单季差分涉及的两端也必须完整。不能把两个不同集合的合计相除。
- 收入与应收、利润与现金等联合判断只用所涉字段、期间的共同有效集合。单指标事实表允许各自有效集，但不能将它们直接拼成联合比率。
- 2024—2026季度趋势同时提供每期有效样本数和同比共同样本；若展示全11期固定面板，另标其公司数/覆盖，不替换为“全市场”。

## 3. 金额、日期与基础变量

1. 原始财报金额统一人民币元，金额保留源精度，派生比率使用28位有效数字的十进制运算，仅在展示时舍入；展示换亿元。`total_mv`万元乘10,000转元，`total_share`万股乘10,000转股，股价为元。百分数与百分点分别标识，不把`dv_ttm`百分数直接当小数。
2. 股票交易币种不能单独证明财报计价币种。外币、单位或合并范围不能确认的公司/期末单列，不凭空假定汇率；本轮不新增汇率历史工程。事实原值可附注，不能混入人民币金额合计或评分。
3. 按东财一级“银行/非银金融”区分本方案的金融范围，不以comp_type单独决定研究行业。非金融取`R=revenue`，不以`total_revenue`任意兜底；金融旁表用`total_revenue`。comp_type用于核对公司报表类型与字段适用性，金融控股公司comp_type为1不意味着应转入非金融。金融旁表及不参与预测/综合榜仍按§8提案状态，不安排金融专项。
4. `P=n_income_attr_p`，`N=n_income`，`D=profit_dedt`，`C=n_cashflow_act`，`E=total_hldr_eqy_exc_min_int`。D暂称“扣非利润”；用至少3家公司公告核对确属归母口径后才标“扣非归母”。若语义不一致，停止D相关预测/评分并说明，不用其他字段悄悄替换；R/P等事实可继续。
5. 累计流量转单季：`Q1=Q1；Q2=H1−Q1；Q3=9M−H1；Q4=FY−9M`。每端同代码、同币种、同合并范围、可比版本。季度比率由季度金额重算，不能相减累计比率。
6. 余额只取期末值；平均余额为对应期初/期末简单平均，不能把余额加成全年流量。`TTM=FY2025+9M2026−9M2025`；TTM平均余额为2025Q3/2026Q3均值。其他季度按相同关系平移。
7. `q_dtprofit`只用于交叉核对，不作为默认填补值。当前已定位2024/2025直接Q4与累计差分超过1元的10/13个代码年份，以及3个优先版本NULL单元，后续只作有限核验；未解释的差异影响相关D单季有效性，不删掉整家公司全部事实，也不改源库。
8. 金额差异1元只是版本/算术核验容差，不是“经济上没有变化”的阈值。并购、会计变更或重述无法确认可比时，相关比较标NA，保留原因，不做主观金额调整。

## 4. 事实指标及可复算标签

### 4.1 需求、盈利和广度

所有Σ均在该行注明的同一集合上计算。行业比率从金额加总重算，不平均个股比率。

| 指标 | 公式/判定 |
| --- | --- |
| 收入同比 | `ΣR_t/ΣR_(t−4)−1`，基期收入为正 |
| 单季增速变化 | 当前单季收入同比减上季单季收入同比，四端共同样本，单位百分点 |
| 两年复合增速 | `(ΣR_t/ΣR_(t−8))^(1/2)−1`，正值且可比；2026适用 |
| 毛利率、营业利润率 | `(ΣR−Σoper_cost)/ΣR`；`Σoperate_profit/ΣR`，收入/成本匹配 |
| 合并、归母、扣非利润率 | 分别`ΣN/ΣR`、`ΣP/ΣR`、`ΣD/ΣR`，不可互称 |
| 亏损比例 | P<0公司数/P有效公司数；D另列，缺报不计亏损 |
| 改善范围 | 同比D金额增加公司数/两期D共同有效公司数；收入、利润率改善另列 |
| 典型公司 | 同比增长或利润率变化的公司中位数；分母非正或近零的公司不强给利润增速 |

P或D基期非正、符号变化，或`abs(基期利润)/基期收入<0.1%`时，利润增速留空，展示增减金额、利润率和扭亏/减亏/转亏/增亏。0.1%为本次拟议的近零保护参数，不用它删掉利润金额或亏损企业。

当前表现：在R/P两期共同集上，以收入与归母利润金额的同比正负对应增收增利、增收不增利、减收增利、收入利润双降。相等标“持平”，缺失标“资料不足”；D的同口径结果并排显示，若相反说明利润质量，不能把P/D混成一个标签。

趋势提案：每季用同样本计算三个方向信号：①单季收入同比较上季上升/下降；②单季D利润率同比上升/下降；③D同比改善公司比例较上季上升/下降。每项按原始未舍入值记+1/0/−1；至少两项+1则本季方向+，至少两项−1则方向−，其余为0。当前及上季都是+称“景气上升”；当前+而上季不是+称“边际改善”；两个−称“景气下降”；当前−而上季不是−称“边际转弱”；当前0称“震荡分化”。缺所需信号则“资料不足”。起始季度不足以计算的不强贴标签。

标签只是方向描述，必须同时展示实际百分点/金额，微小变化不据此声称统计显著，也不直接进入投资评分。现金质量另作提示，避免重复改变同一标签。

判断连续两季时，在覆盖t、t−1、t−2及各自上年同期、所涉季度差分端点的共同样本上重算两个方向，不直接拼接不同集合生成的旧标签。缺2023资料会使早期趋势标签不可得，不能为贴标签扩大日期范围。

### 4.2 现金、库存与资本

| 指标 | 公式/限制 |
| --- | --- |
| 经营现金流率 | `ΣC/ΣR`，同期间 |
| 销售收现/收入 | `Σc_fr_sale_sg/ΣR`，含税及会计范围差异，不能等同已收回应收比例 |
| 利润现金转化 | `ΣC/ΣN`，N为正，另列金额；金融不适用 |

| 存货周转天数 | `平均存货/同期间oper_cost×期间天数`，成本正；存货不等于产成品 |
| 应收与收入增速差 | 同集两期应收同比减收入同比，百分点；基期应收为0不强算 |

| 固定资产 | `fix_assets_total`金额、同比及固定资产/资产；口径不随新旧字段可用性切换 |
| 资产周转、ROE | TTM R/平均总资产；TTM P/平均归母E；D版本用于评分，不能冒称监管加权ROE |
| 杠杆 | `Σtotal_liab/Σtotal_assets`，资产正；不是有息负债率或违约概率 |

天数统一360天惯例：累计季度分别90/180/270/360，TTM360。2024需要2023期初的数据留NA；可计算的2024单季仍正常展示，不拿期末余额冒充均值。

利润变化对称分解：`Δ(Rm)=ΔR×(m1+m0)/2+Δm×(R1+R0)/2`；m用被分解利润对应利润率。杜邦仅用合并N、合并权益和资产的同集TTM：`N/R × R/平均资产 × 平均资产/平均合并权益`。不把归母和合并范围拼接。

行业合计、公司中位数、改善比例及基期收入前三公司贡献并列。基期按比较对象确定：9M同比用上年9M，单季同比用上年同季，全年预测对照用2025全年；同额按代码升序，前三名单在该次比较中固定。剔除后按相同公式重算，剩余为空或分母不合法则NA；总增量近零时只列贡献金额、不报不稳定贡献率。名次对照的适用条件见§7.4。货币库存的升降不能独立证明补库存/去库存或因果关系。

## 5. 全年预测：统一模型与情景

### 5.1 预测单元和有效集合

**先预测非金融二级行业，一级和非金融总额由二级金额向上加总。** 不给一级单独拟合另一组结果，不平均下级增长率或利润率；没有有效预测的行业不填零，加总必须写“已覆盖行业/样本合计”。本轮不建立逐公司预测或个股投资榜。

R/P联合预测集要求2024、2025各H1/9M/FY，以及2026H1/9M的所需字段完整、可比；收入有关分母、历史Q3/Q4和当年Q3/9M汇总均为正。D在对应利润历史完整集上独立预测，C也在自己的完整集上独立预测；**每次必须在该集合上重算收入预测**，不拿更大R集的金额乘较小D/C集的利润率。

预测表可同时显示R/P集、D集、C集，但相互比率/贡献必须改用共同集。评分用§7统一评分集全部重算。历史缺失、未解释版本冲突或合并范围不可比只使相关预测不可用，不任选一年、不插值、不切到备用模型，也不向未预测企业放大。

### 5.2 收入预测

在同一行业同一集合上，R为行业收入合计：

```text
k = 0.5 × (R_2024Q4 / R_2024_9M + R_2025Q4 / R_2025_9M)
A = R_2026_9M × k                         # 两年季节占比
B = R_2025Q4 × (R_2026Q3 / R_2025Q3)       # 最近单季同比延续
R_Q4_base = 0.5 × A + 0.5 × B
R_Q4_low = min(A,B)；R_Q4_high = max(A,B)
R_FY_s = R_2026_9M + R_Q4_s，s∈{base,low,high}
```

另列`R_2025Q4`作为季节简单基准对照。50/50已由管理员本轮确认先采用，不是拟合得到；若A=B，模型收入范围可以为零，不人为加一个固定波动带。敏感性另看A/B权重25/75和75/25，主方法不根据最终排名改权重。

### 5.3 归母、扣非利润预测（季节调整公式已确认）

X分别取P或D，各用自己的同集收入，`m=X/R`：

```text
d24 = m_2024Q4 − m_2024Q3；d25 = m_2025Q4 − m_2025Q3
m_Q4_base = m_2026Q3 + (d24+d25)/2
m_path24 = m_2026Q3+d24；m_path25 = m_2026Q3+d25
m_low = min(m_Q4_base,m_path24,m_path25)
m_high = max(m_Q4_base,m_path24,m_path25)
X_Q4_base = R_Q4_base × m_Q4_base
X_Q4_low/high = min/max{R_low×m_low,R_low×m_high,R_high×m_low,R_high×m_high,X_Q4_base}
X_FY_s = X_2026_9M + X_Q4_s
```

负利润率下，低收入不必产生最差利润，故取乘积角点。上下情景对R和利润率是模型内组合，不是有确定发生机制的宏观情景。归母与扣非单独预测；非经常性差异、减值、年末费用作为解释和失效提示，不在已有季节效应外再任意扣一次。

### 5.4 经营现金流预测

现金流的Q4与Q3季节性差异较大，改以前三季现金流率作起点。`c9_y=C_y9M/R_y9M`，`c4_y=C_yQ4/R_yQ4`：

```text
e24=c4_2024−c9_2024；e25=c4_2025−c9_2025
c_Q4_base=c9_2026+(e24+e25)/2
c_path24=c9_2026+e24；c_path25=c9_2026+e25
c_low/high=min/max{c_Q4_base,c_path24,c_path25}
C_Q4_base=同集R_Q4_base×c_Q4_base
C_Q4_low/high=同§5.3的四角点乘积及基准取min/max
C_FY_s=C_2026_9M+C_Q4_s
```

这是现金流率情景，不是应收回款概率，也不在金融行业使用。

### 5.5 覆盖、解释和检验边界

- 每个预测输出候选N、有效N、当年/上年9M收入覆盖，以及缺失类别，覆盖定义遵守§1.3，分子分别代入该项预测集合。低于90%只能称“样本预测”；达到门槛仍须写明覆盖范围，不宣称已预测全部公司。公司数少于5另标小样本，不进入综合榜。
- 只有两个历史年度，不能证明季节性稳定；不拟合多变量回归，不给置信区间、概率或准确率承诺。极端周期、政策、会计变更、重组和年末集中减值可能让模型失效，报告必须写明。
- 可做2025收入的季节朴素基准诊断，唯一公式`Rhat_2025Q4=R_2024Q4`，与同公司实际2025Q4比较，报告金额误差及按2024全年收入归一化的误差。该诊断沿用当前最新修订数据，不恢复2025当时公告版本，因此是**事后回看诊断，不是严格样本外回测或当时可实现的准确率**；不作P/D/C未定义公式的同名检验，也不能验收2026完整双年度组合模型。
- 缺某个二级行业时，一级仅显示已覆盖集合的加总与覆盖，不能把缺失行业当0。金融旁表保留事实，不从非金融模型推导金融全年预测。 一级基准、低、高金额分别等于有效二级同名金额之和；低高合计代表各二级同时取模型内边界，不是同一个已设定宏观事件的预测，更不是置信区间。各层比率由该层同集合合计重新计算。
- 业绩预告、宏观资料及公司公告作为独立佐证，标明信息日期；没有预先审核的数值规则不手改基准。已披露资料与前三季财报不能重复计入。

## 6. 估值含义与样本一致

`M=Σtotal_mv×10000`，取10/30同一预测/评分集合的市值。主估值指标是预测全年扣非收益率`D_FY_base/M`，并列归母预测PE=`M/P_FY_base`（P正）、PB=`M/E`（E正）、TTM及股息率原值。行业PE/PB由合计重算，不平均个股PE/PB，不把源PE空值都当漏数。

M沿用源A股估值字段，不另构造多类别股份真实总市值；A/H、B股和不同类别股份的股本/定价差异必须附注。因此只称“按源市值口径的盈利收益率/估值比较”，不称跨市场真实全公司价值或无风险套利。按A股价格折算的源市值也不能据此推出股东可兑现价值。

预测PE不是未来收益率，低估值可能对应利润周期高点。2024以来两个完整年度不能证明正常周期利润；周期行业的高盈利收益率必须结合利润率变化、现金及情景下行解读，不据此认定长期低估。本次不计算历史日频估值分位、目标价、2027全年数值或持有期预期收益。

### 7.3 统一转分、并列及缺失规则

1. 先确定通过全部条件的同层级固定候选行业，n为行业数。n<5时不计算本套分位得分、不发布综合排名，保留原始值，避免n=1时除零和过小分布的误导；n≥5后再对每项原值从低到高做平均秩排名r。高为好的`p=100×(r−1)/(n−1)`；低为好取`100−p`。原值相同用平均秩；全部相同均50分。
2. V为单指标分数；G、Q、K分别为各自两项分数的平均。`综合分=(V+G+Q+K)/4`。不再额外加入趋势标签、源PE或主观行业判断。
3. 基于未舍入分数降序排名；完全同分同名次，用竞赛排名如1、1、3，同分展示顺序按行业代码。金额/比率显示位数不能影响排名。
4. 百分位已限制单项极值影响，不额外剪掉真实极值；展示极值及来源。有缺项则不进入该次固定排名集合，不按不同指标各取不同候选分布。
5. 先为每个二级行业建立上述字段完整的评分输入集合、计算预测金额，再分别判断行业排名资格。一级使用其所有二级的有效评分输入集合的并集，并加总这些二级金额预测，再判断一级覆盖及正利润等条件；不只选择已经进二级榜的行业，也不平均二级得分。例如二级仅3家公司不能进二级榜，其有效输入仍可纳入一级；输入/模型本身不可用时不能填零。一级仍遵守二级向上加总，不重新独立拟合一级预测。

### 7.4 稳健性展示

四维权重各取15%、20%、25%、30%、35%，只保留合计100%的组合；七项原始值、分项和候选行业集合不变，只改四维组合权重。展示名次范围和进入前20%的组合比例，令k=ceil(0.2n)，竞赛名次≤k的全部纳入，边界同分不按代码截断；附实际入选数（可能多于20%）及总组合数。这是权重稳定性，不能叫盈利概率或胜率。

收入A/B替代权重25/75、75/25，及剔除按§4.2选定的前三家公司，是另两类敏感性，必须分别重算共同集合上的预测和原始分项，不能沿用原利润率或市值。仅当原候选行业全部仍满足原定正利润、公司数及覆盖等资格时，才在**同一原候选行业集合**重算分位和对照名次。

若任一原候选在替代方案失效，该方案不提供可比全榜名次范围，保留有效的原始值变化、失效行业及原因；不能删除失效行业后给其余行业重新排名，也不能填0保住名次。剔除龙头的目的主要是检查集中度，可能无法形成与主榜可比的完整排序，不承诺每种敏感性一定有名次。

预测与估值共享盈利输入，利润相关项可能重复奖励；同期相关性和分项移除诊断只解释主榜依赖何项，不替代已确认四维七项主公式，不按最终结果反调权重。

每个unit/批次前后检查取消，数据库取消则回滚只读事务，保留已校验的本地完成unit，未完成`.part`不参与计算。任何不可中断步骤不得超过30秒。运行日志至少每30秒展示阶段、数据集/报告期、已完成/总unit、数量、最后更新时间；未知ETA写“暂无法估算”。不创建生产任务记录来展示本地研究进度。

重复运行同一run_id必须先读检查点、验证哈希和参数，完整unit不重复追加；部分失败只重做该unit。续跑检查已完成unit的源计数/最大抓取时间指纹，指纹变更则停止，选择重提取一致的新运行，不能混用同步前后数据。计数/时间指纹不能证明所有原值完全没变，最终依据本地冻结输入及来源时段；要求原子源快照时需另行设计，不擅自持有全库长事务。

计算按“行业×步骤”持久化金额表、集合及校验结果；图表、排名共用这些表，不各自重新算。最终验收以本地冻结表对账，不再全库扫一次；只做预算内源元数据/指纹确认。输出文件失败不修改输入；恢复时验证已完成结果与输入/参数哈希一致后复用。

### 11.2 必须通过的检查（有限试算结果见§10.6）

- **独立人工字面样本**：季度差分、跨年TTM、360天平均余额、元/万元/万股转换；期初缺失必须NA，余额不求季度和。关键预期独立人工核算，不调用待测公式生成expected。
- **真实边界**：先核生产者列/类型/NULL/唯一键和至少3家公告语义，再构造夹具；对已知23差异、3 NULL单元只检查相关边界。Mock不能代替真实生产者读取验收。
- **共同样本**：联合比率、同比及预测每个分子分母相同公司，加入大额缺报反例能阻止虚假90%覆盖；新股缺历史和零值/NULL必须不同。
- **分类**：唯一直接/三级上溯一致可以纳入；冲突、多父级、跨日期重复必须拦住；所有行业加总对本地公司集无漏无重。当前4家无三级且直接上级完整必须正常通过。
- **预测**：负利润率下四角点；基准在情景范围内；历史不足不切模型；上下级金额加总一致，缺行业不能填零，年度=9M实际+Q4预测。
- **评分**：五个不同原值对应0/25/50/75/100；低为好反向、相同值平均秩/全50、n<5、缺项不重权、同分1/1/3、正利润/权益/覆盖资格，边界应有正反例。
- **范围**：六排除代码所有期间不进入；5缺报不填0；查询和投影没有2024之前及已取消项目；金融不进入本轮非金融评分，源PE缺失不误判漏数。
- **恢复**：中途取消、输出失败、进程退出、幂等续跑、源指纹变化时停止；已完成unit哈希可读回，未完成单元不能被误算。
- **报告**：每张图可追到冻结金额表/样本ID；金额加总、利润分解、行业归属及评分权重独立对账；事实、条件预测、研究优先级明确区分。方法局限、剔除/缺报/覆盖在正文或相邻注释可见。
