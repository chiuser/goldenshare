# 三买A诊断：需要分清“上涨中的回踩”和“下跌后的反弹”

日期：2026-09-09。结论可信度：**可以作为探索性诊断分享，不能作为有效策略发布。**

本轮最有用的发现不是某个新胜率，而是：当前程序三买标签没有可靠地区分两种完全不同的市场背景。2024年9月的少数大涨显著抬高30分钟成绩；10月已经从高点大幅回落后的反弹，却仍触发60分钟三买。价格位置是值得继续验证的线索，但简单看“涨得多不多”“是否放量”还不够。

## 1. 数据与边界

输入完全复用[A实验](../chan_minute_variant_a_20260909/review.md)，不重新读湖。行情2021-09-09—2026-09-08，2021年部分仅初始化；实际评估2022-01-04—2026-09-08。三指数×30/60分钟，原始B3共93个，20交易日冷却后82个，分布在64个信号日期；同日不同指数/周期信号不等于独立试验，64个日期也不代表64个独立行情阶段。

下文主表为冷却口径；[diagnostics.json](diagnostics.json)同时保存原始口径、逐日期/年份删除诊断、日期聚类和正负结果特征分布。[events.json](events.json)保存全部93个事件的当时特征、原评分和冷却身份，不删除失败信号。

Q = 下一交易日收盘 / 信号之后下一根完整柱开盘 − 1。是无成本指数价格代理，不是交易账户收益。方向上涨率R与Q盈利率不是同一个指标，本报告按Q正负描述结果；不做卖点、止损、ETF、费用、滑点或T+1模拟。

## 3. 一个具体失败案例：沪深300，2024-10-10 11:30

程序此时首次给出笔确认的三买，事件的锚柱是当日10:30收盘柱。按执行代理，要用下一根13:00—14:00柱的开盘价4070.484，而不能按已经过去的回踩低点买入；保存字段`entry_bar_end=14:00`是柱终点，不是14:00才成交。

在11:30信号发出时，已经知道：

| 当时可知事实 | 数值 | 含义 |
| --- | ---: | --- |
| 信号收盘 | 4068.8818 | 当时位置 |
| 20交易日前收盘，2024-09-03 | 3273.4282 | 近20日已涨24.30% |
| 前20日及当天截至此时最高价 | 4450.3677 | 10月8日已出现；当前比它低8.57% |
| 同进度成交额倍数 | 2.387倍 | 相对前20日同样截至11:30的累计额均值 |
| 锚柱最低价到信号收盘的反弹 | 3.99% | 确认时已离开低点一段距离 |

**“近20日还涨着24%”和“已经从高点跌了8.6%”可以同时成立。** 只看涨幅会觉得很强；只看局部三买会觉得回踩完成。两者都可能忽略：这是经历大幅回落之后的一次反弹。

随后2024-10-11收于3887.167，Q=3887.167/4070.484−1=**-4.504%**；期间最差价格偏离入场价-5.487%，最好+0.688%。后面这些仅用于评估，未输入当时特征。

作为对照，沪深300在2024-09-26 10:30的30分钟大涨案例，触发时近20日涨幅只有4.06%，距近期高点-0.75%，成交额1.474倍，确认前反弹1.41%，随后Q为+7.663%。两例周期不同，且按事后极端收益选出，只用于解释，不能据此归纳成成功/失败判别器。

## 4. 有没有在其他样本中重复出现？

四项事前特征固定为：近20日涨幅、距近期高点、同进度成交额倍数、确认前反弹。窗口只取前20个完整交易日和当天已完成部分；具体公式见[原方案第15节](../../docs/product/chan-signal-prediction-and-profit-experiment-plan-v1.md)。不使用当天尚未完成的收盘或全天成交额。

相对更一致的现象是：**Q非正样本触发时，通常已经离近期高点更远。**

| 指数/频率 | Q正/非正数量 | Q正样本：距高点中位数 | Q非正样本：距高点中位数 |
| --- | ---: | ---: | ---: |
| 上证30分钟 | 9/7 | -0.87% | -1.01% |
| 上证60分钟 | 4/5 | -0.96% | -1.34% |
| 沪深30030分钟 | 10/6 | -0.66% | -1.81% |
| 沪深30060分钟 | 8/4 | -0.97% | -2.03% |
| 中证50030分钟 | 10/8 | -1.47% | -1.70% |
| 中证50060分钟 | 6/5 | -0.55% | -2.42% |

但还不能据此设一条“回撤超过X就不买”的有效规则：

1. 正负样本的取值范围六组都有重叠；例如中证50030分钟，有正收益信号距离高点-4.67%，也有负收益信号仅-0.43%。接近高点不保证成功，离高点较远也不必然失败。
2. **追加的事后敏感性核查**：剔除2024年后，上证60分钟正/非正样本中位数为-1.35%/-1.07%（3/2个），中证50030分钟为-2.18%/-0.94%（7/7个），方向反转。其余四组方向保留，但不能用“六组一致”掩盖年度不稳定。此核查不是独立验证，也不作为删年的理由。
3. 近20日涨幅、成交额倍数、确认前反弹，正负样本中位数的关系均不跨六组保持同一方向。尤其“放量”并不能自动区分强势延续与冲高后的反弹。
4. 上证30分钟还有一例2022-03-03信号，锚柱在2月18日，间隔72根柱。虽然总体确认滞后中位数很短，不能据此假定每个标签都是刚刚完成的回踩。该例保留，不能事后抹掉。

## 5. 下一步：验证一个风险假设，不继续放宽买点

建议聚焦：**较深回撤之后出现的三买，是否更容易只是下跌途中的反弹？**

下一轮应先固定一个价格背景判据，再与不加判据的A比较。需要同时报告挡住了多少亏损、错过了多少大涨、剩余样本数、均值/中位数和年度稳定性；不能只展示过滤后的胜率。跨指数波动不同，可以讨论把回撤按过去波动归一化，但本轮没有计算或挑选阈值，也没有宣布该做法有效。

尤其应检查：剔除2024年那几个极端案例后，关系是否还存在。如果只改善这几个已看过的案例，应判定为对历史事故的修补，不是通用改进。当前历史已经多次看过，后续试验仍须标为探索性；新规则最终需要后续未用于选规则的数据检验。
