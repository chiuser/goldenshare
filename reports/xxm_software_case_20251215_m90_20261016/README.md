## 3 优先研究的解释：取消前能否转用已合格参照

16日11:00，在当前冻结输入及原两段历史池下，同一根恰好发生：

- 原参照的DIF被突破：-9.772002低于-7.239400。
- 另一参照的价格资格首次成立：收盘3821.7300低于旧段最低收盘3823.2960，低1.5660点；同时DIF -9.772002仍高于该段-39.363871，背离没有破坏。

如果先核全部合法参照、改用仍有效的较早低峰，钝化可延续，不需要16日新报一绿一黄；这与两张图保持四条的观察相容。它使用当时已知历史及当前完成柱，不需要未来行情。**这是优先候选解释，不是本轮已运行或已批准的通用新状态机。** 仅把“下一根重选”改成“同根取消再激活”，若仍输出一绿一黄，依然未解释画面为什么没有多出一轮。

本例只约束DULL状态下旧参照突破与另一参照同根合格时的竞争，不能一并决定STRUCTURE期间、较早已合格时、顶部镜像或所有周期的切换方式。也不能因此删除单根历史段、增加通用先红后绿门禁或复活已经被突破的旧参照。

下一步以**参照切换与取消的优先级**为单一研究目标：先在隔离研究中定义候选，再核已有四周期冻结账本及软件保护点，特别保留日线7/15真正取消、7/17另一参照后来才合格的链条。不是所有取消都能改成延续。暂时无需用户继续找新资料；候选若遇到具体外部证据分歧，再提出一个有区分价值的问题。

原“12/16 14:00软件新激活是否允许使用上午段低价”的问题也不能由本图证明：如果软件实际维持钝化，就根本没有该次首次激活。普通首次用价的通用定义仍待核，不因本例擅自改掉。
