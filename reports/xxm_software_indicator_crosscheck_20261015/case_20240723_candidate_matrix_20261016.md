# 7月23日研究收敛：价格条件更有支持，附加DIF与结束时机仍待确定

核查日期：2026-10-16。上证000001.SH，仅为解决7/23历史结构消失而复核已有相关材料，不转入顶部疑报。先保存候选定义，再执行对照；没有新增软件图、独立原音或盲测样本，没有修改产品代码、参数、API、Figma或正式数据。

## 1 本轮新增结论

**“以原结构负柱段最低收盘为价格参照”比“只看DIF反向”获得了更多现有材料的支持。** 价格单独、价格加DIF下降、价格加DIF下降至少1%，都能对齐三处日线及两处120分钟的既有绿色标记。还不能决定这三种中的哪一种是原软件公式。

只看DIF下降至少1%的一次性历史消失候选，会将120分钟7/31结构的消失提前到8/2下午，旧记录随即结束，不能再输出图中8/5下午与该结构对应的绿色。这个不相容来自后续有绿色的正观察，而不只是“8/2图上没字”。它仍依赖既有结构关联、源指标及一次性历史记录模型；不宣称已经排除所有可能的DIF型公式。

## 2 先固定什么，再检查什么

研究候选为7种触发解释×2种开始时机×3种结束策略，共42种组合。它们是临时诊断的组合数，不是42个独立软件样本，也不进入线上双轨实现。

| 触发解释 | 本轮对照结果 |
| --- | --- |
| H1：收盘破原结构负柱段最低收盘 | 三处日线、两处120分钟均能对齐 |
| H2：仅DIF相对前一根下降至少1% | 120分钟8/5那处提前命中8/2，无法同时对齐五处 |
| H3：H1且DIF下降至少1% | 五处均能对齐，与H1仍不可区分 |
| H4：H1且DIF有所下降 | 五处均能对齐，与H1、H3仍不可区分 |
| H5：收盘破原来用于背离比较的参照段价格 | 提前命中多处，即使变色后才检查，也不能同时对齐 |
| H6：收盘破结构形成那根的收盘 | 同上；确认收盘不是原段最低收盘 |
| H7：DIF只要回落就触发 | 日线7/23提前到7/10、8/22提前到8/21，120分钟8/5也提前，不能同时对齐 |

开始时机分别为结构后一根即检查、原负柱段结束后才检查。若结构恰由变色确认，第二种从其后一根即可检查，不额外等待另一次变色。

结束策略均先检查原DIF参照突破，再分别检查：E1任何新的底部钝化／结构接替；E2同E1但忽略当前已知有问题的dif_return类DULL；E3只有新结构接替。结束检查先于历史触发，最后才建立新的结构记录。三种无固定期限，最多一个旧结构；这些都是明示假设，不是软件规则真值。

本轮冻结当前普通内核，未把A组同段修订偷偷加入B组诊断。E2仅检查结束条件的敏感性，不代表忽略dif_return已获证实正确。

## 3 比7月23日更能区分解释的已有材料

使用用户已给的9/4上证120分钟图中7/31至8/5一段，没有让用户另找日期。

| 节点 | 原源值 | 不同解释的结果 |
| --- | --- | --- |
| 7/31 11:30形成结构 | 原结构段最低收盘2876.8700，来自7/30上午；形成时收2930.8035 | 锁定不同价格概念，不能混用 |
| 8/2 15:00 | 收2905.3374，仍高于2876.8700；DIF -8.538613→-8.831294，下降3.4277%；柱值+8.117167 | 仅DIF至少1%先输出并结束旧记录；价格型解释继续等待 |
| 8/5 15:00 | 收2860.6978，低于2876.8700；DIF -12.397226；柱值-0.520073 | 三种价格型解释在这里输出，与既有绿色柱位对应 |

已有图按柱位映射8/5下午有绿色，前面的结构对应7/31上午；9/4讲稿还明确此前结构循环与当天真正钝化消失不同。没有游标或软件结构ID，不能把关联精度写成已经独立验证。若要坚持纯DIF解释，须额外解释为什么8/2先触发后仍能在8/5对同一旧结构再输出，或证明原关联不同；不能只说它也补中了7/23就直接采用。

其他两个价格参照也受此段约束：用旧背离参照价2940.5940，会在7/31下午收2938.7493时先命中；用确认收盘2930.8035，会在8/2上午收2919.3170时先命中。推迟到变色后检查也不能解决这两处提前命中，因为此前已经转红。

因此，上轮“仅7/23不能确定比较哪个价格”仍然成立；本轮利用其他既有正观察，把**旧参照价、确认收盘两种已列候选降为不建议采用，优先研究原结构段最低收盘**。不将条件性排除推广成所有可能价格或OHLC公式都已排除。

## 4 结束策略的反证与保留项

42种组合中，18种能对齐已有五处正观察，均属于H1／H3／H4。它们各有两种开始时机、三种结束策略，不能按命中次数决定哪个正确。

其中E3的6种组合会在9/2下午新钝化出现时再输出一条旧结构绿色。现有图及用户确认只见新黄色、绿色在更右侧后续失效处，与这条额外预测不相容；它仍是静态负证据，不能当作软件从未产生该事件。因此优先保留其余12种，E3另列争议，不按硬反例宣布完全排除。

E1与E2、两种开始时机也没有由五个正观察唯一确定。E2＋从下一根开始，还会在已有时间范围内预测8/14日线、8/28下午90分钟、8/12下午及8/27上午120分钟的其他历史绿色；这些不直接计为误报。9/4图再看这些邻近区域，文字相接，尚不足给出可靠逐柱无事件结论。本轮不新增这些日期的找图任务，不把A组已知dif_return错误当成B组结束策略的独立证明。

## 5 可提交评审的工作修订方向

建议将B组研究主线收敛为以下三点，仍待用户确认，尚不能进入正式编码：

1. 底部结构形成后，保留它的身份、原负柱段最低收盘及所用DIF参照；普通状态变色清空，不等于这份历史判定上下文立即失效。
2. 已完成收盘跌破原段最低收盘是核心价格候选。DIF是否还需下降、是否需达到比例门槛，继续将H1／H3／H4分别保留在离线研究中，不静默删除条件或照搬1%。
3. 旧参照失效及新信号接替必须单独处理，不能在新钝化出现时机械追加旧绿色。开始时机和E1／E2的区别仍是未确认项；不引入无证据的固定到期根数。

7/23对应的工作解释现在更集中：保留7/9底部结构原段最低收盘2922.4498，跨7/11红柱，7/23收2915.3685时触发价格候选；它至少可与其他四处已有绿色共同解释，而非只为7/23孤立加判断。**仍未证明原软件的附加DIF条件、完整寿命及所有关联规则。**

技术面预测仍按当时真实普通状态与合法参照判断：历史记录尚在，不等于当前仍钝化；历史结构消失也不等于当根已经新钝化或真正钝化失效。不得沿用旧结构直接预测新结构成立，或让旧历史参照替代新钝化自己的参照。B组正式合同及预测迁移仍需先评审，本轮未改变A组实现范围。
