## 回退

旧环境、旧 pyproject.toml、旧 uv.lock 和已安装版本清单保存在 ignored `venv.bak` 中，不要清理。

在本机终端执行以下命令可回退；它先检查活动 run/backfill，优雅停止 DG，确认停机后再次检查活动，恢复旧环境与依赖文件，再通过原启动入口启动。若依赖文件在升级后已被修改，脚本拒绝覆盖，必须先人工对账。

```bash
/bin/bash -lc 'cd /Users/congming/github/goldenshare/lake_console/orchestrator && exec .venv/bin/python3 -B venv.bak/dg-upgrade-1.13.26-20261013/rollback.py'
```

回退脚本仅作语法校验，未执行，以免撤销本次升级。回退不撤销升级后正常调度产生的业务数据或事件；后续若做独立数据库迁移，应重新评估回退。

详细启动日志、只读健康 JSON 和隔离审计脚本在 `venv.bak/dg-upgrade-1.13.26-20261013/`。当前 dg 提示未激活 virtualenv 的提示不影响启动，未为了隐藏提示新增配置。
