# DG 公告 P1 核心实现验收

日期：2026-10-04。依据：[方案](../docs/design/dagster-anns-d-onboarding-plan-v1.md)、[LLD §13](../docs/design/dagster-anns-d-onboarding-low-level-design-v1.md)。范围为核心合同、来源读取、流式文件、校验与恢复；不包含 P2 注册和正式执行。

## 实现

新增八个核心模块：anns_d_contract、anns_d_source、anns_d_io、anns_d_checkpoint、anns_d_execution、prod_db/anns_d、bootstrap/anns_d_history、run_contracts/anns_d。共享 paths.py 仅新增公告路径函数。新增六个测试模块和三个隔离支持文件。

Raw 仅六个源字段，保留 NULL、空值及全部不同版本，仅消除六字段完全一致的记录。Prod 月读取用只读 repeatable read 服务端游标，单批10,000；Tushare 单页2,000，默认请求结束后间隔5秒，包含重试。日100次/窗口350次预算持久化；每次源调用30秒硬截止，取消释放上限5秒。

每页落盘、完整结束证据、候选集合读回、源和目标指纹复核、同日锁、原子提升及逐文件 checkpoint 已实现。未完成的日/月 capture 重启新 attempt，不混合源快照；已改名但 checkpoint 未更新时按文件证据恢复。专用 DuckDB 一次物化月份，再生成每日候选，包括空日，不累积全历史 Python 对象。

## 验证

- 公告及既有资源测试82项通过；受保护 DuckDB launcher 27项通过，共109项。覆盖 NULL/空字符串、异常字段、满页/空尾页、重试、持久预算、取消、两种进程退出、幂等重放、源/目标篡改、磁盘不足、锁冲突与观测失败后提交保留。
- DuckDB 回归按 stock_suspend_confirmed_test_runner 的隔离 guard 执行，没有正式 writer。存在4条既有 Dagster/Pydantic 弃用警告。
- 实际 ProdPostgresResource：transaction_read_only=on；2023-06 月同快照计数147,952，首批10,000行，最终 SQL 首批包含计数/传输/验证耗时4.268秒，显式关闭游标和只读连接。没有完整读取该月，不能据此宣称整月吞吐验收完成。
- 实际可终止 SDK 调用：2026-09-26 空页0行、六列齐全；155162.SH / 2023-06-09 两行，缺URL一行、缺rec_time两行，缺失值还原正确。只读调用之间间隔至少5秒。
- scoped Ruff 及全 src/tests 致命语法检查通过，文档完整性和 git diff --check 通过，CodeGraph sync/status 显示索引最新；[结构化证据](anns_d_dg_p1_20261004.json)只保存聚合结果，不含秘密或完整源 payload。

## 边界与下一步

无 Prod、正式 Lake、Dagster 事件写入，无调度启用。共享资源实现和子系统依赖矩阵不变，下载器和前端不变。新增路径影响面由 CodeGraph query/impact 核验，core 仅依赖 orchestrator 内部资源及现有基础库。

P2 接入 catalog/schema、自然日 asset、正式 checks、job、默认停止的08:00七日 schedule及运营入口；再完成 definitions 和窗口接线验收。P3/P4 经独立授权后执行真实样本、全量 bootstrap、事件补报、2026-10-01起衔接补拉及启用调度。完整月吞吐、正式事件恢复及全集覆盖尚未验收。
