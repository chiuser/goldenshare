MA

boll_mid(t) = avg(close[t-19 ... t])

boll_lower(t) = boll_mid(t) - 2 * sigma(t)

MACD

alpha_fast = 2 / (12 + 1)
alpha_slow = 2 / (26 + 1)
alpha_signal = 2 / (9 + 1)

ema_fast(t) = close(t) * alpha_fast + ema_fast(t-1) * (1-alpha_fast)
ema_slow(t) = close(t) * alpha_slow + ema_slow(t-1) * (1-alpha_slow)
dif(t) = ema_fast(t) - ema_slow(t)
dea(t) = dif(t) * alpha_signal + dea(t-1) * (1-alpha_signal)
macd(t) = 2 * (dif(t) - dea(t))

首个历史 bar seed: ema_fast=close, ema_slow=close, dea=0

KDJ

llv9(t) = min(low[t-8 ... t])
hhv9(t) = max(high[t-8 ... t])
rsv(t) = 50 if hhv9 == llv9 else (close-llv9)/(hhv9-llv9)*100
k(t) = (2/3)*k(t-1) + (1/3)*rsv(t)
d(t) = (2/3)*d(t-1) + (1/3)*k(t)
j(t) = 3*k(t) - 2*d(t)

  6. 除整体历史基线首日外，批量检查严格前一 expected date 的 7 个 state assets。

6.12 历史 Bootstrap 与修复

  • 输入只能是已健康的 Silver 日期集合；不调用 Tushare，不顺手修 Silver。
  • 按日期严格升序处理，一日期内一次完成 7 个频率。
  • 首个实际 Silver 日期按 seed 初始化 MACD/KDJ；后续日期读取上一 expected 日期 state。
  • 每批完成后对 14 文件、行数、keys、state、参数版本和磁盘空间生成 manifest。
  • 失败从最后一个完整 ready 日期恢复；禁止跳过失败日期继续向后。
  • 历史计算不直接写 Dagster events；文件全量审计后，events 工具另行批准。
  • 算法版本变化的 repair 必须输出受影响日期数、输入/目标文件数、空间峰值和 plan hash，再获得执行批准。
