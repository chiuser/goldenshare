Dagster Phase 3 指数链路 Low Level Design（合并版）

本文件是原 Phase 3 LLD 与 Index Daily 重构 LLD 的合并版索引。 旧 active pool / raw-by-trade-date 代码路径不再作为实现方案保留。 需要代码级细节时，以 Index Daily 重构 LLD 为准。

实现原则job 只做 asset selection，拉取和写文件逻辑必须在 asset/helper 内。

旧链路只允许作为历史审计对象，不允许作为新开发参考。

1. 当前代码结构

文件 当前职责 不得混入的旧职责
defs/partitions.py 定义 cn_a_index_ts_codes 和 cn_a_index_trade_days。 不得恢复 active pool 作为指数代码集合事实源。
defs/paths.py 提供 raw-by-code、raw staging、silver-by-date 路径函数。 不得恢复旧 raw-by-trade-date 输出路径作为生产路径。
defs/assets/index_daily.py 定义 raw_tushare_index_daily_by_code 和 silver_index_daily。 不得恢复旧 raw_tushare_index_daily[trade_date] asset 或 active pool 读取。
defs/checks/index_daily_checks.py 绑定 raw-by-code checks 和 silver-by-date checks。 不得恢复 active pool coverage check 作为生产门禁。
defs/jobs/index_daily.py 定义 index_daily_update_job 和 silver_index_daily_update_job。 不得恢复旧 history backfill / repair job。
defs/sensors/index_trade_day_sensor.py 只注册指数交易日 dynamic partitions。 不得触发 raw 或 silver。
defs/sensors/index_daily_sensor.py 判断交易日、源站 ready 和 raw 缺口，触发 index_daily_update_job。 不得触发 silver，不做历史批量重建。
source_readiness/tushare/index_daily.py 只做 Tushare index_daily ready 探测。 不得写 parquet，不注册 partitions，不触发 job。
defs/tushare_api_io.py 复用 Tushare 分页拉取、字段校验、DuckDB 写 parquet、原子替换和 stdout 日志辅助。 不得包含 active pool 请求流程。

2. 当前数据流

index_trade_day_sensor
  -> register cn_a_index_trade_days

index_daily_sensor
  -> read cn_a_index_trade_days
  -> read cn_a_index_ts_codes
  -> probe Tushare index_daily ready
  -> trigger index_daily_update_job[ts_code]

index_daily_update_job[ts_code]
  -> raw_tushare_index_daily_by_code[ts_code]
  -> raw-by-code checks

silver_index_daily_update_job[trade_date]
  -> silver_index_daily[trade_date]
  -> silver checks
当前 silver_index_daily 不会被任何 sensor 自动触发。 silver_index_daily_sensor 已新增，在 raw-by-code 全部 ready 后触发 silver。

3. 运行配置契约

入口 partition config 说明
index_daily_update_job ts_code trade_date、write_mode=replace 主入口只支持单个交易日修复；asset 内部映射为源接口 start_date=end_date=trade_date，第一版只支持 replace。
silver_index_daily_update_job trade_date 无业务 config 从全部注册 cn_a_index_ts_codes 的 raw 文件中筛选当日数据。

4. Checks 门禁

资产 blocking checks 执行时机
raw_tushare_index_daily_by_code raw_index_daily_by_code_file_exists、 raw_index_daily_by_code_row_count_positive、 raw_index_daily_by_code_required_columns_and_types、 raw_index_daily_by_code_partition_code_matches、 raw_index_daily_by_code_unique_ts_code_trade_date 随 index_daily_update_job[ts_code] 执行。
silver_index_daily silver_index_daily_row_count_positive、 silver_index_daily_required_columns_and_types、 silver_index_daily_partition_date_matches、 silver_index_daily_unique_ts_code_trade_date、 silver_index_daily_conflicting_duplicate_absent、 silver_index_daily_price_sanity 随 silver_index_daily_update_job[trade_date] 执行。
