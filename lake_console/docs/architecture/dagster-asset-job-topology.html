Dagster 资产与 Job 拓扑梳理

本文用于把当前 Dagster orchestrator 中的 asset 层级、依赖关系、资产归属、job selection、更新频率和触发方式放到一张研发地图里。 它同时区分“当前代码事实”和“后续应遵守的研发模式”，避免业务 job 偷偷写共享基础资产，也避免 full snapshot 并发写入变成隐性坑。

4. Job 与 Asset Selection 关系

Job 的职责是“这次跑哪些资产”，不是“这些资产怎么生成”。因此同一个 asset 可以被不同 job 选中，但必须有清晰目的，不能让多个业务 job 随意写共享基础资产。

calendar_update_job raw_tushare_trade_calendar、silver_trade_calendar + checks 交易日历 raw/silver full file。 当前人工触发；未来低频 schedule。 不能被业务 gold job selection；sensor 只读它。
stock_basic_update_job raw_tushare_stock_basic、silver_stock_basic + checks stock_basic raw/silver full file。 当前人工触发；目标改为日更最先执行。 已改为日更 full snapshot 口径；并发限制作为后续独立设计项。

6.1 推荐研发模式

一个资产，一个清晰归属 每个 asset 必须归属到一个稳定归类：calendar、basic、quote、index、breadth / derived metric、market gold 等。归类决定它的 job 入口、更新频率和 checks 口径；不要重新发明临时资产族或 run tag。
共享基础资产单独写 stock_basic、trade_calendar 只能由自己的 update job 写。业务 job 只能只读依赖。
Job 是入口，不是逻辑容器 job 文件只写 define_asset_job 和 selection。拉取、写文件、SQL、质量判断都不进 job。
Checks 是边界，不是装饰 blocking check 定义能不能继续生产；WARN check 定义可观测差异。readiness 必须读 checks 状态，上游 checks 不全绿就不能触发下游。
Sensor 按资产族拆分 cn_a_trade_day_sensor 只注册交易日；index_trade_day_sensor 只注册指数交易日；stock_mins_trade_day_sensor 只注册分钟线 raw 交易日；stock_mins_silver_trade_day_sensor 只注册分钟线 silver 交易日；index_daily_sensor、silver_index_daily_sensor、market_major_indices_daily_sensor、suspend_d_sensor、stock_basic_sensor、stock_namechange_sensor、stock_identity_map_sensor、stock_daily_sensor、stock_adj_factor_sensor、stock_mins_raw_sensor、stock_mins_silver_sensor 分别判断本资产族是否 missing、fresh、checks passed、seed/input ready 或源站 ready，并提交对应 run request。Automation 页面分类使用 sensor definition tags，不通过改名、目录或 run tags 实现。
Sensor 门禁必须轻量 silver_index_daily_sensor 的门禁只读 raw-by-code 文件事实：全部注册指数代码的 raw parquet 文件都存在，且都包含目标交易日数据；market_major_indices_daily_sensor 只查 10 个主要指数 seed code 在注册分区、silver_index_basic 和当日 silver_index_daily 中是否齐备；不在 evaluation 中读取旧 run tags/config。
告警不参与生产 feishu_run_status_sensor.py 只发送 run started/succeeded/failed 通知，默认停止；发送失败只能影响告警可观测日志，不能阻断、重试或回滚任何 asset 写入。
并发保护作为保险丝 先通过 job selection 设计避免重复写；再用 Dagster concurrency 保护 full snapshot 写入。
