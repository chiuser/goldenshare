## 1. 审计目标和口径

本报告记录 WMT-7 正式历史 plan 被 `bse_code_set_mismatch` 阻断后，对股票分钟线 Raw、Silver、`silver_stock_daily` 和 Tushare 当前源站的定点审计事实。

“缺口”定义为：目标交易日存在 Raw/Silver 分区文件，但同日北交所 expected code set 全部缺失或部分缺失。它不等于整个文件不存在。

审计方法：

1. 用 DuckDB 只投影 `ts_code/trade_date/trade_time/vol/amount` 和必要业务 key，按日期/频率聚合北交所代码数。
2. expected latest code set 来自同日 `silver_stock_daily`。
3. 历史 source code 通过 identity map 的 valid range 反查。
4. Tushare 使用显式历史 source code、日期、频率和 fields 做有限样本请求。
5. 单个 Lake 审计动作均远低于 5 分钟；没有做全市场逐行 Python 扫描。
