# AGENTS.md — `qtf/` 财势量化平台规则

## 适用范围

本文件适用于仓库根目录 `qtf/` 及其全部子目录。

## 目录定位

`qtf` 是财势量化平台的独立产品域，负责研究合同、量化计算、实验状态、验证证据和受控发布。它不是 `src/biz`、`src/ops` 或 `scripts/research` 的子目录。

## 依赖边界

1. `qtf` 只允许导入自身与 `src.foundation`。
2. 禁止导入 `src.ops`、`src.biz`、`src.app`、`src.platform`、`src.operations` 或其他 `src` 根模块。
3. 需要数据库、认证、TaskRun 或 Web 能力时，由 `src.app` 组合根注入端口实现；QTF 核心不得自行创建连接或读取应用配置。
4. `contracts` 保持稳定且无框架语义；`engine` 保持纯计算；`application` 只依赖端口；外部 IO 进入 `adapters`。

## 数据与研究边界

1. 上游只能只读正式 Prod 或 Lake；QTF 不清洗、修复、回填或复制来源数据。
2. 不保存输入快照、缓存或副本。
3. 公式必须代码注册并版本化；禁止网页上传或执行任意 Python。
4. 研究、执行、验证、候选和发布状态必须分开，不能从任务成功直接推导研究有效或自动发布。

## 开发要求

1. 严格按已批准里程碑推进，不提前建设后续目录能力。
2. 每个只允许/禁止/状态转换都必须有正反例测试。
3. 改动依赖、持久化合同或跨域端口前必须先做 CodeGraph 影响面分析。
4. 不得把 `scripts/research` 当作运行时依赖或兼容入口。
