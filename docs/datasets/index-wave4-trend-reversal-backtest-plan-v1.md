## 0. 文档定位与暂停边界

本文保存的是一次技术分析学习形成的、可复现的专项研究协议，不是通用波浪识别系统的 V1 需求，也不是当前开发顺序中的必做阶段。

必须遵守以下边界：

1. 通用波浪内核可以把某个阶段识别为 Wave 4，但不自动启用本文的 `P0/P1/P2/P3` 事件、`MACD(7,52,7)`、60 日观察窗口或三分类标签。
2. 本专项未来只能通过独立 `wave4_end` 模块消费通用内核的版本化 pivot、swing 和 scenario 快照；不得反向修改通用 pivot 确认、浪型语法和默认指标参数。
3. 本文的数据审计和规则收敛结论予以保留，但“数据曾经满足门槛”不等于现在应立即开跑。真正重启时必须重新冻结代码版本、数据快照和当时的数据质量结论。
4. 启动前置条件是：通用因果 pivot/swing 内核已验证、场景快照身份与生命周期稳定、场景无关的 outcome/probability 合同已冻结并通过样本外门禁。
5. 在用户单独批准本专项前，不实现事件引擎、不运行回测、不物化专项资产，也不增加前端参数交互。

换句话说：本文负责“以后若研究这个案例，怎样不自欺”；通用主线负责“市场每走出一根 K 线，怎样识别、保留并修正浪型”。

## 1. 研究结论先行

本轮讨论形成的核心认识是：

1. `120 分钟 MACD(7,52,7) DIF 上穿零轴`只能定义为一个候选事件，不能单独判定四浪结束，也不能单独判定牛市起点。
2. 四浪反弹与趋势反转必须分层识别：
   - 第一层：四浪候选触发；
   - 第二层：下降结构被破坏；
   - 第三层：新上升结构成立；
   - 第四层：市场宽度、成交额和趋势状态共同确认牛市状态。
3. “上穿零轴后成功率多少”不能用事后人工数浪回答。必须先冻结无未来函数的波段识别、信号时点和结果标签，再按时间顺序做样本外回测。
4. 2026-08-08 的冻结 Lake 审计显示，主要指数 120 分钟数据覆盖 2009-01-05 至 2026-08-04，并通过覆盖、重复、日内锚点、OHLCV 和 60→120 聚合一致性审计；这证明当时的数据门槛通过，不代表专项已获启动授权。
5. 初版研究不把原方案中的 100 分制直接当真值。先验证各条件的独立增益，再在训练集上确定是否需要评分及其权重。

本文是独立专项的研究方法和验收口径，不是通用技术分析合同，不是交易建议，也不批准任何代码开发、数据写入、Dagster 任务、历史回补或生产变更。

### 1.1 产品默认与研究特例的边界

`7,52,7` 是本专项为了检验“四浪反弹结束”命题而使用的特殊研究参数，不是 120 分钟 K 线的默认 MACD 参数，也不改变产品的默认指标口径：

1. 用户切换到 120 分钟 K 线时，MACD 仍默认使用标准参数 `12,26,9`。
2. 只有用户明确进入四浪结束判断场景并主动选择特殊参数时，才使用 `7,52,7`。
3. K 线周期与 MACD 参数是两个独立状态；切换周期不得隐式切换 MACD 参数。
4. 当前产品尚不支持手动调整 MACD 参数。本回测可以在研究侧独立计算 `7,52,7`，但这不代表前端参数调整功能已经存在或已获开发批准。

## 2. 原命题的技术含义

原命题是：

> 四浪反弹可以应用一致性获利法的时间跨度研究，120 分钟参数调整为 7、52、7，上穿零轴的时候容易形成四浪反弹结束。

将它翻译为可验证语言：

1. 市场已经完成一段客观可识别的下跌结构：下降起点 `P0`、一浪低点 `P1`、二浪高点 `P2`、三浪低点 `P3`。
2. `P3` 之后出现反弹，被暂时视为四浪候选。
3. 在 120 分钟序列上计算 `MACD(7,52,7)`。
4. 当 DIF 从零轴下方上穿零轴时，记录事件时点 `t0`。
5. 观察 `t0` 后市场究竟：
   - 反弹结束并再次跌破 `P3`；
   - 还是突破 `P2`、形成更高低点和更高高点，转为新上升趋势。

### 2.1 MACD 参数真正表达什么

```text
EMA_fast(t) = EMA(close, 7)
EMA_slow(t) = EMA(close, 52)
DIF(t)      = EMA_fast(t) - EMA_slow(t)
DEA(t)      = EMA(DIF, 7)
```

当 `DIF(t-1) <= 0` 且 `DIF(t) > 0` 时，定义为 DIF 上穿零轴。这表示 7 周期均衡价格刚超过 52 周期均衡价格，说明反弹已经修复了相当一部分中期下跌动量。

需要特别注意：

- DIF 是否上穿零轴只由参数 `7` 和 `52` 决定；第三个参数 `7` 影响 DEA 和柱状图，不影响 DIF 的零轴穿越。
- 因此回测“上穿零轴”时，主变量实际是 `EMA(7)` 与 `EMA(52)` 的关系；如果同时使用金叉、柱状图或背离，才需要第三个参数。
- 价格和 DIF 到达零轴附近，既可能意味着反弹接近均衡阻力，也可能意味着趋势刚刚转强。方向不能由 MACD 自身预先决定，必须由结构和后续价格验证。

### 2.2 一致性获利法的时间跨度假设

讨论中提到的自适应参数思路为：以一浪起点到三浪终点的时间长度估算尺度 `X`，再使用近似 `(5X,34X,5X)` 的 MACD 参数。

这部分在 V1 中只保留为后续竞争假设，不进入 V1 主实验，原因是以下口径尚未形成独立、可复现的规则：

1. 时间长度按自然分钟、交易分钟、120 分钟 K 线根数还是交易日计算；
2. `X=L/60` 中 `L` 的单位；
3. 非整数参数如何取整；
4. 参数上限、下限和极端长周期样本如何处理。

V1 只比较固定参数 `7,52,7` 与基准参数；自适应参数另立后续版本，避免用含糊公式制造不可复现结果。

## 3. 研究对象与术语

### 3.1 四个层级必须分开

| 层级 | 名称 | 含义 | 是否可作为牛市结论 |
|---|---|---|---|
| L1 | 四浪候选触发 | `P3` 后反弹，120 分钟 DIF 上穿零轴 | 否 |
| L2 | 下降结构破坏 | 价格先收复一浪低点区域，再有效突破二浪高点 `P2` | 否，只说明原下降结构失效 |
| L3 | 新上升结构成立 | 突破后形成高于 `P3` 的更高低点，并再创新高 | 可以认定结构反转 |
| L4 | 牛市状态确认 | L3 成立，且日线趋势、市场宽度和成交额持续改善 | 可以认定市场状态转强，但仍是概率结论 |

### 3.2 波段端点

下降结构使用以下端点：

```text
P0：下降起点高点
P1：一浪低点
P2：二浪反弹高点，要求 P2 < P0
P3：三浪低点，要求 P3 < P1
```

波段端点不得在回测完成后人工挑选。V1 使用 ATR ZigZag，并保留预先声明的灵敏度测试：

- 基准反转阈值：`1.5 × ATR(14)`；
- 灵敏度阈值：`1.0 / 1.5 / 2.0 × ATR(14)`；
- 120 分钟序列识别候选结构，日线序列确认大级别结构；
- 一个拐点只有在价格反向运行达到阈值后才确认；
- 信号可使用的时间必须是“拐点确认时刻”，不能回填到实际极值时刻。

最后一条是防止未来函数的核心：虽然 `P3` 的最低价发生在更早的 K 线上，但程序只有在后续反弹达到确认阈值时才知道它是低点。

## 6. 无未来函数的事件生成规则

### 6.1 候选下降结构

未来启动时，本专项从通用波浪内核的版本化 confirmed pivot/swing/scenario 快照中选择候选结构，不再独立扫描 K 线生成另一套拐点事实。在 120 分钟序列中寻找连续的 `P0 -> P1 -> P2 -> P3`，并满足：

```text
P2 < P0
P3 < P1
P0、P1、P2、P3 在各自确认时点均已知
```

可增加但不作为初版硬条件的状态过滤：

- 日线收盘价低于 MA60；
- MA60 斜率小于 0；
- `P0 -> P3` 的跌幅超过同期 ATR 或波动率门槛。

这些过滤项必须单独做消融测试，不能先凭经验全部塞入事件池。

### 6.2 四浪候选触发

`P3` 确认后，首次满足以下条件的 120 分钟收盘时刻记为 `t0`：

```text
DIF_7_52(t0 - 1) <= 0
DIF_7_52(t0) > 0
close(t0) > close(P3)
```

只使用 `t0` 收盘前可见的数据。若用于模拟交易，最早执行价是下一根 120 分钟 K 线开盘价，不得使用 `t0` 的收盘价假装提前成交。

### 6.3 重复事件

同一个 `P3` 之后可能多次穿越零轴。第一版规则：

1. 每个 `P3` 只保留第一次上穿零轴为主事件；
2. 后续穿越作为子事件记录，不重复计入主样本成功率；
3. 新的 `P3` 只有在新拐点被确认后才可产生新主事件；
4. 同一指数事件窗口重叠时，报告原始样本数和去重样本数。

## 7. 结果标签：四浪还是反转

### 7.1 固定价格区域

事件发生时冻结：

```text
break_buffer = 0.25 × ATR_daily(20, t0)
P2_break     = P2 + break_buffer
P3_fail      = P3 - break_buffer
```

`0.25 × ATR` 是第一版基准，不是既定真理；同时测试 `0 / 0.25 / 0.5 × ATR`，并且只能在训练集选择参数。

### 7.2 标签观察窗口

主观察窗口为 `t0` 后 60 个交易日，同时报告 20、40、120 个交易日的敏感性结果。

### 7.3 三分类标签

#### A. `wave4_continuation`：四浪反弹后继续下跌

观察窗口内任何日线收盘价先跌破 `P3_fail`，或者即使一度突破 `P2`，随后仍在窗口内跌破 `P3_fail`，标记为四浪反弹后下跌延续。

#### B. `structural_reversal`：原四浪假设失效，新上升结构成立

必须同时满足：

1. 连续两个日线收盘价高于 `P2_break`；
2. 突破后出现一个按同一拐点算法确认的回调低点 `HL`，且 `HL > P3`；
3. 随后收盘价突破突破后的前高，形成更高高点；
4. 整个主观察窗口内没有跌破 `P3_fail`。

该标签表达“下降结构已经反转”，还不自动等于长期牛市。

#### C. `unresolved`：窗口内无法确认

既没有跌破 `P3_fail`，也没有完成“突破 `P2` -> 更高低点 -> 更高高点”的完整结构，标记为未决。不能为了计算一个好看的成功率，把未决样本强行塞进成功或失败。

### 7.4 牛市状态确认标签

在 `structural_reversal` 成立后，再检查后续 20 个交易日是否同时满足：

1. 日线趋势：`MA20 > MA60`、`MA60` 的 20 日斜率大于 0、收盘价高于 MA120；
2. 日线 MACD：DIF 在零轴上方至少持续 5 个交易日，或 10 日中至少 8 日在零轴上方；
3. 市场宽度：按每日有效股票数加权的 5 日上涨家数比例 `AR5 > 55%`；
4. 中期扩散：`P20 > 60%` 且 `P60 > 50%`；
5. 新高新低：新高家数连续 5 日合计大于新低家数；
6. 成交额：全市场成交额满足 `MA5 > MA20 > MA60`。

满足结构反转但不满足上述组合的样本，仍然是结构反转，只是不标记为“牛市状态已确认”。

## 8. 因子量化规则

### 8.1 趋势与动量

| 因子 | 基准定义 | 研究用途 |
|---|---|---|
| 120 分钟零轴穿越 | `DIF_7_52(t-1) <= 0 < DIF_7_52(t)` | 触发事件 |
| 零轴停留 | 连续 6/8/10 根 120 分钟 K 线 DIF > 0 | 检验穿越是否具有持续性 |
| 二次峰值 | 第二个已确认 DIF 峰值高于第一个峰值 | 检验动量扩张，不能事后取峰 |
| 均线多头 | `MA20 > MA60` | 日线趋势确认 |
| MA60 斜率 | `MA60(t) / MA60(t-20) - 1 > 0` | 排除仍在下降的长期均线 |
| 长期站稳 | 收盘价高于 MA120 | 中期趋势确认 |

### 8.2 成交量与成交额

原讨论中的候选阈值保留为待验证参数：

```text
突破量能：breakout_amount > 1.3 × amount_MA20
回调缩量：pullback_amount < 0.8 × breakout_amount
再次放量：restart_amount > amount_MA20
```

对指数自身 `vol/amount` 和全市场 `gold_wealth_market_turnover.total_amount` 分开测试。指数成交量口径在不同指数间可能不可直接比较，跨指数模型优先使用标准化值或全市场成交额。

全市场成交额基准只读取 `build_status=READY` 的 `freq=1` 日汇总行；其他频率用于跨频率对账，不把同一交易日的五个频率重复相加。

### 8.3 市场宽度

所有股票截面指标必须按当时的 `list_date/delist_date` 构造可交易股票池，不能用今天仍上市的股票回看历史。

```text
P20(t) = 当日收盘价 > 当日 MA20 的有效股票数 / 当日有效股票数
P60(t) = 当日收盘价 > 当日 MA60 的有效股票数 / 当日有效股票数
AR5(t) = 最近 5 日 up_count 之和 / 最近 5 日 total_count 之和
NH20(t) = 创近 20 日收盘新高的股票数
NL20(t) = 创近 20 日收盘新低的股票数
```

价格窗口不足 20/60 日的新股不进入对应分母；停牌和无有效收盘价样本必须使用冻结规则处理，并在回测报告中列出剔除数量。

### 8.4 原 100 分方案如何处理

原讨论建议结构 30 分、动量 20 分、量能 15 分、市场宽度 20 分、资金 15 分。这个框架适合表达重要性，但不能直接当成回测标签：

1. 权重尚无历史证据；
2. 当前资金模块数据不完整；
3. 多个指标高度相关，直接相加会重复计分；
4. 先定权重再回测容易产生参数迎合。

第一版采用分层门禁：

```text
触发层：120 分钟 MACD
必要层：价格结构
确认层：日线趋势 + 市场宽度 + 成交额
状态层：结构反转后的持续性
```

只有当消融实验显示因子具有稳定增益后，才在训练集拟合评分权重，并把权重冻结后用于验证集和测试集。资金层缺失时不得把 85 分简单等比例换算为 100 分。

## 9. 回测实验矩阵

### 9.1 参数对照

| 组别 | MACD 参数 | 目的 |
|---|---|---|
| A | `7,52,7` | 检验原命题 |
| B | `12,26,9` | 常用参数基准 |
| C | `5,34,5` | 较敏感参数基准 |

自适应 `(5X,34X,5X)` 不属于 V1 实验矩阵，待单位、取整和上下限另立版本后再执行。

不得先看全样本结果再挑最好参数。参数选择只能发生在训练集，最终测试集只允许跑一次冻结模型。

### 9.2 因子消融

按以下顺序比较：

1. `MACD` 单因子；
2. `MACD + 结构突破`；
3. `MACD + 结构 + 日线趋势`；
4. `MACD + 结构 + 趋势 + 市场宽度`；
5. `MACD + 结构 + 趋势 + 宽度 + 成交额`。

每增加一层都要报告事件数、误判率、未决率和置信区间。若事件数大幅下降但准确率只小幅提高，不能简单认定新因子有效。

### 9.3 周期对照

1. 日线影子模型：用日线近似事件验证方法，并作为周期对照，不代替 120 分钟主模型。
2. 120 分钟正式模型：使用已经通过数据门槛的主要指数 120 分钟线触发，并由日线确认。
3. 不把日线模型的结果冒充 120 分钟参数结论；两者必须单独报告。

## 10. 回测执行规则

### 10.1 时间切分

先生成事件清单和年度分布，再确定具体年份边界。原则固定如下：

1. 按时间顺序切分，不随机打散；
2. 最早约 60% 的事件用于训练；
3. 中间约 20% 用于验证和冻结参数；
4. 最近约 20% 作为一次性测试集；
5. 测试集必须覆盖完整市场阶段，必要时采用滚动扩窗验证；
6. 同一 `P3` 派生的事件不得跨集合泄漏。

如果分钟历史事件太少，则只报告探索性结果，不输出“成功率已验证”的结论。

### 10.2 指标预热

- MACD 至少预热 `3 × slow_period` 根 K 线；
- MA120 至少预热 120 个日线交易日；
- P60 至少预热 60 个有效交易日；
- 新高新低按定义窗口预热；
- 预热期数据只能用于计算，不进入事件统计。

### 10.3 成交与成本

指数信号本身不可直接交易。若后续评估策略收益，必须另行选定可执行载体，例如对应 ETF 或股指期货，并单独处理：

- 下一根 K 线开盘成交；
- 手续费、滑点、冲击成本；
- ETF 上市日期和跟踪误差；
- 期货换月、保证金和基差。

本方案的第一目标是识别结构，不把指数点位变化偷换成可实现交易收益。

### 10.4 V1 版本与数据快照规则

“冻结”只表示研究协议和单次运行快照不可在看到结果后静默修改，不表示 Lake 停止更新。

1. V1 首次正式运行前固定 `model_version`、目标指数池、样本资格、参数、标签、观察窗口、异常处理和时间切分。
2. 每次运行记录 `data_snapshot_id`、数据截止日、代码版本和完整参数；本次基准截止日为 2026-08-04。
3. 训练集可以用于选择预先声明的敏感性参数；验证集用于冻结选择；测试集只允许运行一次冻结后的主模型。
4. 看到验证集或测试集结果后若修改任何主规则，必须升级模型版本并从事件生成阶段重新运行，不能覆盖原结果。
5. 后续 Lake 新增数据只进入新的快照或前向观察，不改变已经发布的 V1 历史分母。

## 11. 评价指标

不能只汇报一个“成功率”。每组实验至少输出：

1. 原始事件数、去重事件数、指数数和年度分布；
2. `wave4_continuation / structural_reversal / unresolved` 数量和比例；
3. 以结构反转为正类的准确率、召回率、误报率；
4. 从 `t0` 到标签确认的时间；
5. `t0` 后 5/10/20/60/120 日收益分布；
6. 最大有利波动 MFE、最大不利波动 MAE；
7. `P3` 跌破率、`P2` 假突破率；
8. 按指数、年份、牛熊阶段、波动率分组的稳定性；
9. 通过事件级 bootstrap 计算的 95% 置信区间；
10. 参数和阈值敏感性，防止单点参数偶然最优。

成功率的分母必须明确：

```text
条件成功率 = structural_reversal / (structural_reversal + wave4_continuation)
未决率     = unresolved / all_events
```

必须同时展示未决率，不能把未决样本从报告中隐藏。

## 12. 示例

以下是说明规则的虚构样本，不是历史行情结论：

```text
P0 = 3400
P1 = 3150
P2 = 3280
P3 = 2850
t0 日 ATR20 = 40
break_buffer = 10
P2_break = 3290
P3_fail  = 2840
```

`P3` 确认后，指数反弹到 3020，120 分钟 `DIF_7_52` 首次上穿零轴，记录 `t0`。

场景 A：指数最高只到 3190，没有有效突破 3290，之后日线收盘跌破 2840。标签为 `wave4_continuation`。这个样本支持“零轴穿越接近四浪反弹结束”的假设。

场景 B：指数连续两日收在 3290 上方，随后回调低点在 3200，之后收盘再创新高至 3340，且 60 日观察窗口内没有跌破 2840。标签为 `structural_reversal`。若同期还满足 MA、宽度和成交额条件，才进一步标记为“牛市状态确认”。这个样本说明零轴穿越也可能发生在新趋势启动阶段。

回测的任务不是选择更符合故事的场景，而是统计两类场景在固定规则下各出现多少次、在哪些条件下更容易出现。

### S0：专项研究协议收敛——已完成

4. 事件明细字段、版本与数据快照规则已经定义。

### S1：专项适配器与无前视验证——暂缓

前置条件：通用内核已经产出经过验证的 confirmed pivot、swing 和 scenario snapshot；本专项不得复制一套平行的 ATR ZigZag 或拐点事实。

1. 实现只读消费通用快照的 `wave4_end` 适配器，以及专项 MACD 和主事件去重；
2. 先生成不含未来标签的事件清单，再单独生成结果标签；
3. 用合成样本和历史逐时截断重放，证明任何时点只使用当时可见数据；
4. 输出分指数、分年份事件数量和因规则被剔除的样本数量，不先计算结论性成功率。

### S2：标签、确认因子与影子回测——暂缓

1. 加入日线结构标签、宽度、成交额和各项预热规则；
2. 跑三组 MACD 固定参数、预先版本化 detector profile、突破缓冲/观察窗口敏感性和因子消融；专项不能在测试集上反向调节通用 detector；
3. 建立训练、验证、测试时间切分，但只查看训练集和验证集；
4. 对典型成功、失败和未决样本做人工核验，人工核验不得修改程序标签。

### S3：120 分钟正式回测——暂缓

数据启动门槛曾在 2026-08-08 的冻结快照上通过：主要指数 60/120 分钟历史覆盖、重复、日内锚点、OHLCV 和 60→120 聚合一致性均合格。专项重启时必须重新审计当前快照，不能把这次历史结论当成永久通过。

1. 冻结训练和验证阶段选出的 V1 参数；
2. 对一次性测试集运行最终模型；
3. 输出事件级明细、参数对照、因子消融、分层结果和置信区间；
4. 只有整体历史和足够长历史的指数跨越多个市场周期后，才形成正式结论。

### S4：前向观察——暂缓

把冻结模型用于后续新事件，持续记录预测时点、当时特征和最终标签。前向样本不得参与模型调参，用于检验历史回测是否过拟合。

## 16. V1 已确认决策

以下是首轮实现和回测必须遵守的 V1 主口径。表中敏感性参数只用于预先声明的对照，不得在全样本或测试集上择优。

| 决策 | V1 口径 | 原因 |
|---|---|---|
| 拐点算法 | ATR ZigZag，基准 `1.5 × ATR14` | 可复现并适应波动率 |

| MACD 参数 | `7,52,7` 为实验组，`12,26,9` 为基准组 | 才能判断特殊参数是否真有增益 |

| 自适应参数 | 不进入 V1 | 当前公式仍有解释歧义 |
| 目标指数池 | 排除北证 50；目标为 10 个非北交所指数 | 用户已确认第一版排除北证 50 |
| 本次主样本资格 | 120 分钟、日线和预热窗口同时可用；当前可执行 9 个指数 | 避免缺失日线的 `000680.SH` 污染分母 |
