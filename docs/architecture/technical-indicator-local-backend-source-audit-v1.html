与目标的差距

  • 本地详情常用指标已由算子库读取 DG 行情并计算。指数技术研究中的顶底识别仍使用 DG 指标成品，波段核对仍从 Prod 读技术因子。指数周月线省略截止日的请求也会查 Prod 确定日期。
  • Prod 指数日线仍有两个成品依赖。除上证综指的算子路径外，日 K 常用指标读取指数日线技术因子。指数九转仍读取独立结果表。
  • Prod 分钟线股票和指数详情均未开放。Prod 已有股票、指数分钟数据，详情页还没有通过算子库消费它们。
  • 盘口和保留接口也有单独的依赖。Prod 股票、指数的盘口仍读取各自技术因子表的行情字段。通用行情接口保留技术因子读法和业务侧计算，仓库内未找到调用方。迁移图表指标后，仍需按实际调用核对这些表的用途。
