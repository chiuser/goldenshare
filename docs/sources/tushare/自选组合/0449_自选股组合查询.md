# 自选股组合查询

- 分类：自选组合
- 原始链接：[https://tushare.pro/document/2?doc_id=449](https://tushare.pro/document/2?doc_id=449)

- 接口：p_get
- 描述：查询组合的成分列表

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| name | str | Y | 组合名称 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| id | int | Y | 编号 |
| ts_code | str | Y | 成分代码 |
| ts_type | str | Y | 成份类型（用户自定义类型，比如按行业、按概念板块或其他） |
| name | str | Y | 名称 |
| desc | str | Y | 描述 |
| weight | float | Y | 权重 |
| create_time | datetime | Y | 创建时间 |
| update_time | datetime | Y | 修改时间 |

## 接口用法

```python
# 初始化pro接口实例
pro = ts.pro_api()


# 查看我的组合列表
df = pro.p_list()
print(df)

# 查看某个组合的成份列表
df = pro.p_get(name="我的股票池", fields="ts_code,create_time,update_time")
print(df)
```
