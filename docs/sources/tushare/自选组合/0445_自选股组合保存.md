# 自选股组合保存

- 分类：自选组合
- 原始链接：[https://tushare.pro/document/2?doc_id=445](https://tushare.pro/document/2?doc_id=445)

- 接口：p_save
- 描述：创建或修改自选股组合
- 限量：每个用户最多200个组合，如需更多请联系管理员

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| name | str | Y | 组合名称 |
| desc | str | N | 描述 |
| items | list | Y | 成份列表; 每个元素包含<br>ts_code:str<br>ts_type:str<br>weight:float<br>name:str<br>desc:str |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| id | int | Y | 主键 |
| ts_code | str | Y | 成分代码 |
| ts_type | str | Y | 成份类型 |
| name | str | Y | 名称 |
| desc | str | Y | 描述 |
| weight | float | Y | 权重 |
| create_time | datetime | Y | 创建时间 |
| update_time | datetime | Y | 修改时间 |

## 接口用法

```python
import tushare as ts

pro = ts.pro_api()

# 选取股票列表
df = pro.stock_basic()
df_stock = df.head(10)
print(df_stock)

# 保存到自定义组合
p_items = df_stock[["ts_code", "name"]]
df_p1 = pro.p_save(name="我的股票池", items=p_items.to_dict(orient='records'))
print(df_p1)
```
