# 基金规模数据

- 分类：公募基金
- 原始链接：[https://tushare.pro/document/2?doc_id=207](https://tushare.pro/document/2?doc_id=207)

- 接口：fund_share，可以通过[**数据工具**](https://tushare.pro/webclient/)调试和查看数据。
- 描述：获取基金规模数据，包含上海和深圳ETF基金
- 限量：单次最大提取2000行数据
- 积分：用户需要至少2000积分可以调取，5000积分以上频次较高，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS基金代码 |
| trade_date | str | N | 交易日期 |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |
| market | str | N | 市场代码；官方页面仅列 SH/SZ，当前实测还接受并返回 O |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 基金代码，支持多只基金同时提取，用逗号分隔 |
| trade_date | str | Y | 交易（变动）日期，格式YYYYMMDD |
| fd_share | float | Y | 基金份额（万） |
| total_share | float | N（实测补充） | 合计份额（万）；只有显式请求后才返回，当前抽样全部为空。 |
| fund_type | str | N（实测补充） | 基金类型；当前源端默认响应已返回，但官方页面和 MCP 字段元数据未完整列出。 |
| market | str | N（实测补充） | 市场；当前源端默认响应已返回，实际值包含 `SH`、`SZ`、`O`。 |

### 实测补充（2026-08-07）

官方页面未列出 `total_share`、`fund_type`、`market` 或分页参数；当前 MCP 字段元数据仍把默认字段描述为前三列，但真实无 `fields` 响应已经包含 `fund_type`、`market`。显式请求六列时才稳定取得 `total_share`，因此接入契约固定为：

```text
ts_code, trade_date, fd_share, total_share, fund_type, market
```

真实验证结果：

1. `trade_date=20260616` 为 1,664 行，SH/SZ/O=`938/708/18`；`trade_date=20260617` 为 1,652 行，SH/SZ/O=`938/707/7`。
2. 项目实际 Tushare connector 以 `limit=1000` 请求 20260616..20260617，页行数为 `1000/1000/1000/316`，共 3,316 行；以 `limit=777` 重拉为 `777/777/777/777/208`。两种分页结果及两个单日结果并集的完整行多重集、摘要均一致。
3. 20260701..20260707 区间分页为 `1000`×8 + `393`，共 8,393 行；与七次逐自然日请求完整行多重集一致。逐日行数为 `1671/1669/1696/0/6/1678/1673`。
4. 2026-07-05 是周日，但源端返回 6 条 O 市场记录；因此 `trade_date` 不能按交易日历裁剪，历史范围必须覆盖每个自然日。2026-07-04 返回 0 行则是合法无事件日。
5. 上述 8,393 行中 `(ts_code, trade_date)` 全部唯一，无内容冲突；SH/SZ/O 为 `4766/3584/43`。`total_share` 全为空，`fund_type` 为空 473 行，但六列仍须全部显式请求和保存。

结论边界：已证明短区间支持 `limit/offset` 分页，不能再把“区间请求不支持分页”作为逐日执行的理由；尚未用任意宽历史区间证明单个超大 unit 的内存和事务可接受。工程上是否逐日拆 unit，应由事务边界、失败隔离和补录粒度决定。

## 接口用法

```python
#初始接口
pro = ts.pro_api()

#单只基金
df = pro.fund_share(ts_code='150018.SZ')

#多只基金
df = pro.fund_share(ts_code='150018.SZ,150008.SZ')
```
