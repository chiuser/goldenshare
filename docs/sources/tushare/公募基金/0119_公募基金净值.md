# 公募基金净值

- 分类：公募基金
- 原始链接：[https://tushare.pro/document/2?doc_id=119](https://tushare.pro/document/2?doc_id=119)

- 接口：fund_nav，可以通过[**数据工具**](https://tushare.pro/webclient/)调试和查看数据。
- 描述：获取公募基金净值数据
- 积分：用户需要至少2000积分才可以调取，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS基金代码 （二选一） |
| nav_date | str | N | 净值日期 （二选一） |
| market | str | N | E场内 O场外 |
| start_date | str | N | 净值开始日期 |
| end_date | str | N | 净值结束日期 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | TS代码 |
| ann_date | str | Y | 公告日期 |
| nav_date | str | Y | 净值日期 |
| unit_nav | float | Y | 单位净值 |
| accum_nav | float | Y | 累计净值 |
| accum_div | float | Y | 累计分红 |
| net_asset | float | Y | 资产净值 |
| total_netasset | float | Y | 合计资产净值 |
| adj_nav | float | Y | 复权单位净值 |
| update_flag | str | N（实测补充） | 更新标识；官方页面当前未列出，但显式请求后源端返回。 |

### 实测补充（2026-08-05）

官方页面未列出 `limit`、`offset` 与 `update_flag`。当前 `tushareMcp` 和 Goldenshare 的 `TushareHttpClient` 实测：`market=O, nav_date=20260617`，以 10 个字段（含 `update_flag`）和 `limit=2000` 连续请求 offset `0..22000`，末页 598 行，共 22,598 个唯一 `(ts_code, nav_date)`；每页均返回同一 10 字段集合。默认单页返回 10,500 行，并非该场外日期样本的全部结果。

同次实测显示：`start_date/end_date` 不能单独作为全市场查询条件。只传这两个参数时，源端返回“`ts_code` 和 `nav_date` 至少填写一个”的参数校验错误；带 `ts_code` 的短区间查询可以返回结果。这是当前源端行为，与页面把日期范围列为可选输入的表述存在边界差异。

2026-08-05 11:17 CST，以 `nav_date=20260805` 和字段 `ts_code,ann_date,nav_date,update_flag` 请求 E、O 两市场均返回空集；同一审计前一日的 O 市场已有 10,500 行。这只记录该时点的可用性样本，未证明稳定发布时刻。

## 接口用法

```python
pro = ts.pro_api()

df = pro.fund_nav(ts_code='165509.SZ')
```
