# 公募基金分红

- 分类：公募基金
- 原始链接：[https://tushare.pro/document/2?doc_id=120](https://tushare.pro/document/2?doc_id=120)

- 接口：fund_div
- 描述：获取公募基金分红数据
- 积分：用户需要至少400积分才可以调取，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ann_date | str | N | 公告日（以下参数四选一） |
| ex_date | str | N | 除息日 |
| pay_date | str | N | 派息日 |
| ts_code | str | N | 基金代码 |

### 实测补充（2026-08-07）

1. 无业务参数会返回 `50101`；`ts_code`、`ann_date`、`ex_date`、`pay_date` 至少传一个。接口没有 `start_date/end_date` 范围查询。
2. `ann_date=20260617` 默认字段与显式 16 字段均返回 122 行，多重集完全一致；市场后缀分布为 OF 116、SZ 2、SH 4。
3. 官方页面和当前 `tushareMcp` 声明未列出分页参数，但项目 connector 实测运行时接受 `limit/offset`：
   - `ann_date=20260617, limit=50, offset=0/50/100/150` 为 `50/50/22/0`，分页并集与不分页 122 行多重集一致；
   - `ann_date=20201215` 为 `50/50/41/0`，分页并集与不分页 141 行多重集一致，包括重复行的出现次数。
4. `ann_date` 必须按自然日请求。周六 `20260613` 返回 40 行、周六 `20070414` 返回 7 行；`20260614` 返回 0 行，空公告日是合法结果。
5. 有界 A/B 验证中，`000001.OF` 与 `500001.SH` 的 `ts_code` 历史多重集，均能由对应 `ann_date` 全市场结果筛选后完整复现，missing/extra 都为 0。该结果支持以 `ann_date` 作为全市场主轴，但只是当前样本证据，不是源端永久 SLA。
6. 当前实测最早公告日候选为 `19990329`。为避免遗漏未来补入的更早记录，历史规模审计建议从当前最早基金成立日 `19980327` 开始扫描；这两个日期都不是 Tushare 永久保证。
7. 历史日期存在 16 字段完全相同的重复行：`20201215` 返回 141 行、74 个完整唯一行，67 个重复组各出现两次；连续三次请求多重集稳定。`20191104` 为 12/6，`20211215` 为 160/82，`20230110` 为 36/21。接入口径已确定为“完全重复只保留一条业务事实”：不保存逐行重复次数，不生成 occurrence 身份；运行级 `rows_deduplicated` 只用于解释源端行数与唯一事实行数的差额。不能把单日 `20260617` 的 122/122 唯一性外推到全历史。
8. 对上述历史重复日、最早候选日和 `20260617` 共 476 个源行的字段剖面显示：`ts_code/ann_date` 0 null；`earpay_date/ear_amount/account_date` 分别有 462/362/178 个 null；四个数值最多 10 个整数位、4 位小数；`base_year` 的非空样本长度为 8。该剖面只用于当前类型与 nullability 设计，不是全历史永久上限。

分页结论只能说明当前运行时接受 `limit/offset`；实现仍须由项目 source client 每页显式携带 16 个字段，满页后按固定 `page_limit` 递增 offset，以短页终止且不设置任意最大页数。
