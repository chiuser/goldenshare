# 公募基金业绩基准库

- 分类：公募基金
- 原始链接：[https://tushare.pro/document/2?doc_id=462](https://tushare.pro/document/2?doc_id=462)
- 接口：`mkt_idx_bmk`
- 描述：获取公募基金业绩基准库中的基准指数参考信息。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | 指数代码 |
| BMK_TYPE | str | N | 基准类型 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 指数代码 |
| symbol | str | Y | 指数简称/代码标识 |
| name | str | Y | 指数名称 |
| fullname | str | Y | 指数全称 |
| bmk_level | str | Y | 基准层级 |
| bmk_type | str | Y | 基准类型 |
| bmk_src | str | Y | 基准来源 |
| idx_type | str | Y | 指数类型 |

## 实测补充（2026-08-05）

当前 Tushare MCP 的无筛选请求返回 141 行和上述 8 个字段；该接口当前展示的输入参数为 `ts_code`、`BMK_TYPE`，未展示分页参数。2026-08-05 通过项目 `TushareHttpClient` 对显式 8 字段实测，`limit/offset` 实际生效：`limit=64` 的页长为 `[64, 64, 13]`，141 条分页并集与无参数基线按完整行内容多重集一致。接入时应使用短页结束的 `offset_limit` 分页。以上为当前实测快照，不表示源端永远不会扩展字段或改变分页语义。
