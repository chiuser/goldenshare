# ETF日线行情

- 分类：ETF专题
- 原始链接：[https://tushare.pro/document/2?doc_id=127](https://tushare.pro/document/2?doc_id=127)

- 接口：fund_daily
- 描述：获取ETF行情每日收盘后成交数据，历史超过10年
- 限量：单次最大5000行记录，可以根据ETF代码和日期循环获取历史，总量不限制
- 积分：需要至少5000积分才可以调取，8000积分频次更高，具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

### 实测补充（2026-08-28）

2026-08-28 使用 `trade_date=20260827` 并显式请求 `ts_code,trade_date`，源端返回 2,113 行，其中 1,019 行为 `.SZ`、1,094 行为 `.SH`，没有 `.OF`。这些代码中有 470 个不在同日取得的当前 `etf_basic` 快照内，但 470 个全部能在 `fund_basic(market='E', status='L')` 中找到，主要是 LOF、REIT 等其他场内基金。

因此当前真实返回范围比接口标题“ETF 日线行情”更宽。这里的按日全集是“该接口当天返回的全部场内基金行情”，不是全部场内外公募基金，也不能假设等于 `etf_basic` 代码集合。`159002.OF` 在 `20260101..20260827` 的对象区间实测返回 0 行；该样本只证明当前查询结果，不应硬编码成接口永久不返回 `.OF`。

### DG 接入 P0 实测补充（2026-09-02）

- 不传 `ts_code` 和 `trade_date` 时，接口返回 `50101` 参数校验错误；二者至少填写一个。DG 的正式执行 unit 因此固定为单个 `trade_date`，不使用无参数全集请求。
- `trade_date=20260901`、显式请求全部 11 个字段、`limit=5000, offset=0` 时，项目 `TushareResource` 返回 2,105 行，第一页即为短页。返回字段与显式字段完全一致。
- 为验证项目分页链，同一日期另以诊断用 `limit=1000` 拉取，得到 `1000 + 1000 + 105` 三页；与正式 `limit=5000` 结果做双向 `EXCEPT ALL`，差异均为 0。这个诊断 limit 只用于验证分页，不改变正式 limit。
- 该日期包含一行 `.OF`：`158008.OF`。因此“当前样本通常只有 `.SH/.SZ`”不能写成 Raw 永久过滤条件；Raw 必须保留接口实际返回，Silver 再按 ETF Basic 筛选。
- 盘中 `20260902 11:39 CST` 查询当日返回 0 行。该结果只证明盘中尚未发布，不能代替 21:00 后可用性验收。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | 基金代码 |
| trade_date | str | N | 交易日期(YYYYMMDD格式，下同) |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |
| limit | int | N | 单次返回数据长度 |
| offset | int | N | 请求数据的开始位移量 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | TS代码 |
| trade_date | str | Y | 交易日期 |
| open | float | Y | 开盘价(元) |
| high | float | Y | 最高价(元) |
| low | float | Y | 最低价(元) |
| close | float | Y | 收盘价(元) |
| pre_close | float | Y | 昨收盘价(元) |
| change | float | Y | 涨跌额(元) |
| pct_chg | float | Y | 涨跌幅(%) |
| vol | float | Y | 成交量(手) |
| amount | float | Y | 成交额(千元) |

## 接口用法

```python
pro = ts.pro_api()

#获取”沪深300ETF华夏”ETF2025年以来的行情，并通过fields参数指定输出了部分字段
df = pro.fund_daily(ts_code='510330.SH', start_date='20250101', end_date='20250618', fields='trade_date,open,high,low,close,vol,amount')
```
