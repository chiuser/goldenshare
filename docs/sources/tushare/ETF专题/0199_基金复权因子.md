# 基金复权因子

- 分类：ETF专题
- 原始链接：[https://tushare.pro/document/2?doc_id=199](https://tushare.pro/document/2?doc_id=199)

- 接口：fund_adj
- 描述：获取基金复权因子，用于计算基金复权行情
- 限量：单次最大提取2000行记录，可循环提取，数据总量不限制
- 积分：用户积600积分可调取，超过5000积分以上频次相对较高。具体请参阅[积分获取办法](https://tushare.pro/document/1?doc_id=13)

### 实测补充（2026-08-28）

2026-08-28 使用 `trade_date=20260827` 并显式请求 `ts_code,trade_date,adj_factor`，通过当前 `tushareMcp` 取得 2,134 行，其中 1,036 行为 `.SZ`、1,098 行为 `.SH`，没有 `.OF`；其中 490 个代码不在同日取得的当前 `etf_basic` 快照内。返回范围因此不能直接等同于 ETF basic 代码集合。

本地源文档仍写“单次最大 2,000 行”，而本次 MCP 结果超过 2,000 行；当前不能仅凭 MCP 外观判断是源端上限变化还是 MCP 内部已分页。工程实现仍必须显式使用 `limit/offset` 并以短页结束为分页门禁，不能把 2,134 当作单页新上限。

`159002.OF` 在 `20260101..20260827` 的对象区间实测返回 0 行。该样本只证明当前查询结果，不足以把“永不返回 `.OF`”写成永久契约。工程 raw 层应保留源端实际返回，ETF serving 再按 ETF 主数据范围发布。

### DG 接入 P0 实测补充（2026-09-02）

- 默认字段仍只有 `ts_code,trade_date,adj_factor`；`discount_rate` 只有显式放入 `fields` 才返回。以 `510330.SH`、`trade_date=20260901` 实测，显式请求返回 `discount_rate=-0.0061`。
- `trade_date=20260901`、`limit=2000` 时，项目 `TushareResource` 实际分页为 `2000 + 138`，合计 2,138 行；第二页是短页，跨页合并后主键无重复。
- 三日样本中的 `discount_rate` 允许为空：`20250102` 有 1 行为空，`20260901` 有 7 行为空。非空值也可能很极端：三个样本的总体最小值为 `-72.4787`，最大值为 `9940.7`。因此 Raw 只做类型保存，不按正负号或绝对值裁剪。
- 不传业务参数时接口会返回最新数据，但会受 `limit/offset` 影响，不能把首个返回页当作完整日分区。DG 的正式执行 unit 仍固定为单个 `trade_date`。
- 盘中 `20260902 11:39 CST` 查询当日返回 0 行。该结果只证明盘中尚未发布，不能代替 21:00 后可用性验收。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | TS基金代码（支持多只基金输入） |
| trade_date | str | N | 交易日期（格式：yyyymmdd，下同） |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |
| offset | str | N | 开始行数 |
| limit | str | N | 最大行数 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | ts基金代码 |
| trade_date | str | Y | 交易日期 |
| adj_factor | float | Y | 复权因子 |
| discount_rate | float | N | 贴水率（%）；必须显式请求 |

## 接口用法

```python
pro = ts.pro_api()

df = pro.fund_adj(ts_code='513100.SH', start_date='20190101', end_date='20190926')
```
