# ETF历史分钟行情

- 分类：ETF专题
- 原始链接：[https://tushare.pro/document/2?doc_id=387](https://tushare.pro/document/2?doc_id=387)

- 接口：etf_mins
- 描述：获取ETF分钟数据，支持1min/5min/15min/30min/60min行情，提供Python SDK和 http Restful API两种方式
- 限量：单次最大8000行数据，可以通过股票代码和时间循环获取，本接口可以提供超过10年ETF历史分钟数据
- 权限：正式权限请参阅 [权限说明](https://tushare.pro/document/1?doc_id=290)

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | ETF代码，e.g. 159001.SZ |
| freq | str | Y | 分钟频度（1min/5min/15min/30min/60min） |
| start_date | datetime | N | 开始日期 格式：2025-06-01 09:00:00 |
| end_date | datetime | N | 结束时间 格式：2025-06-20 19:00:00 |
| limit | int | N | 单页行数，接口上限 8000 |
| offset | int | N | 分页偏移量 |

## freq参数说明

| freq | 说明 |
| --- | --- |
| 1min | 1分钟 |
| 5min | 5分钟 |
| 15min | 15分钟 |
| 30min | 30分钟 |
| 60min | 60分钟 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | ETF代码 |
| trade_time | str | Y | 交易时间 |
| open | float | Y | 开盘价 |
| close | float | Y | 收盘价 |
| high | float | Y | 最高价 |
| low | float | Y | 最低价 |
| vol | int | Y | 成交量（股） |
| amount | float | Y | 成交金额（元） |
| freq | str | N | 分钟频度；显式请求时返回 |
| vwap | float | N | 成交均价；显式请求时返回 |
| exchange | str | N | 交易所；显式请求时返回 |

## 当前真实行为验证

- `ts_code` 与 `freq` 都是必填参数。
- 只传 `ts_code/freq` 不等于全历史：`510300.SH + 1min` 实测返回 1,446 行，仅覆盖最近约 6 个交易日。
- 显式请求 `ts_code,freq,trade_time,open,close,high,low,vol,amount,vwap,exchange` 时，`freq/vwap/exchange` 均可返回。
- `limit/offset` 实测生效：同一 6 行窗口以 `limit=3` 请求，`offset=0/3/6` 分别返回 `3/3/0` 行，分页合并唯一键与不分页结果一致。
- 返回顺序实测为 `trade_time` 倒序，调用方不得依赖源端顺序完成幂等。

## 接口用法

```python
pro = ts.pro_api()

#获取沪深300ETF华夏510330.SH的历史分钟数据
df = pro.etf_mins(ts_code='510330.SH', freq='1min', start_date='2025-06-20 09:00:00', end_date='2025-06-20 19:00:00')
```
