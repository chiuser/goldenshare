# ETF申赎清单

- 分类：ETF专题
- 原始链接：[https://tushare.pro/document/2?doc_id=407](https://tushare.pro/document/2?doc_id=407)

- 接口：etf_sh_cons
- 描述：获取上交所 ETF 申赎清单成分明细数据。
- 限量：支持 `limit / offset` 分页。本地实测单页使用 `limit=3000` 可正常返回。
- 权限：以 Tushare 当前账号权限为准。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | ETF代码，如 `510300.SH` |
| trade_date | str | N | 交易日期，格式 `YYYYMMDD` |
| start_date | str | N | 开始日期，格式 `YYYYMMDD` |
| end_date | str | N | 结束日期，格式 `YYYYMMDD` |
| limit | int | N | 单次返回数据长度 |
| offset | int | N | 请求数据的开始位移量 |

## 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| trade_date | str | Y | 交易日期 |
| ts_code | str | Y | ETF代码 |
| con_code | str | Y | 成分证券代码 |
| con_name | str | Y | 成分证券名称 |
| qty | float | Y | 证券数量 |
| sub_flag | str | Y | 现金替代标志 |
| cpr | str | Y | 现金替代溢价比例 |
| rdr | str | Y | 申购赎回替代比例 |
| sca | str | Y | 替代金额 |
| exchange | str | Y | 成分证券交易所 |

## 接口用法

```python
# 获取单只ETF在指定交易日的申赎清单
df = pro.etf_sh_cons(ts_code="510300.SH", trade_date="20260618")

# 获取单只ETF在一段日期区间内的申赎清单
df = pro.etf_sh_cons(ts_code="510300.SH", start_date="20260601", end_date="20260618")

# 分页获取
df = pro.etf_sh_cons(ts_code="510300.SH", trade_date="20260618", limit=3000, offset=0)
```

## 本地实测补充

本节记录接口真实返回行为，用于补足源站页面无法直接抓取时的接口事实。

| 请求形态 | 实测结论 |
| --- | --- |
| 不传业务参数，仅传 `limit=1, offset=0` | 可返回默认页。 |
| `trade_date + ts_code` | 可返回指定 ETF 在指定交易日的清单。 |
| `ts_code + start_date/end_date` | 可返回指定 ETF 在区间内的清单。 |
| 多个 `ts_code` 逗号拼接 | 样本请求返回 0 行。 |
| `ts_code` 通配符 | 样本请求返回 0 行。 |
| 默认字段 | 默认返回字段包含本文列出的 10 个输出字段。 |
| 显式字段 | 显式请求本文列出的 10 个字段可正常返回。 |
