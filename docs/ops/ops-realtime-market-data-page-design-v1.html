页面区域与 API 字段

设计稿中的每块信息都必须来自健康 API，不允许前端拼 Redis key。

前端页面 API
GET /api/v1/ops/realtime/stock-rt-daily/health
GET /api/v1/ops/realtime/stock-rt-min/health
页面只调用这两个 Ops health API。进入页面时先分别读取一次；只有对应 health API 返回 page_polling_enabled=true 时，才按 recommended_poll_interval_seconds=60 每 1 分钟局部更新对应分组的状态区域、批次信息、错误信息和指标展示。午休、收盘后、夜间、非交易日、feed disabled 时不持续轮询。不得整页刷新，不得重新挂载整个页面，避免页面闪烁；它不触发 collector，不请求 Tushare，不写 Redis；页面也不得直接读 Redis、自行计算 stale、current batch 或分钟频率列表。
状态字段 展示 说明
status=ok 正常 采集时段内最近 feed 阈值窗口发布过新批次；日线阈值 20 秒，分钟阈值 90 秒。
status=idle 空闲 非采集时段，不请求源站，不是失败。
status=stale 滞后 采集时段内超过 feed 阈值未发布新批次，但旧批次可读。
status=unavailable 不可用 Redis 不可连接，或没有 current batch。
页面区域 字段来源 展示含义
当前总状态 status / current_batch_age_seconds 实时 feed 是否可用，不代表离线数据集状态。
当前批次 current_batch_id / snapshot_count API 当前可读批次和批次内股票快照数量。
上游请求 last_request_at / source_row_count / source_elapsed_ms Tushare 0372 日线或 0374 分钟请求是否稳定、返回是否正常。
采集窗口 is_trading_day / collection_sessions / collection_status 判断当前是否应该请求 Tushare，非交易日显示休市，非采集时段显示空闲。
限速 request_count_last_minute / max_calls_per_minute 确认 collector 没有超过 feed 级限速。
Redis 保留策略 snapshot_ttl_seconds / keep_recent_batches 确认当前批次保留 72 小时且只保留最近 3 批。
Stream 事件 last_batch_event_id / last_delta_event_id / delta_count_last_batch 展示最近批次事件、最近逐股票变化事件和本批次变化股票数量。
页面轮询 page_polling_enabled / recommended_poll_interval_seconds 只在交易日交易时段内启用 1 分钟局部刷新；其他时段停止定时轮询。
异常信息 last_error_at / last_error_message 只展示最近错误，不堆叠重复日志。

刷新链路

让运营知道“数据什么时候从服务器请求 Tushare，又如何进入 Redis”。

1
判断采集窗口 只在交易日 9:30-11:30、13:00-15:00 请求源站；非交易日显示休市，非采集时段更新空闲状态。
2
采集时段内请求 Tushare 0372 rt_k(ts_code="3*.SZ,6*.SH,0*.SZ,9*.BJ")
3
写入新 batch 先写 batch 下的 snapshot、index、meta，再写 batch stream 和 delta stream，读请求此时仍看旧 batch。
4
切换 current pointer 最后一步原子切换，API 要么读旧批次，要么读新批次。
5
页面读取健康状态 Ops 页面只读健康 API，不直接读 Redis，不触发采集。
操作边界
本页不提供“手动同步”“重新提交”“停止处理”。实时流是常驻服务，运营只查看健康和错误。
错误态文案
实时流监控暂不可用。系统没有可读的 Redis 当前批次，请检查 collector、Redis 和上游 Tushare 请求。若当前为非交易日或非采集时段，应显示“休市/空闲”，不应显示失败。
设计结论：实时流监控作为一级菜单展示，页面只关心实时 feed 健康。它不是任务中心页面，也不是数据集新鲜度页面。V1 仅在交易日 9:30-11:30、13:00-15:00 请求源站；stale 阈值只用于采集时段内，当前日线为 20 秒、分钟为 90 秒。
