公共事实对象一条记录代表什么组合后已经表达的事实哪些审计直接使用建议如何提供查询
01 公共合法日历事实日历范围 × 每个自然日一个日期同时带开市、周/月收盘日、自然周期标签、报告期末等标识。全部有日期含义的数据集值得持久化为小型日期表；所有日/周/月/报告期审计共用。
02 市场交易时段事实交易所/市场 × 交易制度有效期 × 交易阶段保存开盘集合竞价、连续交易、收盘集合竞价等阶段的起止时间与时区。股票/基金交易事实、集合竞价、分钟数据按有效期保存少量规则记录，每日生成股票事实时引用。

生成工作集中在事实生产任务。审计读取已经组合好的事实；不同数据集直接共享当天记录。九类逻辑对象按复用价值选择落表或视图，采用现有来源及有效期关系。

公共事实输入来源生成 / 更新时间复用方式
公共合法日历事实已确认可靠的trade_cal + 自然日期规则按已有日历覆盖范围提前生成，随日历扩展补充新日期。值得持久化为小型日期表；所有日/周/月/报告期审计共用。
市场交易时段事实现行市场交易制度和源K线时间标签合同预置当前规则，交易制度变化时新增生效版本。按有效期保存少量规则记录，每日生成股票事实时引用。
每日上市股票交易事实公共日历 + 股票基础信息/代码映射 + 停复牌 + 市场交易时段盘后基础信息更新后，按日期生成一次；更正时只更新受影响的日期和股票。持久化每日事实；一只股票一天一条，日内区间放在同一条记录中。
每日场内基金/ETF交易事实基金/ETF基础信息 + 交易场所日历与时段 + 基金自身交易状态随场内基金基础信息和交易状态，按日期生成。与股票采用同类日期对象结构；股票与基金各用自己的交易状态来源。
每日指数/板块有效对象事实index_basic、DC/THS目录、申万分类、现有服务池目录或服务池更新后刷新对应日期；历史按生效区间读取。复用目录与有效期，按日提供统一查询；活跃池变动保留生效日期。
每日成员/篮子事实同日成员清单、历史入出关系、指数权重、ETF篮子和基金披露持仓跟随名单发布或成员变更更新；按日期取有效版本。优先复用现有名单，用有效期/版本及视图提供按日查询；每组人数保存为小型汇总。

源采集与交付批次事实现有维护请求、源分页结果、Raw提交与交付记录每个完成的采集单元形成一份可读事实，后续审计直接复用。优先整理现有TaskRun/节点和提交记录为统一查询；补充已有记录尚未表达的业务完成字段。

每日股票事实的生成任务

  1. 按公共日期事实取当天开市标记；开市日生成股票事实，休市日由公共日期事实直接表达。
  2. 一次读取当天有效的上市股票和代码映射，一次读取当天停复牌记录，并取得适用市场时段规则。
  3. 按股票汇总全天停牌、分时停牌和复牌状态，生成当天有效交易区间。
  4. 以 business_date + ts_code 保存当日一批事实，所有股票日级、竞价和分钟审计复用。
  5. 后续更正只更新受影响日期和股票；目录与成员按发布/生效变更更新相关事实。
