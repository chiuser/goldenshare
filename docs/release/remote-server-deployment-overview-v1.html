6. 部署脚本与发布方式

部署入口仍然是仓库内脚本，远程必须使用 goldenshare 用户执行，避免 Git 目录所有权问题。

ssh goldenshare-prod 'sudo -n -u goldenshare /bin/bash -lc "cd /opt/goldenshare/goldenshare && bash scripts/deploy-systemd.sh dev-interface"'
命令/参数当前语义
bash scripts/deploy-systemd.sh dev-interface全量部署：拉代码、安装后端依赖、构建运营后台、构建财富前端、迁移 DB、重启服务、健康检查。
--platform-only只发布 Web/API 层；当前已收紧为默认不处理 realtime collector。
--ops-only只发布 Ops 调度层。
--foundation-only只发布 Foundation worker 层。
--with-realtime在非全量部署中显式带上 realtime collector。
--skip-realtime全量部署时显式跳过 realtime collector。
--skip-build同时跳过 frontend 与 wealth 构建。
--skip-wealth-build仅跳过财富系统前端构建。

本地推送到 GitHub 后，远程 Gitee 镜像通常需要 30 秒到 1 分钟同步。若远程拉不到最新提交，应按最多 3 次重试规则等待，不应手工打 patch。
