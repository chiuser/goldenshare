## 2. 目标

报表回答三个核心问题：

1. `2026H1` 相比 `2025H1`，哪些东财行业整体增收增利，哪些行业改善质量不足或正在恶化？
2. `2026Q2` 相比 `2026Q1`，哪些东财行业正在加速，哪些行业正在转弱？
3. 从 `2025Q1` 到 `2026Q2`，哪些行业持续景气上升、仅出现边际改善、正在边际转弱或持续景气下降？

“行业整体”必须同时看三类证据：

1. **规模**：行业配对样本的营业总收入、归母净利润、扣非净利润、经营现金流合计如何变化。
2. **广度**：行业内有多少家公司改善、恶化、扭亏或转亏。
3. **质量与风险**：利润率、ROE、现金质量和杠杆是否同步改善。

报表不是股票推荐工具，不生成投资评级、买卖结论或黑箱综合分数。

## 4. 当前事实与可行性基线

以下是 2026-08-30 的 Prod 只读审计基线，只用于锁定方案能力，不直接作为最终报表结果：

### 4.1 东财行业快照

1. `2026-06-30`、`idx_type='行业板块'` 包含 31 个东财一级行业、128 个东财二级行业和 337 个东财三级行业。
2. 东财一级行业包含 5,606 家公司、5,606 条成员关系，同一家公司没有重复一级行业归属。
3. 东财二级行业包含 5,611 家公司、5,611 条成员关系，同一家公司没有重复二级行业归属。
4. 数据库存储的层级值是 `东财一级行业`、`东财二级行业`、`东财三级行业`，实现不得使用错误的简写值过滤。
5. `2025-06-30` 行业历史快照不完整，因此同比和环比均固定使用 `2026-06-30` 成员，避免成分变化污染财务变化。

### 4.2 三张报表与配对覆盖

三张报表已完成 `2025-01-01 ~ 2026-08-31` 初始维护和 Prod 验收，raw 保存全部源站版本，serving view 提供每个公司、每个报告期唯一最新合并报表。

在 5,606 家东财一级行业成员中，关键字段的配对公司数为：

| 比较 | 利润表 | 现金流量表 | 资产负债表 |
| --- | ---: | ---: | ---: |
| `2026H1 vs 2025H1` | 5,366 | 5,505 | 5,365 |
| `2026Q2 vs 2026Q1` | 5,363 | 5,502 | 5,363 |

这些数量足以支持一级行业和主要二级行业分析；最终报表仍必须逐行业展示真实分母与覆盖率。

### 4.3 字段覆盖

1. `total_revenue` 和 `n_income_attr_p` 在四个关键报告期接近全覆盖，可作为营收和归母净利润的绝对金额主字段。
2. `n_cashflow_act` 接近全覆盖，可作为经营活动现金流绝对金额主字段。
3. `total_assets`、`total_liab` 接近全覆盖，可用于行业资产规模和聚合资产负债率。
4. `fina_indicator.profit_dedt` 可提供扣非净利润累计金额，`q_dtprofit` 可提供单季度扣非净利润；质量指标和增长率字段覆盖充足。
5. `income.net_after_nr_lp_correct` 当前没有有效覆盖，禁止把它作为扣非净利润主字段。

这表示：

## 7. 比较期与单季度推导

### 7.1 半年报同比

比较：`2026-06-30` 对 `2025-06-30`。

利润表和现金流量表均使用半年累计金额；资产负债表使用两个期末时点值。

### 7.2 第二季度环比

比较：`2026Q2` 对 `2026Q1`。

利润表和现金流量表是年初至报告期末的累计值，因此：

```text
2026Q1 单季金额 = 2026-03-31 累计金额
2026Q2 单季金额 = 2026-06-30 累计金额 - 2026-03-31 累计金额
```

该公式分别应用于：

- `total_revenue`
- `n_income_attr_p`
- `n_cashflow_act`

资产负债表是时点数据，不做相减：直接比较 `2026-06-30` 与 `2026-03-31`。

`fina_indicator.q_sales_qoq`、`q_netprofit_qoq`、`q_profit_qoq` 只用于方向交叉核对，不替代绝对金额推导。

### 7.3 六季度景气趋势

趋势面板固定使用 `2025Q1、2025Q2、2025Q3、2025Q4、2026Q1、2026Q2` 六个季度。由于当前 Prod 中 `2024Q1~Q3` 三张财务报表不完整，报表不虚构 2025 年行业绝对金额同比；趋势判断使用源端已经计算并落库的公司单季度同比字段：

- 营收：`q_sales_yoy`
- 归母净利润：`q_netprofit_yoy`

每个季度仍使用固定的 `2026-06-30` 一级行业成员，分别计算行业内公司增长率中位数和正增长公司占比。该趋势面板用于判断公司改善的方向、广度和持续性，不能替代 2026H1 的行业绝对金额合计分析。

## 8. 配对样本与行业汇总

### 8.1 每个指标独立配对

每个指标、每个比较维度必须建立自己的配对公司集合：

1. 公司属于固定行业成员。
2. 当前期和比较期的该指标均非空。
3. 单季度推导所需的累计值均存在。
4. 同一行业当前期和比较期必须使用完全相同的公司集合求和。

禁止当前期用 100 家、比较期用 95 家后直接比较总额。不同指标的有效样本数可以不同，必须分别展示。

### 8.2 绝对金额汇总

对配对公司分别求和：

```text
行业当前期合计 = sum(当前期公司金额)
行业比较期合计 = sum(比较期公司金额)
行业金额变化 = 当前期合计 - 比较期合计
```

营收增速仅在比较期营收合计大于 0 时计算：

```text
行业营收增速 = 行业当前期营收合计 / 行业比较期营收合计 - 1
```

### 8.3 利润状态

利润合计可能为负，不能一律计算百分比：

| 比较期利润 | 当前期利润 | 展示规则 |
| --- | --- | --- |
| 正 | 正 | 展示利润增速和金额变化 |
| 负或零 | 正 | 标记“行业整体扭亏”，展示金额变化，不展示虚假百分比 |
| 正 | 负或零 | 标记“行业整体转亏”，展示金额变化 |
| 负 | 负且绝对亏损减少 | 标记“亏损收窄” |
| 负 | 负且绝对亏损扩大 | 标记“亏损扩大” |
| 零 | 零 | 只展示金额，不计算百分比 |

该规则同时适用于归母净利润和扣非净利润。

## 9. 指标体系

### 9.1 规模主指标

| 维度 | 字段 | 半年同比 | 二季度环比 |
| --- | --- | --- | --- |
| 营业总收入 | `income.total_revenue` | 两期配对合计 | H1-Q1 得到 Q2，再与 Q1 比较 |
| 归母净利润 | `income.n_income_attr_p` | 两期配对合计与利润状态 | H1-Q1 得到 Q2，再与 Q1 比较 |
| 扣非净利润 | `fina_indicator.profit_dedt` / `q_dtprofit` | 累计金额配对 | 使用单季度 `q_dtprofit` |
| 经营活动现金流 | `cashflow.n_cashflow_act` | 两期配对合计 | H1-Q1 得到 Q2，再与 Q1 比较 |
| 总资产 | `balancesheet.total_assets` | 两期末配对合计 | Q2 期末对 Q1 期末 |
| 总负债 | `balancesheet.total_liab` | 两期末配对合计 | Q2 期末对 Q1 期末 |

### 9.2 行业聚合质量指标

| 指标 | 算法 | 作用 |
| --- | --- | --- |
| 聚合净利率 | `sum(n_income_attr_p) / sum(total_revenue)` | 判断行业收入转化为归母利润的能力 |
| 聚合经营现金流收入比 | `sum(n_cashflow_act) / sum(total_revenue)` | 判断收入是否转化为经营现金流 |
| 聚合资产负债率 | `sum(total_liab) / sum(total_assets)` | 判断行业改善是否伴随杠杆变化 |

上述比率必须使用同一配对样本的分子和分母。分母小于等于 0 时不计算。

### 9.3 公司分布与交叉验证

从唯一化后的 `fina_indicator` 计算：

1. 营收、归母净利润、扣非净利润正增长公司占比。
2. 毛利率、净利率、ROE、经营现金流收入比的公司中位数变化。
3. P25/P50/P75 和 P5-P95 缩尾均值。
4. 扭亏、转亏、连续亏损收窄、连续亏损扩大公司数和占比。
5. `or_yoy/q_sales_qoq` 与绝对金额结果的方向一致性。
6. `netprofit_yoy/q_netprofit_qoq` 与绝对金额结果的方向一致性。

增长率中位数是“公司广度”证据，不再替代行业总量增速。

### 9.4 公司类型与指标适用性

`comp_type` 表示报表科目体系：`1` 一般工商业、`2` 银行、`3` 保险、`4` 证券；源站还可能出现其他值，例如 `7`。

1. `total_revenue`、`n_income_attr_p`、`total_assets`、`total_liab` 等跨类型主字段按实际非空值参与配对。
2. 毛利率、存货、应收账款等行业专属指标不用于金融行业主结论。
3. 任一指标有效覆盖率不足 70% 时标记“指标不适用或样本不足”，不填 0、不强行排名。
4. 资产负债率对金融行业只展示行业自身的时序变化，不参与跨行业高低排名。

### 9.5 景气趋势指标

每个一级行业、每个季度计算以下六项可回查指标：

1. `q_sales_yoy` 中位数和正增长公司占比。
2. `q_netprofit_yoy` 中位数和正增长公司占比。
3. `q_netprofit_margin`、`q_roe`、`q_ocf_to_sales` 中位数。

行业至少需要 10 家有效公司，且营收、利润同比字段覆盖率分别达到 70%，才进入景气分类。缺失值不填零，样本不足时直接标记“样本不足”。

## 10. 行业结论规则

### 10.1 主标签

主标签由行业配对样本的营收合计方向和归母净利润状态共同决定：

| 营收 | 归母净利润 | 主标签 |
| --- | --- | --- |
| 增长 | 增长或整体扭亏 | 增收增利 |
| 增长 | 下降、转亏或亏损扩大 | 增收不增利 |
| 下降或持平 | 增长、整体扭亏或亏损收窄 | 减收增利 |
| 下降或持平 | 下降、转亏或亏损扩大 | 营收利润双降 |

半年同比和二季度环比分别生成标签，不能合并成一个结论。

### 10.2 质量标签

根据配对样本增加透明标签：

1. 扣非利润同步改善 / 与归母利润背离。
2. 经营现金流同步改善 / 利润现金背离。
3. 净利率改善 / 恶化。
4. 杠杆上升 / 下降。
5. 改善广泛 / 少数公司驱动 / 行业内部分化。

不生成加权总分。排序默认以归母净利润状态和营收增速为主，样本覆盖率始终并列展示。

### 10.3 六季度景气分类

景气判断不使用黑箱总分。计算层使用以下四类相邻季度信号，页面只展示由这些信号产生的直接财务证据，不展示内部计分：

1. **需求**：营收同比中位数较上季度改善或恶化，`1` 个百分点以内视为持平。
2. **盈利**：利润同比中位数较上季度改善或恶化，`1` 个百分点以内视为持平。
3. **广度**：营收与利润正增长公司占比的合计方向，`2` 个百分点以内视为持平。
4. **质量**：净利率、ROE、经营现金流收入比三个中位数中，多数同向才定义改善或恶化，单项 `0.5` 个百分点以内视为持平。

需求、盈利、广度、质量中至少两项同向，才将单季度阶段定义为上行或下行；否则为“震荡分化”。当前水平由营收、利润同比中位数及各自正增长公司占比共同判断，用于区分“加速上行/低位修复”和“高位降温/加速下行”。

最终标签强调持续性：

| 条件 | 标签 |
| --- | --- |
| 最新两个季度连续处于上行阶段 | 景气上升 |
| 最新季度转为上行，但尚未连续两个季度 | 边际改善 |
| 最新两个季度连续处于下行阶段 | 景气下降 |
| 最新季度转为下行，但尚未连续两个季度 | 边际转弱 |
| 最新季度没有形成明确同向信号 | 震荡分化 |

因此，“景气上升/下降”是连续两季度确认后的结论；单季波动不会被夸大成行业趋势反转。

## 11. 样本门禁

行业只有同时满足以下条件才给出明确方向标签：

1. 指标配对公司不少于 10 家。
2. 指标覆盖率不低于该行业固定成员的 70%。
3. 行业当前期和比较期使用同一配对公司集合。
4. 营收比较期合计大于 0，才展示营收百分比增速。

不满足时标记“样本不足”，保留金额、样本数和缺失原因，但不参与排名。

一级行业和二级行业分别执行门禁，不共享覆盖率。

## 12. HTML 报表结构

本版采用“先回答、再给证据、最后下钻”的阅读顺序。页面不展示 `current_level_score`、`momentum_score`、内部阶段分或重复的趋势标签。

### 12.1 报表头部

展示：

1. `Executive Summary` 直接回答持续改善、开始转弱、持续转弱和方向分化行业数量。
2. 三张概览卡分别展示改善、转弱和分化行业数。
3. 明确提示本报告判断的是“行业财务景气”，不是包含订单、产量、库存和就业的完整宏观景气指数。
4. 生成时间、数据截止时间、行业成员快照和样本门禁放在口径说明中。

### 12.2 全市场概览

首页按三类可直接理解的证据展开：

1. **幅度**：2026Q2 行业营收同比中位数、利润同比中位数及其较上季度变化。
2. **广度**：行业内利润正增长公司占比，避免把少数大公司改善误当成全行业改善。
3. **持续性**：同一改善、转弱或分化方向连续出现的季度数。
4. 用营收同比为横轴、利润同比为纵轴展示 31 个一级行业的当前分布。
5. 用正负横向柱展示利润同比较上季度改善和转弱幅度最大的行业。

### 12.3 行业财务景气分布

横轴为行业内公司 `q_sales_yoy` 中位数，纵轴为 `q_netprofit_yoy` 中位数。零轴把增减方向直接分开，气泡大小为行业公司数，颜色表示“持续改善、开始改善、方向分化、开始转弱、持续转弱”。

图中不得出现内部综合分数；鼠标提示只展示直接指标、较上季度变化、改善公司占比和持续季度数。

### 12.4 一级行业总表

31 个一级行业只分成“改善方向、分化观察、转弱方向”三组，完整展示且不翻页。每行只保留六个读者最需要的字段：行业、当前判断、营收同比、利润同比、利润增长公司占比和持续季度数。

更细的绝对金额、现金流、杠杆和样本覆盖留在后续验证与下钻区域，避免主表横向过宽。

### 12.5 二级行业下钻

选择一级行业后，展示其二级行业的同口径结果。样本不足的二级行业保留展示，但不参与强弱排名。

### 12.6 行业详情

自动选择持续改善、开始改善、开始转弱、持续转弱四类代表行业，分别用六季度分组柱展示营收与利润同比中位数。六个报告期是离散比较，不用短折线制造连续走势错觉。

二级行业内部差异和主要公司驱动继续保留。公司只能称为“指标改善靠前/恶化靠前”，不得直接称为投资机会或风险股票。

## 16. 已确认决策

> **D1：行业层级。一级行业作为主视图，二级行业作为下钻，首版不展示三级行业。**

三级行业数量多且小样本比例高，会削弱首版重点。

> **D2：主结论。以行业绝对金额合计为主，以公司增长中位数和正增长占比解释改善广度。**

三张报表已接入，继续只看增长率中位数会浪费已经具备的总量能力。

> **D3：行业成员。固定使用 `2026-06-30` 东财行业成员。**

2025 年同期行业快照不完整，固定成员也能隔离成分变化。

> **D4：扣非净利润。半年累计使用 `fina_indicator.profit_dedt`，单季度使用 `q_dtprofit`。**

利润表中的 `net_after_nr_lp_correct` 当前无有效覆盖，不能作为主字段。

> **D5：样本门禁。至少 10 家配对公司且覆盖率达到 70%。**

该门禁同时约束总量标签和公司分布标签，避免少量公司代表整个行业。

> **D6：版本节奏。现在先生成初版；半年报基本披露完并重新同步后，使用同一生成流程产出正式版。**

初版必须明确标记“初版”，展示准确生成时间、各数据源最新抓取时间和真实样本覆盖率，不把披露中的结果表述为最终结论。正式版不修改计算口径、不手工调整数字，只在三张报表和财务指标完成后续同步后重跑同一生成流程，并以实际生成时间作为正式数据截止时间。
