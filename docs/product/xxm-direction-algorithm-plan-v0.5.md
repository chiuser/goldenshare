## 2. 怎样分段、取价和选参照

当前使用MACD柱符号分段：正柱为正段、负柱为负段，零柱也会使段发生变化。每个非零段结束时存入对应方向的历史池；每个方向只留最近两个已结束段。

每段保存整个段截至当根的最高/最低收盘价及DIF极值，两者位置分别记录。正段取最高收盘、最高DIF；负段取最低收盘、最低DIF。**不是按每个局部DIF峰建立不同参照，也不是从DIF峰后才开始统计价格。**

零柱切段后，旧非零段也会入池；目前没有单独检查两段之间必须实际出现反色柱。因此红→零→红也可能检查前红段，绿柱镜像。不能把研究要求的“必须反色分隔”写成现代码已严格满足。

首次钝化检查使用以下顺序：

1. 当前段非零、至少两根，且存在同向历史段；顶部还要求**当根DIF>0**，底部没有对应的DIF<0条件。
2. 当前整个正段最高收盘先严格高于最近旧正段最高收盘；底部则当前整个负段最低收盘先严格低于最近旧负段最低收盘。不满足最近段价格门槛就不继续。
3. 将池内至多两段按DIF强弱排序：顶部优先较高旧DIF，底部优先较低旧DIF。选择同时满足本段价格突破、DIF严格背离的首个段；相同DIF按原逆时间顺序保留较近者优先。
4. 顶部要求当前段最高DIF严格低于所选旧DIF，底部要求当前段最低DIF严格高于旧DIF；相等不首次成立。成立后输出DULL。

这里首次取价是**本段累计收盘极值**，不是统一以最新一根收盘检查。最新价已经回落、但本段先前极值已越过旧价时，仍可能首次激活；不能将之后的研究试验行为当产品事实。

依据：[分段及段内极值](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:34)、[首次资格](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:92)、[参照选择](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:161)。

## 3. 钝化、形成结构、纠错和取消

### 3.1 同一柱色段内

当前转折门槛是`abs(上一根DIF) × 1%`，比较本根与上一完成根DIF的差；上一根DIF为0时不走这条转折判断。

| 当前情况 | 当前代码处理 |
|---|---|
| 有DULL，顶部DIF向下/底部DIF向上，变化达到或超过1% | 输出STRUCTURE，状态变STRUCTURE |
| 有STRUCTURE，DIF又朝原方向转回且达到1% | 顶部回DULL；底部另核本根价格资格，可能回DULL，也可能进入NONE加等待，见第4节 |
| 已有活动参照，本段DIF极值严格越过该参照 | 输出CANCEL，普通状态变NONE，参照清空；原值相等不取消 |
| 变化不足门槛，或本根DIF等于上一根DIF | 不因这条转折路径新增事件；恰好达到1%仍按上面的形成/纠错分支处理，价格回落也不是普通DULL独立取消条件 |

首次激活与同段转折是同一组条件中的不同分支，所以r2不会在首次DULL那根再接着生成一个STRUCTURE。当前普通事件通常最多一项，但可以和独立历史撤销事件同根共存。

### 3.2 柱色变化与零柱

原段直接切到反色时，先按原参照检查当根DIF是否严格突破：突破则CANCEL；未突破且原普通状态是DULL，则通过`color_flip`形成STRUCTURE，**这条路径不要求达到1%转折门槛**。随后计算器开始新柱色段、清空原普通状态及参照。

因此同一根可以有“旧方向结构形成事件”，但根末普通状态已经是NONE。事件和当前状态必须分别看。切到零柱不会通过换色路径确认结构，但也会清掉原普通状态；不能据此补造一个绿色消失事件。

### 3.3 底部钝化期间可以更换参照

当前底部DULL在同负段内，本根使整段最低DIF严格跌破原参照后，会在发出CANCEL之前尝试从现有两段池寻找更强且合格的旧参照。找到则更换参照，可能没有新事件；找不到才按原取消逻辑处理。已有STRUCTURE、等待状态或顶部不走这条救援换参照路径。

所以不能把r2概括为“同一轮所有方向都固定原参照”。研究中采用的固定规则尚未完整落地。

依据：[普通事件与换色](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:38)、[同段转折](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:71)、[底部救援](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:173)。

## 4. 历史结构和底部等待分别怎样处理

### 4.1 顶部历史

顶部形成STRUCTURE时，冻结截至形成根的原正段最高收盘、时间和原参照，建立PENDING历史。换色确认时使用刚结束的正段，不把新负柱价格算入原峰。

此后依次检查：原参照DIF突破、新TOP的DULL/STRUCTURE、形成后后续收盘严格超过冻结最高收盘。前两种只结束旧历史；第三种才额外输出`RESEARCH_HISTORICAL_WITHDRAWAL`。顶部这条价格撤销不要求先离开原正段。历史没有24根或26根自动到期。

### 4.2 底部历史

底部形成时同样冻结原负段截至形成根的最低收盘及原参照。换色确认用刚结束的负段，排除新红柱收盘。**历史最低价在创建时就冻结，之后原负段继续创新低也不会更新这份历史最低价。**

底部历史价格撤销要求先离开原负段：首次出现非负柱记录离开时间，之后最新收盘严格低于冻结低价才输出历史撤销事件。原参照DIF突破、同段STRUCTURE_DISAPPEARED或新的BOTTOM DULL/STRUCTURE，会优先结束历史，但不额外制造同一种绿色事件。顶部信号本身不作为底部后继信号。

### 4.3 底部结构消失后等待再次钝化

同负段内，底部STRUCTURE因DIF回转达到1%时，若最新收盘仍严格低于“原参照低价”和“最近完成负段低价”两者的较小值，段内DIF仍背离且根数足够，则直接回DULL。

不满足上述再次钝化的任一条件，则输出STRUCTURE_DISAPPEARED，普通状态为NONE，另外保存WAITING；不只价格失败，段内DIF等于原参照而未严格背离也可能进入此分支。若段内DIF已严格跌破原参照，则更早走CANCEL，不进入这个等待分支。等待保留原参照及最近旧价门槛；后续仍在原负段且最新价重新严格低于两价较小者、段内DIF仍严格背离、至少两根，才输出DULL/reactivation。不能仅凭过去累计最低价已突破就自动重出。

等待期间DIF严格跌破原参照只结束等待；换色或零柱也结束等待，不虚构新CANCEL。保存等待不等于当前已有钝化，历史结束也不等于每次都要画绿色字。

依据：[顶部历史](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:110)、[等待及再次激活](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:191)、[底部历史](../../src/biz/services/wealth/market/index_detail_xxm/calculator.py:234)。

## 5. 接口、页面与预测的当前关系

代码已有“路由→查询/来源读取→计算器→严格响应schema→Wealth图层”的链路。查询保存完整计算前段、逐根状态/事件和历史，显示窗口只是截取结果，不重新从窗口第一根建立状态。保存恢复校验规则、标的、周期和来源身份；当前的快照不包含新研究要求的完整局部DIF峰池。

日线读取既有指数因子表的收盘及未复权MACD列，分钟读取本地分钟价格/指标来源。当前业务日期按开市日20点切换，不能把该链路描述成盘中实时信号。具体接口、来源、业务日期、缓存和显示限制见配套说明第2—5节。

当前关键条件预测使用同一r2计算器的副本检验假设价格路径，不是另一套已完成的新算法；保留1%及旧参照政策。预测范围最多20根，包含条件触发价范围、结构条件和来源精度不确定情况。识别切换规则后，预测仍需相应设计与迁移，不能认为当前已支持两位DIF新方法。
