## 3. 参照选择：先B，后A

统一命名：

```text
较远A红段 → 绿段 → 较近B红段 → 绿段 → 当前C红段
```

底部是绿段、红段对称。A/B是当前段以前最近两个已结束的同色段，按发生先后确定，不按DIF大小重排。只有B时可检查B；没有B就不产生首次钝化。不能因为A/B不合格继续找第三个历史段。

1. 先检查C的累计最高收盘是否严格超过B的最高收盘；底部为累计最低收盘严格低于B。
2. 未突破B价格时只关注B，不检查A，也不能因A似乎合格跳过B的价格门槛。
3. 已突破B价格后，先检查B的完整价格/DIF资格；B合格即选B，停止搜索。
4. B不合格才检查A；A仍须满足自己的价格与DIF条件。只突破B，不代表已经突破A。
5. A也不合格则本次无新钝化；不选“DIF最强者”，不放宽等号，不增加更远候选。

顶部资格保持r2：当前段最高收盘严格高于参照最高收盘，当前段最高DIF严格低于参照最高DIF。底部保持镜像：当前段最低收盘严格更低，最低DIF严格更高。这里仍比较原值，不用两位截断。价格与DIF极值可不在同一天。

**取价窗口保持r2。**从当前逻辑色段首根到最新完成K线累计；历史参照使用对应完整色段极值，不改为DIF峰谷起至当天，不接入新价格候选。钝化日不必是价格极值日。

**首次资格已确认。**当前逻辑色段必须已有至少两根对应的真实红/绿柱；最新完成K线可以是同色柱，也可以是仍属于本段的零柱。零柱不增加有色根数，但当天价格/DIF满足既定条件时，允许当天首次钝化。首次顶部仍要求当根DIF大于0。历史A/B不新增至少两根限制。没有已知逻辑色段的开头零柱不能首次钝化。首次当天只产生DULL，不在同根追加STRUCTURE，后续仍按相邻DIF的1%或真实翻色检查结构。

**已有钝化先跟踪原参照，近参照失效时当根检查远参照。**不每根重新挑峰；进入本根前已DULL、仍在同一逻辑色段、原参照是B且累计DIF严格突破B时，取消前按相同价格/DIF资格检查A。A合格，当根换A并继续原钝化，不先清空状态，不另报消失或再次钝化；A缺失或不合格才按原规则取消。只允许B→A，不回切B、不查第三个。顶部在研究v2新增，底部已有处理保留；STRUCTURE、底部WAITING及真实反色仍按原流程，详见§15/LLD§5.3、§15。

## 4. 零柱：不分段，不充当反色

已确认：真实零柱不能隔开同方向的比较段；零柱不计入“两根有色柱”。已有钝化/结构在零柱当日仍正常检查DIF转折及原参照突破。2026-10-28进一步确认：有色柱数量及其余条件满足时，允许零柱当天首次钝化；底部等待期间，价格重新合格且原参照有效时，也允许零柱当天重新底部钝化。

| 输入或状态 | 本轮已确认处理 |
|---|---|
| 开头连续零柱 | 保留输入和前一根真实K线，不建立红/绿段，不产生首次钝化 |
| 红→零→红 | 同一逻辑红段；零日收盘/DIF参与该段极值统计，红柱根数不增加 |
| 红→零→绿 | 第一根真实绿柱完成时结束红段、保存历史红段；绿柱不加入旧红段 |
| 连续零柱 | 不制造额外历史段，不无限增加参照；每根仍按完成时间处理 |
| 已钝化，零日达到1%转折 | 当天形成结构，不等待下一根有色柱 |
| 已有结构，零日达到1%同向回转 | 进入原r2纠错分支；不得简单保持旧结构或重新报首次钝化 |
| 零日突破原参照DIF | 已DULL且仍在原逻辑段时，先按§15检查B→A当根切换；无合格A才取消。STRUCTURE/WAITING原突破处理不扩大 |
| 零日尚无活动钝化且无等待阻断 | 逻辑段已有至少两根对应有色柱，其余首次资格全部满足时，当天首次钝化；否则无新钝化。零柱既不新增根数，也不充当历史反色 |
| 底部等待遇零 | 先按原参照DIF突破规则判失效；仍在原绿段、晚于结构消失当天、有色根数足够且当根收盘重新严格低于保存的价格门槛、累计DIF仍合格时，当天重新底部钝化；条件不足继续等待 |

这两项是管理员为本轮r4试验选定的口径，替代原草稿的“零日不首次/不重新激活”，不冒称2015课程已逐项规定或真实历史已验证。LLD§5.5保留原人工数值及确定预期，后续须补其他正反案例；若新案例表明需要改规则，先同步本方案/LLD并review，不能边运行边改或把两种规则做成用户开关。

零柱日仍以当前段方向更新累计价格/DIF极值；首次判断仍使用累计极值。等待重新钝化沿用保存的原参照及最近旧谷价格门槛，判断当根收盘，不能因过去已有更低收盘就自动重新钝化。成功只产生原DULL事件（route=reactivation）及原关联，不当成新的activation，也不在同根追加结构。

相邻1%仍比较前一根**实际完成K线**，即使那根是零柱；不跳过零日，不改成寻找上一根有色柱。前值DIF为0的原保护保留。柱色只看源MACD柱值，不能把零改成极小正/负数骗过旧代码。

## 6. 开发和验收顺序

**此前已完成的共享安全检查（本次不再修改）。**单根行情使用同一份`XxmBar.validate`，r2和r4都在修改状态前调用。补齐数值不能是布尔值、完成标志必须为True及非法字段类型的明确拒绝；已有有限数值、正收盘、日线日期、分钟时区及时间升序唯一要求保留，不另造两份规则。正常int/float和合法行情的r2状态、事件、编号与参照须保持一致。具体字段/代码点/反例见LLD§3.2。

**此前已完成的内存进度副本检查（本次复用）。**现r2先解析检查、最后赋值；此前已补齐Wave、普通参照、顶部历史等检查，不重写判别算法。共通检查放在产品计算器同目录的`snapshot_validation.py`，由r2恢复流程调用，r4继承复用；字段、有效数字、正价格、整数计数、日期、身份、状态与参照关系统一要求。r2允许独立零段，r4只建红/绿逻辑段、允许段内零日，这些差别分别检查，不能把r4规则改进r2。正常副本的字段、编号和继续计算结果不变；缺原参照、NaN，以及底部已有结构却缺少或不匹配纠错所需原历史的副本，均须在替换进度前拒绝，不能补猜内容。

试验仅在内存，不保存行情、完整账本、恢复文件或浏览器缓存；失败丢弃本次结果，重试从头。指定一组输入最多1000根，完整验证/两组计算/比较20秒、进程256MiB、结果16MiB；人工测试单组60秒。这里是研究预算，不放宽现识别4秒、预测200ms或现页面预算。此前B1前及B1仅用人工输入，B2已完成有界只读接入，具体合同和成绩见§12—13；研究v2已按§15完成人工回归和独立代码审计，真实重放仍待后续指令。

**源码保护方式已改为工程审计。**r4不新增读取源码、计算或比对源码SHA、锁定源码正文或AST逐字相同的检查，不因共享安全修改改变文件指纹就阻止试验，也不为r4重新登记源码SHA。算法继续只处理调用方明确传入的行情，不隐藏读取旧标签/旧结果；结果、恢复文件仍不落盘。版本、规则、标的、周期和输入来源的内存身份检查继续保留，用于避免拿错计算进度，不用于证明源码未变，具体见LLD§3.1。

**报告须能说明“同样是钝化，为什么比较对象不同”。**每个日期分别列r2/r4的状态和事件、实际参照所属红绿柱区间及价格/DIF极值；记录近B与远A的实际检查顺序、各自价格/DIF条件、未检查或未选中的原因，以及沿用旧参照、本日首次选中或已有钝化当根B→A。相同标签但参照或判断依据不同，也必须计入差异；已钝化期间不得拿“本日重新算首次资格”冒充实际持续理由。当根切换须同时列切换前B、切换后A及原因，不篡改原钝化事件的日期和原参照。完整字段、编号关联和空值含义见LLD§6.2/§15。

**恢复验收须覆盖正常变化。**连续计算与复制后继续计算逐根一致；空状态、r2独立零段、r4开头全零及段内零、合法回退、换色后保留历史都应通过。历史结构保存的原参照可能已经离开最近两段池，不能一律要求它仍在池里；活动参照和等待参照按各自现有关系检查。错误副本须在发布状态前拒绝，随后同一对象仍能接受合法副本。恢复与最终验收的开销纳入本阶段既定预算，不另加保存或恢复任务。

## 7. 必须能抓住的反例

1. A和B都合格，A的DIF更强：r4必须选B。
2. 未突破B价格，A似乎合格：不得选择A；价格等于B也不算突破。
3. 突破B但B的DIF不合格，A自己价格/DIF合格：选A。
4. A价格未突破、A不存在或A也不合格：不继续找第三个。
5. 红→零→红不产生两个红段；红→零→绿→红才满足红段间真实反色。
6. 红→零→红只有两根红：计数2，零日不能冒充额外一根红柱；已有两根后零日才首次满足价格/DIF条件，必须当天首次钝化；只有一根有色柱、开头全零或价格/DIF等于门槛的反例仍不成立，底部镜像。
7. 已钝化遇零：保持、按1%形成、B失效而A合格当根切换、无合格A才取消分别验证；已有结构及等待各有独立样本，不扩大切换范围。
8. 顶底对称、连续/分批/恢复一致、逐日前缀不看未来、错误恢复不改变原对象。
9. r4研究报告须解释顶/底已有钝化的B→A当根切换，不漏记录或报为重新钝化；未来预测集成也须包含这条路径，不沿用“首次已经选最强”假设。
10. 底部等待遇零：当根收盘重新合格则当天重新钝化；价格等于门槛、DIF失效、同根新建等待、真实反色、连续零日不重复激活分别验证，保留原事件及历史/等待关联。

两个零日场景及本轮确定的预期见LLD§5.5，正反测试要求见LLD§7。人工演示只说明规则可以计算，仍需其他案例检验；以上为持续验收要求；研究v1实际成绩见§10—13，研究v2实现及人工验收见§15.5，真实对照未执行，不把旧成绩当新规则或算法可靠性证明。
