## 1 目标、范围与依据

### 1.1 初版要回答什么

对上证指数 `000001.SH` 的每根已完成周期柱，分别回答：

1. 当前柱段是否处于顶部／底部钝化或结构状态，本柱是否产生新事件？

### 2.2 数值与合并

MACD 来源参数为 12、26、9，柱值采用 `H = 2 × (D − A)`。算法消费已有数值，不在每个截图或回放窗口重新初始化 EMA。`C`、`D`、`H` 按保存精度计算，不先取整数、三位小数或按截图末端差值作固定偏移。

已保存文件合并只复用 §8.44 冻结的来源优先级：同周期同时间戳优先保留清单中在先的真实导出；已有推导只补缺少的时点。重叠收盘数值须相等，DIF／柱值绝对差须小于 `1e-8`。该容差仅用于这批保存文件的一致性检查，**不进入价格、DIF 或转向判定，也不表示软件误差界**。全部来源及其保留／重叠行数写入结果。

以下情况拒绝本次运行并报告具体原因，不静默忽略或自动修复：重复／乱序时间、非有限值、非正收盘价、对象或频度混杂、未完成柱、冻结文件哈希不符、重叠值超出上述口径，或缺少必需的来源说明。产品查询只纳入已完成柱，源中出现未完成柱时排除并说明实际计算末端；不能把未完成柱的预判画成已确认事件。原图或文字不够清晰则记“软件观察未确认”，不反过来修改数值输入。

### 2.3 历史起点与缺口

冻结回归沿用已保存序列起点；产品计算采用核查过的同来源连续历史起点，并记录来源身份。第一段可能已在起点前开始，必须在结果中保留“初始历史不完整”的说明；不凭若干根固定暖机长度宣称所有早期事件已充分初始化。候选允许只有一个已完成同向参照时比较，但这不能当作软件真实历史只有一个峰。图表请求范围只限制返回的显示窗口，不限制参照和历史记录的计算起点。

## 4 普通钝化与结构规则

### 4.1 记号、柱段与极值

`s = sign(H)`：正柱为 `+1`，负柱为 `−1`，精确零柱为 `0`。同一非零符号连续出现构成当前段，符号改变结束原段。一根异色柱也结束原段；零柱结束原段，但零段不加入正／负历史池。

对每个非零方向 `p`：顶部 `p=+1`，底部 `p=−1`。当前段及每个已完成段分别保存：

- 顶部取该段最高收盘价、最高 DIF；底部取最低收盘价、最低 DIF。
- 价格与 DIF 各自取极值，可以发生在不同柱；不强制同柱。
- 当前段极值只累计截至当根，不使用后面的完整段终点。
- 历史段保存起止时间、方向、柱数及极值；历史单根段参与计数。

以下称当前极值为 `Cw、Dw`，最近同向完成段的价格极值为 `Cn`，待比较历史段为 `Cr、Dr`。

### 4.2 历史参照的选择

仅在当前普通状态没有活动参照、当前非零段至少两根、且同向完成段存在时，尝试首次钝化：

1. 最近价格前置条件：`p × (Cw − Cn) > 0`。未突破最近同向段的收盘极值时，不回退到更早的峰强行钝化。
2. 先截取原始最近两个已完成同向段，再筛当次资格。不能先从全部历史筛合格段再取两段；一段不合本次资格仍占原始范围。
3. 每个候选同时满足 `p × (Cw − Cr) > 0` 与 `p × (Dw − Dr) < 0`。价格必须严格突破该参照，DIF 必须严格保留背离余量。
4. 从合格池选择 `p × Dr` 最大者：顶部选最高 DIF 峰，底部选最低 DIF 谷。DIF 并列时优先最近段，与当前稳定排序一致。
5. 存在合格参照则输出普通 `DULL`，原因 `activation`；状态进入 DULL，并锁定该段。

历史池不足两段时只使用已有段，不补造第二段。没有参照时保持 NONE，不以空字段生成事件。价格与 DIF 等于参照均不满足首次钝化。

不额外增加永久 DIF 淘汰或后段价格／DIF 双突破淘汰。它们在当前限定前提下与最强两段选择冗余，见研究 §8.36—§8.37；这一结论不用于扩大历史池或删除已锁定参照。

### 4.3 同色段内的状态转换

**当前实现说明：** 下表的底部 `STRUCTURE → DULL / dif_return` 已被 7/10 当日讲解证伪，保留用于审计旧代码；待审替代流程见 §12.3—§12.5。顶部现有分支没有因这份底部证据一并修订。

普通状态只有 `NONE、DULL、STRUCTURE`。在已有活动参照时先检查取消，再检查转向：

| 当前状态／条件 | 新事件与状态 | 规则 |
| --- | --- | --- |
| 有参照且 `p × (Dw − Dr) > 0` | `CANCEL`；状态 NONE，活动参照清空 | 严格 DIF 极值突破优先；等号不取消 |
| DULL 且经过滤反向 | `STRUCTURE`；状态 STRUCTURE | 顶部 DIF 下降，底部 DIF 上升；不重新要求本柱价格突破历史价 |
| STRUCTURE 且经过滤恢复原方向 | `DULL`；状态 DULL | 顶部 DIF 回升，底部 DIF 回落；原因 `dif_return`，沿用锁定参照 |
| 其他 | 无新事件，保持普通状态 | 不把无事件误写成状态 NONE |

转向比较定义为：`δ = p × (D[t] − D[t−1])`，`g = abs(D[t−1]) × dif_turn_pct / 100`。

- DULL → STRUCTURE：`δ < 0` 且 `−δ >= g`。
- STRUCTURE → DULL：`δ > 0` 且 `δ >= g`。
- 前根 DIF 为零时，不产生相对比例转向事件；不使用任意小分母替代。

这是单根、以前值绝对值为基数的候选。状态内累计比例和软件精度过滤仍未识别，不在 V0.1 主候选中自动替换。顶部／底部同色段均按这份表达计算，即使 DIF 自身符号与柱色不同也不新增过滤。

每根最多输出一个普通事件。CANCEL 当根不再激活其他参照；之后若新的当根资格成立，可以产生新的 activation，而不是静默换峰。同色段可反复出现 DULL／STRUCTURE，这些事件分别记录。

### 4.4 柱色切换：先检查旧方向，再清空当前普通状态

如果原段非零、当根直接变成相反非零符号，并且原段仍有活动参照：

1. 用**当根 DIF**检查是否严格突破旧参照；满足则输出旧方向的 `CANCEL`，原因 `dif_break_on_flip`。
2. 否则，原状态为 DULL 时输出旧方向 `STRUCTURE`，原因 `color_flip`。本候选暂不再要求相对转向达到 1%。
3. 原状态为 STRUCTURE 时不因变色自动再输出一次结构，也不以变色本身补造历史撤销。

完成上述检查后，归档旧段，建立新段，并清空当前普通状态与活动参照。**结构事件可以属于旧顶部方向，而本柱当前段已经负柱、普通状态为 NONE。** 例如 4 月 21 日 60 分钟，不能因为输出 state=NONE 就删掉同柱确认事件。

零柱仅结束旧段、清空普通状态，不沿用“直接相反颜色”确认路径。零柱后的非零段重新按首次钝化资格处理；历史顶部上下文是否保留是另一层，见 §5。零柱处理是明确的候选边界，现有分钟输入没有精确零柱，尚未取得软件验证。

## 5 顶部历史结构撤销的生命周期

### 5.1 与普通状态分离

每个对象／频度最多有一份**待跟踪的顶部历史记录**，同时保留全部已产生事件的只读账本。当前段 NONE 不表示该记录已经结束；记录结束也不删除旧的 STRUCTURE 事件。

记录至少包含对象、频度、版本、结构确认时间、确认路线、原 DIF 参照及身份、确认前正柱段的收盘峰及时间、创建时的来源和处理位置。跨柱追踪时另外记录经历的负柱、零柱、柱色切换次数及已过柱数，供诊断，不用这些计数新增到期条件。

### 5.2 创建与价格锚点

普通层输出顶部 STRUCTURE 后，在当根结束处理时建立记录：

- 若在正柱中确认，保存从本正柱段开始至确认当根的最高收盘价。
- 若直接转负柱当根确认，保存紧前完整正柱段的最高收盘价；不把确认负柱或后来新高加入原锚点。
- 原 DIF 目标取**这次结构事件引用的参照**，不是结构确认 DIF、后来的最近峰或全图最高峰。
- 当根新建记录不做自身撤销判断，从后续完整柱开始跟踪。

若存在旧待跟踪记录，先按下面的竞争次序结束旧记录，再为新顶部结构建立新记录。每次新结构都有自己的身份，不复用旧身份。

### 5.3 每根的固定执行次序

先计算普通事件，保留其原义；历史层再依次处理：

| 优先级 | 条件 | 对原待跟踪记录的处理 | 对事件账本的处理 |
| --- | --- | --- | --- |
| 1 | 当根 `D[t] > 原记录的 DIF 目标` | 结束旧比较窗口，原因 `original_reference_break` | 仅当普通层实际输出 CANCEL 才记录普通取消；历史目标突破截尾不另外补造 CANCEL 或价格撤销 |
| 2 | 当根普通事件为顶部 DULL 或顶部 STRUCTURE | 结束旧比较窗口，原因 `new_top_DULL`／`new_top_STRUCTURE` | 保留该普通事件；同柱不再判断旧记录的价格撤销 |
| 3 | 旧记录仍待跟踪、当根晚于其确认时间且 `C[t] > 保存价格峰` | 输出一次研究历史撤销，随后结束该记录 | 事件名 `RESEARCH_HISTORICAL_WITHDRAWAL`；明确关联旧结构，不冒充普通 CANCEL |
| 4 | 本柱普通层输出新的顶部 STRUCTURE | 为该事件创建新记录 | 与本柱旧记录的结束分别记录 |

旧目标严格突破与新顶部事件同时出现时，旧记录的主结束原因取优先级 1，但两项竞争事实都可记入诊断证据。普通层事件不丢失。价格等于保存峰不撤销。

普通底部事件不是这里定义的新顶部竞争事件，因此不直接清除顶部历史记录。若某柱同时有普通底部事件与顶部历史撤销候选，分别记录两层结果，不以“每柱只准一个事件”删除其中一层；每柱最多一个普通事件的约束只属于普通层。这一组合在已保存 1% 撤销点没有实例，仍须合成边界验收。

### 5.4 保留、结束与输入截尾

| 场景 | V0.1 暂定行为 |
| --- | --- |
| 当前普通状态 NONE、正负柱切换、经过零柱 | 历史记录继续待跟踪；不复活旧普通 DULL／STRUCTURE 状态 |
| 下一根出现更高价格，但同柱先出现新顶部 DULL | 旧记录按新事件结束，不再输出旧记录撤销 |
| 已输出研究历史撤销 | 该记录永久结束；后来满足条件不重复输出，不删除此前确认事件 |
| 新顶部结构确认 | 旧记录结束，新结构建立独立记录 |
| 数十根后仍没有定义的结束条件 | 继续保留，并显示年龄／经过段数；不擅自到期 |
| 输入结束时仍待跟踪 | 结果记“观察截至输入末端”，即右侧截尾；不是 EXPIRED、撤销或永久终态 |
| 下次追加同来源同版本的连续输入 | 恢复待跟踪记录和普通状态，继续处理；不能因上次报表写了 input_end 而丢掉记录 |
| 版本变化、来源无法连续或处理失败 | 本次结果不得冒充连续成功回放；保留已知处理位置及失败原因，不合并两版事件 |

原冻结报告把输入末端写作 `input_end` 的诊断观察边界。实现验收时应区分“本次报表的观察边界”与“算法记录真正结束”，否则追加数据会改变本应连续的行为。状态恢复不要求部署或引入数据库；可以从原起点重放，或使用包含普通状态、两方向历史段、历史顶部记录和输入位置／来源身份的完整状态。产品查询的窗口结束也只是观察边界，不让历史记录到期。

不加入“先进入负柱才可撤销”，也不加入 24 柱、固定天数或几次变色后的到期。没有精确负柱必要性的普适证据，也没有历史到期公式。**这使 V0.1 主候选可复现长保留行为，但不意味着软件确实这么做。**

### 5.5 长保留的验收边界

本方案暂保留已核查行为，必须在验收报告单列：

- 120 分钟：2025-11-14 15:00 结构到 2026-01-06 11:30 预测撤销，跨 69 根、三次柱色切换。
- 60／90 分钟：同轮旧记录分别跨 136／102 根，直到 2026-01-05 的新顶部钝化截尾。
- 60／90 分钟：8 月确认后仍保留到 10 月输入末端的记录只属于截尾，不算已撤销。

长保留输出统一标为“研究候选，历史寿命未验证”。不能为了让它看起来合理而新增到期，也不能将年龄长解释为软件结构仍有效或防守仍须持续。研究事件与作者实际采用、持仓恢复始终分开。

这些是算法必须产出的结果；离线验收报告保留完整证据，页面/API 消费其中有明确展示用途的部分。具体 DTO 另见接入设计，不修改既有 K 线或 DatasetDefinition 合同。

实际活动参照与事件参照必须分开：旧研究输出的 `ref_start` 在 CANCEL 等行可能保留诊断残值，不能因此宣称参照仍活动。新实现应按真实状态表达活动参照；与旧回放核对时比较语义，不能把该残值当作继续选峰依据。

事件身份至少由算法版本、Spec 哈希、对象、频度、事件类型、时间和被关联的结构锚点确定。三组门槛使用不同的冻结 Spec 身份，不能混入同一账本。同一输入重放结果幂等；不得因为后来变色或撤销而删除／移动旧事件。软件历史文字是否会保留、覆盖或回填，作为观察层的未确认问题，不用来悄悄修改候选账本。

价格＋DIF 仅是一份独立验收对照：同样先处理旧目标突破及新顶部事件，再检查价格与当根 DIF 同时符合。它不在主结果上作兜底，不按日期决定用哪个机制，不维护两套对外指标。

### 12.3 结构消失后保留什么

以 7/10 为例，流程应表达为：**底部结构消失 → 当前没有有效钝化，但原参照尚可用 → 后续价格重新满足条件，才再次钝化 → 再等待结构或钝化失效。** 结构消失不能自动等同于钝化消失，也不能自动等同于新钝化。

待审候选沿用既有1%相对转向计算，底部 STRUCTURE 的 DIF 向下反向达到候选门槛时，生成独立 `STRUCTURE_DISAPPEARED`，不再生成 DULL。若原参照已先被 DIF 严格突破，则先按原取消规则处理，不再保留待重入参照。消失门槛只是暂定值，见 §12.6。

无有效钝化时，普通状态仍为 NONE，活动参照为空；另存一份**等待重新钝化的参照记录**，不将 NONE 伪装为 DULL。记录保存原结构事件、原锁定参照的价格／DIF及时间、原最近价格前置门槛、当前负柱段起点、结构消失时间和结束原因。每周期最多一份正在等待的记录；已结束记录进入账本，恢复及过去时点查询必须保留因果性。具体字段见 LLD §15.3。

原负柱段继续累计其真实极值，不人为截成新柱段。保留参照的含义是“以后仍可比较”，并非“现在仍满足钝化”，更不表示可跨红柱无限沿用。

### 12.4 何时重新钝化、何时结束等待

设保存的底部参照价格为 `Cr`、DIF为 `Dr`，锁定时的最近同向段价格前置门槛为 `Cn`，当前完整负柱段最低DIF为 `Dw`。**结构消失之后的某根已完成柱**必须同时满足：

1. 仍属于记录的同一负柱段，且段柱数不少于原有两根要求；
2. 本根收盘 `C[t] < Cr`，且 `C[t] < Cn`，不是仅检查旧累计低点；
3. `Dw > Dr`，DIF 背离仍严格成立。旧参照一旦被严格突破，记录已结束，不能等DIF反弹后原样恢复。

三项满足才输出 DULL，原因 `reactivation`，恢复原锁定活动参照，并结束对应等待记录。该根不同时确认结构；后续结构确认沿用有效DULL及原转向／变色规则。等待期间未达到价格条件，可以继续等待，不输出新的钝化消失。

| 等待期间的情况 | 本轮候选处理 |
| --- | --- |
| 价格仍在重新激活门槛上方 | 保留等待记录，不输出DULL或CANCEL |
| 价格满足，但DIF恰好等于参照 | 不重新钝化；严格等号沿用原比较口径，软件精度待核 |
| DIF严格低于原参照 | 结束记录，原因为参照突破；当前本来没有钝化，不补造一次CANCEL；本根不重选参照 |
| 出现红柱或精确零柱 | 结束记录，分别登记柱色改变／零柱；后续回到首次钝化规则重新选参照，不跨段搬回3959 |
| 结构消失当根也满足价格 | 暂维持每根一个普通事件：只报结构消失，不同柱重入；该同柱次序仍待软件证据，不称已还原 |
| 重新钝化后又形成结构并再次消失 | 建立关联新结构的新记录；旧记录及原紫色结构保留，不改写旧账本 |

**实际例子：** 7/10收盘3996.1616，模型原锁定参照3959.338、最近价格门槛4027.265、原段最低收盘3952.4917。3996未达重新激活价，不能利用旧3952低点再报钝化。补图实际模拟下一交易日收**3959.16**，低于两个参照门槛，原EMA投影下DIF仍高于参照，软件确实新增黄色钝化；该新收盘无需再低于原最低收盘3952.4917。但模拟最低价也改为3946.16，不能据此唯一证明软件只比较收盘。收3960仍等待只是本模型候选反例，未取得软件邻价对照。讲解3959是简述、3959.16是已观察的正样本、3959.338是模型参照，三者分开记账，不强加整数阈值、严格等号或孤立点位展示。
