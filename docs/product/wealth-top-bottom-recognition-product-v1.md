## 1. 本次要完成什么

财势乾坤采用r4作为唯一正式顶底识别算法，**本轮先仅在本地开发环境支持**。本地普通页面显示钝化、结构、消失及关键高低点预判；辅助核验能力保留，但只在明确请求debug时加载和显示。生产环境暂不提供r4：日线也不显示识别标签、悬停状态、预判卡片或研究入口，不请求相关计算；生产分钟K线继续不支持。不保留r2作为生产回退。

产品化完成后，工作区不再保留r2算法、r2执行入口或可运行的r2比较副本；r2只作为设计、开发和验收文档中的历史记录存在。Git历史不重写，公共输入类型、严格安全检查和r4仍使用的工具不因原来服务过r2而删除。

实施必须先满足LLD§11.3的开工检查；设计完成不代表已开发或已上线，不提前清退仍有消费者的代码。

## 3. 产品范围

1. 标的仍仅上证指数`000001.SH`；算法周期仍为日线、60、90、120分钟，分别计算。
2. 本次不扩大到股票、其他指数或其他分钟周期。本地开发支持上述四周期，分钟继续遵循已有本地分钟配置和数据条件。生产暂不提供r4日线/分钟识别、预判或核验工具，即使带`debug=1`也不开启；正常生产日线K线、MACD、九转和趋势等不受影响。沿用本地分钟的环境区分方式，不能要求日线也必须有分钟Lake才能使用。
3. 实际信号只使用已完成K线、原始收盘价及来源DIF/DEA/MACD柱。不重算实际MACD，不用假设收盘替代真实信号。
4. 关键高低点预判必须采用修订后的r4，目标仅下一根本周期完成K线：先判断可能性，再反求边界；近处有钝化价格解就不计算远处。尚未首次反色结构继续预判考核变化，首次反色后，只在紧接着的下一段同色柱范围内预测旧结构因价格突破而消失；该段结束或旧结构已消失后停止预测。先前20根横盘假设、中点代表范围及全浮点价格遍历不再是目标方法。此前内核基线验收见LLD§16；本轮需按LLD§6.12补齐旧结构条件；完整请求、公开响应、页面和完整400ms预算留第3—5步，不用纯计算耗时代替。
5. 普通指数日线1000根加载能力保留，不因研究工具进入debug退回300根；其他页面和分钟数量不顺手修改。

## 4. r4规则登记

本节是唯一目标规则；详细顺序见技术方案§4、LLD§3，逐条识别测试设计见LLD§14。此前P3第1步只实现本次修改前的规则，本节有限跟踪及配套仍待实施和重新验收；公开显示尚未迁移；修改前单根预测内核验收见LLD§16。两位法不恢复，也不混入独立日线波段的另一种价格窗口。

| 判断步骤 | 固定规则 |
|---|---|
| 分红绿柱区间 | 以源柱值正负判断。真实反色才结束旧区间；零柱中性，不分段，不充当反色，不增加有色柱根数；归属已知区间时参与收盘和DIF极值 |
| 当根判断与历史记录 | 首次钝化的价格和DIF必须来自正在判断的同一根完成K线。色段累计价格/DIF极值及各自日期仍独立保存，用于色段结束后的历史参照，不能拿以前的价格代替当根价格 |
| 候选参照 | 仅最近两个已结束同色区间：近B、远A，按时间确定，不按DIF强弱排序。没有B就没有首次钝化 |
| 首次资格 | 当前区间至少两根真实有色柱；底部当根收盘低于参照谷最低收盘、当根DIF高于该谷DIF；顶部镜像。先过B的当根价格门槛，再查B本根完整资格；B本根不合格才查A自身完整资格，最多两个，A也须过B价格门槛。首次顶部继续要求当根DIF大于0 |
| 本轮DIF突破记忆 | 当前逻辑色段中，只要有任何一根DIF严格击穿某参照谷（顶部为严格超过参照峰），该参照本轮就不能再用。即使以后DIF回升且价格再次满足，也不能回用；本规则同样适用于首次钝化前就已发生突破的情况。B突破看A，A也突破则本轮无钝化可能 |
| 等号 | 首次价格突破和DIF背离仍严格比较；DIF等于旧极值不满足首次背离。已有钝化只有严格突破原参照才按突破规则处理，等于不因此消失 |
| 零柱日 | 根数已够且其余条件满足，可首次钝化；已有状态照常检查结构和消失。零不构成首次反色，也不自行终止状态 |
| 钝化保持 | 已钝化后，不再重复要求当根价格突破历史价；价格高于或低于前谷/前峰都可以。原参照DIF未严格突破且没有结构转折，就保持钝化，不每天重新选峰 |
| 当根B→A | 已钝化且仍在同一逻辑区间，DIF严格突破原B时，**同一根完成K线上、取消前**检查A。A必须未被本轮DIF突破，且本根价格/DIF完整合格；合格则换A、保持原钝化，不多报“消失→钝化”；失败才消失。不能回切B、找第三个或等下一天补做 |
| 结构形成 | 已处于有效钝化，按相邻两根实际完成K线DIF的1%反向转折确认；价格不用再次过首次门槛。达到1%含等号，前值0不走该转折途径，不跳过零柱。真实首次反色仍可独立确认结构。首次钝化当天只报钝化，不在同一根追加结构 |
| 尚未首次反色结构回转 | 先检查原参照DIF是否严格突破：突破则从结构直接消失，不必先回钝化。未突破时，相邻DIF同向回转达到1%就直接退回钝化，顶底相同，不重新检查价格，不进入底部等待；不足1%保持结构 |
| 首次反色 | 旧结构仍有效或当根按独立翻色规则形成结构时，记录首次反色时间和原结构色段的最终极值，保留原形成事实；进入后续有限跟踪。已消失结构不复活。反色不再代表永远不会消失 |
| 首次反色以后 | 原色段完整极值进入历史池。原结构只在下一段同色柱中继续判断价格突破；正常新一轮近B/远A判断同时运行，旧结构消失不能清空新一轮状态。精确起止和顶底镜像见§4.1 |

例：昨天顶钝化对比B；今天DIF突破B，但价格和DIF仍符合A。今天继续顶钝化、活动参照变成A，不增加标签。若A今天不合格，则今天显示消失；明天才合格，不能抹去今天的消失。

事实首次识别时，先检查B本根资格；B本根不合格才查A，不要求B已经永久失效。下一根预测另按“B有钝化价格解就停止、不算A”处理，两者不能混用。

当根连续切换仅限既有钝化；不得扩展到已有结构或真实翻色。首次选择仍按B后A完成，但不伪装成已有钝化的连续切换。底部结构反向达到1%直接退钝化，旧“按当根价格进入WAITING、以后价格重新合格再reactivation”的业务规则撤销，不能保留第二套运行策略。

阶段名称统一使用管理员定义：尚未钝化、具备可能性且存在价格解时是“钝化评估期”；已有钝化后是“结构评估期”，判断保持钝化、形成结构或钝化消失；结构已经形成而尚未真实反色时是“结构形成考核期”；第一次真实反色且结构仍有效的完成根记录首次反色事实；不再使用“结构锁死点”表示永久不失效。这些名称用于明确判断含义，不代表本轮新增页面标签或接口枚举。

例：旧谷价格100、DIF−20。已有底部结构DIF−10，下一根仍绿、收101、DIF−10.2，回转2%但未破−20，直接退底部钝化；若直接到−21，则结构直接消失。DIF曾到−21后再回−16，本轮不能重用该近谷。两个例子不能混为“只看当前DIF”。

### 4.1 原结构在下一段同色柱中的后续判断（已确认，待开发）

下文原段A、下一同色段B只表示前后顺序；判断时原段A是新段B的近峰/近谷，不能把这里的A误当候选集合中的远参照A。

顶部：原红柱段A形成结构，首次翻绿后不再按原色段1%规则考核A，保留A。只有下一段真实红柱B出现，A成为B左侧近峰时才判断A是否因价格突破而消失。B中当根收盘严格高于A完整红柱段的最高收盘，输出A结构消失；B第一根即可触发，不需要两根。B内零柱归B，仍可按收盘判断；分隔绿段及其零柱不触发A的这项价格判断。

底部完全镜像：原绿柱段A形成结构，首次翻红后，只有下一段真实绿柱B中，当根收盘严格低于A完整绿柱段最低收盘，原底部结构消失。第一根可触发，等号不触发。

A的最终价格及发生日直接取A结束时已有Wave极值，包含A内零柱，排除首次反色根；不误用形成当天收盘、形成时尚未完整的累计极值，或A当初对比的更早峰谷价格。形成时已返回的记录不回填为最终极值，二者在内部明确分开保存。

停止条件只有：A已消失，立即停止；或者B结束、首次出现下一根反色柱时正常停止。B的DIF拐头但仍同色不结束；零柱不结束。正常停止不输出结构消失；后续再出现同色段也不重新跟踪A，A后来作为远参照不复开原结构关系。此前已经消失的A不因价格回到门槛内侧而恢复。

新一轮独立判断仍照常：旧结构消失与新钝化可在同根各自出现，关联不同结构/事件；不能处理旧消失后直接return或清空新状态。新钝化至少两根及首次当根价格/DIF条件保持；已有钝化保持及原色段结构考核的1%规则保持。没有新增普通“停止跟踪”标签、开关或磁盘保存。

恢复进度也必须遵守“突破后不恢复”：下一同色段曾有收盘越过原段最终极值，即使末根已回到门槛内，也不能恢复一份仍在跟踪的旧结构。分隔反色段越过不触发，等号仍合法。debug不依赖当天有事件：窗口内仍有效的结构和当日正常结束的记录必须可查看；正常结束不增加消失标签，过期且与窗口无关的旧记录不附带。具体集合和翻色当天形成路线的完整测试见LLD§4.2.1、§14.16。

案例：4月21日旧顶结构所在红段最高收盘3393.3312，4月24日首次翻绿；5月8日下一红段第一根收3395.0036，旧结构消失而新钝化根数不足。5月9日第二根红柱收3357.6707未过3393.3312，不首次新钝化，旧结构也不恢复。底部采用同一时间范围和严格低于条件。

移除debug、切标的/周期、离开页面时，取消辅助请求、清空辅助结果、卸载辅助图层。迟到结果不得重新出现。正常行情、右栏和正式识别不沿研究的历史日期倒退。
