## 1. 本次要完成什么

财势乾坤采用r4作为唯一正式顶底识别算法，**本轮先仅在本地开发环境支持**。本地普通页面显示钝化、结构、消失及关键高低点预判；辅助核验能力保留，但只在明确请求debug时加载和显示。生产环境暂不提供r4：日线也不显示识别标签、悬停状态、预判卡片或研究入口，不请求相关计算；生产分钟K线继续不支持。不保留r2作为生产回退。

产品化完成后，工作区不再保留r2算法、r2执行入口或可运行的r2比较副本；r2只作为设计、开发和验收文档中的历史记录存在。Git历史不重写，公共输入类型、严格安全检查和r4仍使用的工具不因原来服务过r2而删除。

实施必须先满足LLD§11.3的开工检查；设计完成不代表已开发或已上线，不提前清退仍有消费者的代码。

## 2. 当前实现与本次目标

正式识别核心现已按§4实现首次当根取值、统一回转和结构锁死，并同步类型、内存恢复、完整内部模型及历史查询，验收见LLD§15。单根预测纯计算、整数边界、说明及固定Spec已完成，限定验收见LLD§16；公开API及页面尚未完成本次迁移。独立日线峰谷、平台、色段、价格候选、三角和说明能力已经存在，继续作为debug辅助工具，不强行接入识别判断。

本次必须同时修正识别逻辑和上下游配合，禁止只改版本或页面文字。“正式产品”表示版本与功能责任明确，不表示已经证明完全复现作者软件；现行1%仍是本产品已确认规则。

## 3. 产品范围

1. 标的仍仅上证指数`000001.SH`；算法周期仍为日线、60、90、120分钟，分别计算。
2. 本次不扩大到股票、其他指数或其他分钟周期。本地开发支持上述四周期，分钟继续遵循已有本地分钟配置和数据条件。生产暂不提供r4日线/分钟识别、预判或核验工具，即使带`debug=1`也不开启；正常生产日线K线、MACD、九转和趋势等不受影响。沿用本地分钟的环境区分方式，不能要求日线也必须有分钟Lake才能使用。
3. 实际信号只使用已完成K线、原始收盘价及来源DIF/DEA/MACD柱。不重算实际MACD，不用假设收盘替代真实信号。
4. 关键高低点预判必须采用修订后的r4，目标仅下一根本周期完成K线：先判断可能性，再反求边界；近处有钝化价格解就不计算远处。未锁死结构继续预判考核变化，锁死后不再预测撤销这个旧结构。先前20根横盘假设、中点代表范围及全浮点价格遍历不再是目标方法。本轮已按LLD§6完成单根预测内核及限定验收；完整请求、公开响应、页面和完整400ms预算留第3—5步，不用纯计算耗时代替。
5. 普通指数日线1000根加载能力保留，不因研究工具进入debug退回300根；其他页面和分钟数量不顺手修改。

## 4. r4规则登记

本节是唯一目标规则；详细顺序见技术方案§4、LLD§3，逐条识别测试设计见LLD§14。P3第1步已经实现本节识别规则并通过独立人工用例；公开显示尚未迁移；单根预测内核验收见LLD§16。两位法不恢复，也不混入独立日线波段的另一种价格窗口。

| 判断步骤 | 固定规则 |
|---|---|
| 分红绿柱区间 | 以源柱值正负判断。真实反色才结束旧区间；零柱中性，不分段，不充当反色，不增加有色柱根数；归属已知区间时参与收盘和DIF极值 |
| 当根判断与历史记录 | 首次钝化的价格和DIF必须来自正在判断的同一根完成K线。色段累计价格/DIF极值及各自日期仍独立保存，用于色段结束后的历史参照，不能拿以前的价格代替当根价格 |
| 候选参照 | 仅最近两个已结束同色区间：近B、远A，按时间确定，不按DIF强弱排序。没有B就没有首次钝化 |
| 首次资格 | 当前区间至少两根真实有色柱；底部当根收盘低于参照谷最低收盘、当根DIF高于该谷DIF；顶部镜像。先过B的当根价格门槛，再查B本根完整资格；B本根不合格才查A自身完整资格，最多两个，A也须过B价格门槛。首次顶部继续要求当根DIF大于0 |
| 本轮DIF突破记忆 | 当前逻辑色段中，只要有任何一根DIF严格击穿某参照谷（顶部为严格超过参照峰），该参照本轮就不能再用。即使以后DIF回升且价格再次满足，也不能回用；本规则同样适用于首次钝化前就已发生突破的情况。B突破看A，A也突破则本轮无钝化可能 |
| 等号 | 首次价格突破和DIF背离仍严格比较；DIF等于旧极值不满足首次背离。已有钝化只有严格突破原参照才按突破规则处理，等于不因此消失 |
| 零柱日 | 根数已够且其余条件满足，可首次钝化；已有状态照常检查结构和消失。零不锁死结构，也不自行终止状态 |
| 钝化保持 | 已钝化后，不再重复要求当根价格突破历史价；价格高于或低于前谷/前峰都可以。原参照DIF未严格突破且没有结构转折，就保持钝化，不每天重新选峰 |
| 当根B→A | 已钝化且仍在同一逻辑区间，DIF严格突破原B时，**同一根完成K线上、取消前**检查A。A必须未被本轮DIF突破，且本根价格/DIF完整合格；合格则换A、保持原钝化，不多报“消失→钝化”；失败才消失。不能回切B、找第三个或等下一天补做 |
| 结构形成 | 已处于有效钝化，按相邻两根实际完成K线DIF的1%反向转折确认；价格不用再次过首次门槛。达到1%含等号，前值0不走该转折途径，不跳过零柱。真实首次反色仍可独立确认结构。首次钝化当天只报钝化，不在同一根追加结构 |
| 未锁死结构回转 | 先检查原参照DIF是否严格突破：突破则从结构直接消失，不必先回钝化。未突破时，相邻DIF同向回转达到1%就直接退回钝化，顶底相同，不重新检查价格，不进入底部等待；不足1%保持结构 |
| 结构锁死 | 第一次真实反色的K线收盘时，旧结构仍有效，则当根是结构锁死点；首次反色当根才确认结构的，也可当根锁死。已消失的旧结构不能因后来反色而复活 |
| 锁死以后与新一轮参照 | 锁死后的旧结构不再因后来的价格、DIF或新信号追溯撤销。锁死根属于新色段，刚结束的旧色段以完整价格/DIF极值进入历史池；后续按新色段和近B/远A进入下一轮，不拿后来的99点撤销已经锁死的100点附近底部结构 |

例：昨天顶钝化对比B；今天DIF突破B，但价格和DIF仍符合A。今天继续顶钝化、活动参照变成A，不增加标签。若A今天不合格，则今天显示消失；明天才合格，不能抹去今天的消失。

事实首次识别时，先检查B本根资格；B本根不合格才查A，不要求B已经永久失效。下一根预测另按“B有钝化价格解就停止、不算A”处理，两者不能混用。

当根连续切换仅限既有钝化；不得扩展到已有结构或真实翻色。首次选择仍按B后A完成，但不伪装成已有钝化的连续切换。底部结构反向达到1%直接退钝化，旧“按当根价格进入WAITING、以后价格重新合格再reactivation”的业务规则撤销，不能保留第二套运行策略。

阶段名称统一使用管理员定义：尚未钝化、具备可能性且存在价格解时是“钝化评估期”；已有钝化后是“结构评估期”，判断保持钝化、形成结构或钝化消失；结构已经形成而尚未真实反色时是“结构形成考核期”；第一次真实反色且结构仍有效的完成根是“结构锁死点”。这些名称用于明确判断含义，不代表本轮新增页面标签或接口枚举。

例：旧谷价格100、DIF−20。已有底部结构DIF−10，下一根仍绿、收101、DIF−10.2，回转2%但未破−20，直接退底部钝化；若直接到−21，则结构直接消失。DIF曾到−21后再回−16，本轮不能重用该近谷。两个例子不能混为“只看当前DIF”。

## 5. 普通页面与debug页面

以下显示约定**仅适用于本地开发环境**；生产不加载本功能及辅助信息。唯一debug入口沿用指数详情页URL中的`debug=1`。没有该参数即关闭；开发环境也不自动开启。不新增页面调试入口、用户设置、持久化开关或第二套算法选择。进入debug后仍须手动点击“波段核对”，不会自动计算三年研究。

| 内容 | 普通页面 | `debug=1` |
|---|---|---|
| K线、MACD、DIF/DEA/柱值、MA/BOLL、九转、趋势等既有正常行情 | 保留 | 相同 |
| 钝化、结构、消失的文字和圆点，当前顶底状态、发生时间 | 显示正式r4结果 | 相同结果，不另跑一套算法 |
| 关键高低点预判、条件、适用/失效说明、截至时间 | 显示 | 相同，并可核验详细依据 |
| 识别加载中、来源延迟、无数据、失败和重试 | 正常显示，名称改为“顶底识别” | 相同；不能把真实故障藏进debug |
| 参照A/B、区间、编号、DIF/价格极值、结构考核及锁死依据、计算依据、来源核验信息 | 不加载辅助响应、不显示 | 随明确debug请求返回和显示；旧等待专属内容随业务清退，不继续产生新等待记录 |
| 日线“波段核对”按钮、三角、图例、待核对数量、说明列表、研究专用九转/趋势 | 不加载研究模块、不请求、不创建图层 | 加载工具；仍须手动开启“波段核对”才请求三年研究计算 |
| “九转标记未找到对应K线”等核对数量 | 指数详情普通模式不显示这种诊断数量 | 显示；真实指标错误仍按上一行故障原则正常显示 |

普通悬停内容已确认：当前顶底状态、当根事件和发生时间。比较峰谷的日期、价格、DIF、编号、结构考核和锁死依据只在debug查看；MACD本身的正常指标数值继续显示。普通悬停不再显示“徐小明V0.1·研究”“研究判断，历史寿命尚未验证”等研究文案。本地以“顶底识别·r4”描述正式功能；生产不显示该功能名称或占位卡片。本轮未改公开接口或页面；内存恢复和内部结果已按LLD§2—4迁移，公开合同及消费者继续依§11后续步骤实施。

debug只决定辅助资料的请求和呈现，不改变识别、预测的规则、事件编号或结果。完整识别需要的色段、DIF突破记忆和结构考核/锁死事实，后端仍须内部计算、校验；不能因普通响应不展示就省略。等待业务被取消不等于删除通用恢复安全检查。

移除debug、切标的/周期、离开页面时，取消辅助请求、清空辅助结果、卸载辅助图层。迟到结果不得重新出现。正常行情、右栏和正式识别不沿研究的历史日期倒退。

普通页面继续使用后端生成的最终display和必要适用/失效说明，精确范围、参照和数学依据仅debug；内部保持精确开闭，对外按合法范围取整数，没有合法整数不等于无解。除已明确的规则变化和单步预测外，不新增交易建议或独立工具入口。

## 8. 必须验收的结果

1. 顶/底、首次当根价格/DIF、本轮DIF突破记忆、先B后A、真实反色、零日、当根切换、1%、结构考核与锁死均符合§4；对照必须含参照和关联。LLD§14的RC01—69及RC70—72内部工程验证已实施，RC73的HTTP/前端验收仍待后续；不能只数标签，也不能继续要求与旧r4-v2全部输出相同。
2. 四周期人工序列、连续/复制/增量/历史位置以及正式接口均有测试。真实验收分别报告日线、各分钟来源的实际可用范围；缺证据不冒充通过，不为此扩大全局读取。
3. 关键点预判在零柱、切换参照和临界价格上与唯一r4一致；不沿用“DIF最强”“零柱结束”“顶部不会换参照”的旧假设。
