行业分类来自 `core_serving.sw_industry_classification`，当前成员来自 `core_serving.sw_industry_member`，固定过滤条件为 `classification_version='SW2021' and is_new=true`。

## 3. 关键口径

1. 一级行业用于景气总览，二级行业用于内部差异下钻，不展示三级行业。
2. 财务比较期、指标、配对样本、覆盖率门槛和景气分类方法与东财版完全一致。
3. 报告按当前 SW2021 分类与当前成员重述 `2025Q1~2026Q2` 财务历史。
4. 当前成员表不能证明各历史季度当时的行业成分，因此报告不得写成历史时点成分回测，也不得据此宣称消除了前视偏差。
5. 报告只读 Prod serving views，生成本地 JSON 与 HTML，不写生产数据库。

## 4. 实现与验收

生成时，共享生成器通过 `--taxonomy sw2021` 选择申万口径，东财默认口径保持不变。申万版使用独立输出文件，不覆盖东财版。

正式版验收结果：

- 31 个一级行业全部进入景气面板。
- 5,895 个当前成员通过唯一性校验。
- 131 个有当前成分的二级行业进入下钻分析。
- 产物包含 7 张图、8 张表，打包与结构验证通过。
- 报告正文、数据源说明和限制项不存在东财分类残留文案。
