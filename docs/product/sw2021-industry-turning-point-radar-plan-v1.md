## 3. 透明判别规则

基本面方向只使用四项证据：营收方向、利润方向、财务质量方向、改善广度方向。市场确认只使用20日和60日相对31行业等权基准的收益；相对收益在 `±0.5%` 内视为噪声，不参与确认。成交额变化和估值位置作为补充解释，不决定阶段。

| 阶段 | 判别口径 |
| --- | --- |
| 增长确认 | 至少三项基本面方向改善，当前营收和利润同比均为正，20日和60日相对收益均超过 `+0.5%` |
| 拐点候选 | 至少两项基本面方向改善，且20日或60日相对收益超过 `+0.5%` |
| 基本面改善待市场确认 | 至少两项基本面方向改善，但20日和60日相对收益均未超过 `+0.5%` |
| 市场抢跑待财务确认 | 20日和60日相对收益均超过 `+0.5%`，但基本面改善不足两项 |
| 高位钝化 | 当前营收利润仍为正，但至少两项基本面方向转弱 |
| 尚未见底 | 当前营收利润未同时为正，至少两项基本面方向转弱且短期市场未确认 |
| 方向分化 | 其他相互冲突的证据组合 |

每个候选必须同时展示直接证据、下一步需要确认的指标和结论失效条件。

## 4. 边界

1. 当前成员重述历史存在前视边界，不能冒充历史时点成分回测。
2. 六季度数据不足以训练稳定概率模型；必须补齐更长历史并按实际公告日做滚动回测后，才能输出命中率和平均领先时间。
3. 行情数据补齐前，报告必须醒目标注最新日期和滞后天数。
4. 生成时只读 Prod serving views，只写本地 JSON/HTML，未修改生产数据、API 或现有报表；归档后不保留生成器。
