日期：2026-09-12。当前状态：**蔚蓝锂芯30分钟前复权策略回测已完成，结果见第14.1节；不额外处理分红送股。** 第6节原始价/公司行为要求及第12—13节阻塞是原真实账户仿真方向的历史记录，不再作为本轮门槛。买20%/30%/50%、卖50%/30%/20%的股数规则不变。

## 1. 这次到底测什么

只看一只股票自己的K线：发现买点后分批买入，发现卖点后分批卖出，清仓后等待下一轮。连续记录五年数据范围内的现金、持股和账户净值，回答“按这套固定规则交易，这只股票的收益和风险是什么”。

不读取指数走势，不使用指数三买窗口，不按指数区间涨幅挑股票，不比较指数同步性。之前[指数窗口个股研究](stock-chan-index-window-research-plan-v1.md)暂停扩批，已有代码、报告和结论保留为历史；它的698个历史事件和区间涨幅不是本方案的五年交易成绩。

最初方案交付仅含文档；后续开发范围和验收以第12节为准。实现集中在`scripts/research/index_market/chan/`，测试在同主题`tests/`，证据放新建`reports/<run>/`，不接产品账户系统。

## 3. 买点、卖点怎样确定

### 3.1 固定识别实现，不再搜索“最好”的版本

建议先沿用已验证的第三方提交`429d6ed3043e27c93a003ba2b10e70a05575e1f5`和固定A配置，保留取消买入三买前置一买关联的设置。它是**缠论的一种明确程序化口径**，不能称为唯一标准缠论，也不能称为已经证明有效。

当前[类型映射](../../scripts/research/index_market/chan/event_ledger.py)为：`1→B1/S1`、`2→B2/S2`、`3a或3b→B3/S3`；`1p/2s`不单独触发交易。配置、源码和数据哈希保存到每次运行的manifest，不能为了多几个买点临时放宽。

逐根喂入该股票的已完成K线，只接受当时首次确认的买卖点。记录结构锚点和首次可知时间，但只能以首次可知时间生成订单，不能按后来图形把成交回填到早期低点/高点。后续结构修订只记入变更账本，不撤销历史已发生交易。

同一事件ID只处理一次；同一结构后来首次新增另一个有效类别，按新类别判断是否还有本轮份额。不同事件反复出现同一类别，也不能重复启用已经用过的份额。

### 3.2 五年与初始化期

首轮建议使用2021-09-09—2026-09-08全部可用历史，不再在2月/4月/8月的指数退出柱截断。前250个该股票实际交易日用于初始化，不下单，不读取五年之外的数据补足。

报告必须分列数据起止、初始化期、交易允许起止、第一笔成交和实际有效年数。五年账户净值可以从初始资金开始，初始化期持币；另列交易允许区间的收益/年化，不能把约四年的有效交易写成五年始终可交易。上市较晚或历史不足者单列，不把无可用历史当作“策略没有信号”。

新账户不得直接使用旧事件的`evaluation`字段：旧分钟实验按2022-01-01标记评价期，本方案必须按自己的初始化交易日门槛判断。

## 4. 股数规则：先固定分母，再谈20%和50%

### 4.1 买入基数Q

Q表示本轮计划最多买入多少股。一轮内冻结，不因价格变化、现金余量或下一买点出现而重算。

| 信号 | 新启用买入额度 | 假定Q=10000股 |
| --- | ---: | ---: |
| B1 | 0.20Q | 2000股 |
| B2 | 0.30Q | 3000股 |
| B3 | 0.50Q | 5000股 |

例如B1时10元、B2时11元，买的是2000股和3000股，不是两次分别拿账户资金的20%和30%去买。若直接先出现B3，只启用5000股，不补不存在的B1/B2。

**Q的确定办法尚未由用户指定，建议如下：** 每只股票设置独立初始资金100万元；新一轮第一个有效买点出现时，用该柱未复权收盘价和预设成本，计算现金能覆盖的最大1000股整数倍作为Q。估价只用当时已知数据；实际成交遇到跳空或现金不足时少买，绝不透支。清仓后下一轮可以根据当时现金重新定Q，这属于轮次之间复投，而不是轮内按金额配仓。1000股仅是让三份额度容易拆分的计算基数，不替代交易所最小申报规则。

金额在这里仅用于确定账户可承受的初始目标股数和检查现金；20/30/50始终乘Q。若用户希望每一轮都固定同一个绝对Q，可在运行前改为指定股数，但必须同时指定本金；两种方式不能混跑后挑成绩。当前草案推荐上述按轮冻结方式，未默认获得批准。

### 4.2 卖出基数V

建议在本轮第一个有效卖点出现、停止建仓时，取实际累计买入且尚未卖出的股数为V并冻结；未成交买单取消。此后不再买入，V不因减仓而缩小。

| 信号 | 新启用卖出额度 | V=10000股 | 若只买过B1、V=2000股 |
| --- | ---: | ---: | ---: |
| S1 | 0.50V | 5000股 | 1000股 |
| S2 | 0.30V | 3000股 | 600股 |
| S3 | 0.20V | 2000股 | 400股 |

这不是“每次卖剩余持仓的50%、30%、20%”，也不是永远用原计划Q卖。如果只买到2000股，不能因S1理论上对应目标Q的5000股就把2000股全部卖掉。

### 4.3 份额与成交分开

每轮维护已经启用的买入/卖出类别集合，以及累计应买/应卖股数、实际成交股数、未成交余额。份额按股数累计，不把每次剩余持仓当分母。

买入累计额度为Q乘已出现买点权重之和；卖出累计额度为V乘已出现卖点权重之和。每次可执行量是累计额度减已经执行量，再受可用现金、可卖股数、申报单位和成交模型限制。订单重试只是完成原份额，不会产生新份额；每次部分成交均单独记账。

股数按历史适用板块规则处理，不能全市场统一假定“100股一手”。额度不足合法申报数量时先保留，待其它类别释放额度后合并；只向下取可执行量，不为凑整超卖目标。三类卖点全部启用后，卖出剩余实际持仓，按合法零股规则清尾。送转、拆并股发生时，持仓、冻结基数和已执行/待执行数量同步换算；这是单位变化，不是重新按资金分配比例。

## 5. 一轮交易怎样开始和结束

建议采用简单的三个状态，避免边买边卖时分母反复变化：

`空仓 → 建仓/持有 → 减仓 → 空仓`

1. **空仓：** 忽略卖点；首次有效买点冻结Q并启用相应买入额度。至少一笔实际买入后才计入持仓轮次。
2. **建仓/持有：** 首次出现尚未用过的买点类别时启用对应份额。同类重复不加码；不要求一定按B1→B2→B3顺序出现。
3. **首次有效卖点：** 若有持仓，取消未成交买单、冻结V，进入只减仓阶段；没买满也可以开始卖。若买单一股尚未成交，同样取消买单并回空仓，不构造V，也不计一个已完成交易轮次。
4. **减仓：** 后续新类别卖点追加其固定份额；买点照常记录，但不执行。S3先来只启用20%，不会因“三卖”名称就清仓。
5. **清仓：** 等实际持仓归零且相关订单/未交收权利处理明确后结束一轮。下一根柱起，才允许由新的买点开启下一轮；不追溯使用之前忽略的信号。

同柱多个同向新类别按未使用份额相加，例如B1和B2同时首次出现时启用50%Q。同柱买卖冲突优先处理卖出，有持仓则进入减仓，空仓则本柱不买；记录所有原信号和忽略原因。不能根据下一段涨跌挑选类别。

缺少某类卖点，可能多年不能清仓，这也是结果，不能擅自增加时间止损或最后一天按卖点强平。期末未平仓按市值计入净值，未完成轮次单列；不能只展示已盈利结束的轮次。

## 6. 成交、价格和成本

### 6.1 严格时间顺序

信号在该柱完成后产生，最早在下一根真实可交易柱的开盘执行。柱时间戳与实际开盘时间必须区分；11:30完成的30分钟柱后，下一交易柱开盘是13:00，不能在11:30已结束的柱内成交。处理顺序是：开盘处理历史已知的待执行订单 → 收盘估值 → 用刚完成的柱更新结构及生成新意图。

买单在建仓状态保留未成交份额，到首个卖点或期末取消；卖单在减仓状态保留未成交份额，直到能够合法执行或期末仍未完成。T+1可卖数量按购入批次与交易日判断，不把同一天更晚的30分钟柱当作下一交易日。停牌时无成交；恢复后按真实价格处理，不填造停牌柱。

### 6.2 复权价识别结构，真实价格核算股数和现金

建议继续用经认证的Gold复权30分钟数据识别结构，但成交和账户估值使用同时间网格的未复权价格；现金分红、送转、拆并股及相关应收应付单独入账。不把复权后的价格乘真实股数直接称为实际资产，也不把复权因子变化全当成送股。

现有代码只证明过Gold与Silver5来源的抽样复权一致性，未实现五年公司行为账户。正式回测前必须核对未复权分钟映射、除权除息/登记/到账/新增股份可交易日期和股数转换事实；涉及配股等选择性事项还需明确参与规则。资料不足的股票或日期标为`data_blocked`，不默默删股后计算漂亮均值。单纯复权价格版本最多是模型诊断，不替代本方案账户收益。

### 6.3 成交限制和费用参数

拟采用保守的开盘成交模型：买入开盘已触及涨停不假定能买到，卖出开盘已触及跌停不假定能卖出；其它情形也只是成交假设，不代表有真实队列证据。每柱成交量拟不超过上一根已完成同频柱成交量的1%，只用当时已知成交量，不用当前柱后续放量来证明开盘可以成交。缺限价/身份事实则不能给出成交通过结论。

建议佣金假设为成交额万分之三、每笔最低5元；单边不利滑点5基点，另固定10基点敏感性诊断，不用结果选择滑点。佣金是假设，不冒充用户券商收费；过户、印花等按历史生效日期和适用范围登记费率表，须核验后冻结，不用今天的费率套五年。买入成交价格上调、卖出下调，价格步长及当日合法价格范围按规则校验；无法形成合法模型价格则不成交。

上交所2026版交易规则自2026-07-06施行，不能覆盖此前日期；深交所投教资料也明确区分主板/创业板的申报数量与零股卖出要求。执行前需补齐目标股票五年适用版本及板块差异，不把两条来源当完整历史规则验收。[上交所发布通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、[深交所主板交易机制说明](https://investor.szse.cn/institute/rules/t20230706_601604.html)。

毛/净结果从各自现金账独立重放：费用会改变后续可买股数及下一轮Q，不能只在最终毛收益中减一个费用百分比。即使所有检查通过，也只称“指定假设下的历史模拟净收益”。

## 7. 怎样算收益

每只股票一个独立账户，不在股票之间调配资金。主表至少列：

| 指标 | 算法或定义 |
| --- | --- |
| 每柱账户权益E | 可用及冻结现金 + 实际持股×未复权收盘价 + 应收权利价值 − 应付款；估值事实缺失须标识 |
| 累计收益率 | E期末 / 初始本金 − 1，无外部补款 |
| 年化收益率 | (E期末 / E起点)^(365.25 / 区间实际日数) − 1；明确是全范围还是交易允许期 |
| 最大回撤 | max(1 − E当时 / 截至当时的历史最高E)，包括空仓、浮亏和未平仓股票 |
| 年度收益 | 当年末E / 上年末E − 1；首尾不足整年标出，不把年度收益直接相加 |
| 完整轮次胜率 | 净盈利完整轮次 / 全部完整轮次；每次分批卖出不是一个独立轮次 |
| 盈亏比 | 完整盈利轮次平均净盈利 / 完整亏损轮次平均净亏损绝对值；无亏损时列无可估计值 |
| 持仓情况 | 实际持仓交易日占比、平均/最长持有时间、期末股数、未完成轮次及未成交原因 |

另列每笔成交、每类买卖点及完整轮次明细，不把某类卖点天然对应某次买入。部分卖出的已实现损益采用移动平均成本，并通过“期初权益+累计损益=期末权益”独立核对。

对照仅用**同一股票买入持有**：相同初始资金、共同交易允许起点的下一可成交时点、相同成本/公司行为/估值规则；之后不主动卖出，期末按市值估值。开始时间不能挑到策略第一次赚钱的买点。对照资金若因流动性限制分批成交，过程也记录。

比较时同时展示资金使用率，避免把不同仓位暴露造成的差异全归因于信号。没有交易的账户收益可能为零，交易胜率应为不适用，不伪造50%胜率。

## 8. 可手算的验收例子

下面是给股数与现金账做核对的合成例子，不是真实股票信号。给定Q=10000股、初始资金120000元，暂不计费用；Q的估算函数另设测试，不用此例证明选股或成交合理性。

| 信号 | 价格 | 买入/卖出股数 | 成交后持股 | 成交后现金 |
| --- | ---: | ---: | ---: | ---: |
| B1 | 10元 | 买2000 | 2000 | 100000元 |
| B2 | 11元 | 买3000 | 5000 | 67000元 |
| B3 | 12元 | 买5000 | 10000 | 7000元 |
| S1 | 13元 | 卖5000 | 5000 | 72000元 |
| S2 | 12元 | 卖3000 | 2000 | 108000元 |
| S3 | 11元 | 卖2000 | 0 | 130000元 |

总买入113000元，总卖出123000元，利润10000元；账户收益为10000/120000=**8.3333%**，不是把六次成交涨跌幅相加，也不是用卖出当时市值反推份额。

另设必须通过的例子：只出现B1买2000股后进入减仓，S1/S2/S3分别卖1000/600/400；S3先到先卖400；重复S1不再次启用50%；只有B3先到时只买50%Q；卖点没有凑齐时保留期末余额；买卖同柱、买入当天不可卖、现金不足、部分成交、零股及送转各有独立字面预期值。

## 9. 如何验证不是程序制造的成绩

1. **信号因果性：** 完整回放与固定年度截止点前缀一致；仅扰动未来数据不改变此前信号。沿用原本完整、截断、未来扰动、统一缩放和短初始化五类检查，截止不再来自指数窗口。统一缩放只要求结构信号不变，不要求含最低佣金、实际股数取整的现金账户数值不变。
2. **账户因果性：** 截止某日的订单、成交、股数和权益，应与长序列在该日前的结果完全一致；现金和Q不能读取未来价格。公司行为权益及可用时点也受该限制。
3. **份额守恒：** 未发生公司行为时，累计买入≤Q、累计卖出≤V；未启用类别不贡献份额。按已确认股数口径及累计取整规则做正反例，不能仅检查最终清仓。
4. **现金/持股守恒：** 每笔成交前后现金、费用、数量独立核算；不得负现金、负库存、超可卖数量或重复成交。公司行为变更必须有对应来源。
5. **初始化稳定性：** 缩短历史后仅在两者都有足够前置历史的共同交易区间比较首次事件；空集合一致不当作强证据。有差异先报告，不调参消除，也不能把不同起始资金状态的两个账户直接称为稳定。
6. **串并行等价：** 同一股票单进程和4进程调度的完整输出相等。历史首批125.5→39.8秒只说明旧信号路径提速，不证明新账户已经正确或同样快。
7. **结果解释：** 展示全部选定股票、年度、完整与未完成轮次及失败记录，不按未来盈利删样本。必要的收益区间估计按连续交易日区块处理相关性，不把每个30分钟信号当独立试验。先报告描述性结果；不设置一个通用“年化超过X就有效”的门槛。
