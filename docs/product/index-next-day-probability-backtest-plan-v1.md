## 1. 本轮要回答什么

目录整理说明（2026-09-09）：本研究代码和测试已集中到[统一研究入口](/Users/congming/github/goldenshare/scripts/research/index_market/README.md)，历史结果目录不变。本文中的文件链接更新为当前位置；历史结果中的运行命令、参数与哈希保留原样。目录迁移不是新一轮实验，算法与既有结论不变。

每天收盘数据齐备后，预测下一交易日指数收盘价是否上涨。先按时间把历史分为前70%训练、后30%测试；固定参数，不在测试期重新训练或挑选最佳版本。

对象：上证指数 `000001.SH`、沪深300 `000300.SH`、中证500 `000905.SH`，分别训练、分别报告，不合并为独立样本。

目标 `y_t = 1[close_(t+1) / close_t - 1 > 0]`，平盘归入未上涨。只做预测回测，不计算交易收益、仓位或买卖建议。状态识别不等于预测；本轮先用可直接核验的逻辑回归，不引入 HMM 或大模型。

## 3. 冻结的特征和模型

所有滚动窗口只看当日及之前数据。各指数独立标准化，只用训练集均值和总体标准差；零方差列除数设为1。

| 特征 | 精确定义 |
| --- | --- |
| r1、r5、r20 | `close_t / close_(t-k) - 1`，k=1、5、20 |
| sigma20 | 含当天的最近20个 r1 的样本标准差，ddof=1 |
| a20 | `ln(amount_t / median(amount_(t-20)...amount_(t-1)))`，分母不含当天 |
| v20 | 同上，将 amount 替换为 vol |
| 方向与量额交互 | r5*a20、r5*v20，先按上述原始特征相乘，再统一训练集标准化 |

| 版本 | 输入及作用 |
| --- | --- |
| frequency | 恒定预测训练集上涨占比；主要对照 |
| price | r1、r5、r20、sigma20 |
| price_amount | price + a20 + r5*a20；成交额诊断版本，不从中挑赢家 |
| price_amount_volume | price_amount + v20 + r5*v20；预先指定的主要候选 |

逻辑回归 `p=1/(1+exp(-(b+w*x)))`，最小化平均二元交叉熵 + `0.01/2 * sum(w²)`，截距不惩罚。用 NumPy 实现牛顿法及回溯线搜索，最多100步，梯度无穷范数阈值1e-8；未收敛则停止，不能悄悄继续。不调参、不做重采样平衡、不做额外概率校准或概率截断择日。每日全覆盖；概率>=0.5判上涨。

这些参数是预注册的简单起点，不是已证实最优。只允许在看测试成绩前修复实现缺陷；看成绩后不能改变实验设计再冒充首次测试。

## 4. 怎样判断有效

- 主指标：Brier = mean((p-y)²)，越低越好。
- 辅助：log loss、ROC AUC、0.5阈值方向准确率、训练多数类恒定预测准确率、测试实际上涨比例、平均预测概率、固定10个概率区间的可靠性表、按年份拆分。
- 主要比较：主要候选对 frequency、主要候选对 price；三个指数共6个预注册比较。改善定义为“对照Brier−候选Brier”，正数更好。
- 每个比较按同一测试日做配对移动块 bootstrap：块长20个交易日，重复5000次，种子20260908；尾部截断拼接到测试样本长度。报告普通95%区间，以及 Bonferroni 同时比较所用99.1667%区间（整体alpha=0.05、6项比较）。块法只缓解时间相关，不证明平稳，也不覆盖参数估计的全部不确定性。
- 若主要候选同时显著优于两个对照（校正区间下界>0），才称该指数上“本次留出期支持价格量额模型存在增益”。校准与年度表现另行检查，不靠几次极端行情下结论。没有显著改善则写“未证明有效”，不得把运行成功当成方法有效。
- 三个指数高度相关，不把三份成绩当成三次完全独立验证。测试期看过后即成为已知样本，后续改方法必须另做未见数据或前瞻验证。

## 8. 第二轮计划：先拆开看量价条件，不更换预测模型

### 8.1 首轮结论与本轮目的

首轮只说明这套固定逻辑回归尚未证明有次日方向预测增益，不等于所有量价信息无用；状态描述、方向预测和波动风险也不能混为一谈。

本轮先问：同样是近期上涨或下跌、同样处于高或低波动环境，高成交活跃度与低成交活跃度的次日表现是否不同？这种差异能否跨时间保持？主问题仍是次日上涨，次日绝对涨跌幅是预先指定的辅助问题，不能用风险结果冒充方向结果。

### 8.2 数据隔离与时间分段（运行前固定）

- 仍只读三个指数同一份DG日线，不改首轮脚本、参数、源数据或首轮结果。沿用三条精确批准的前收盘警告及其他阻断检查。
- 只读取2010-01-04—2021-09-07，后者只用于原训练末日的标签。原训练信号2010-02-01—2021-09-06共2820日；不读取2021-09-08及之后的行情或首轮测试预测CSV。
- 按相同信号日期顺序分为三段，每段名义940日：D发现段、V1内部验证段、V2内部验证段。D、V1各去掉标签跨入下一段的末日，实际939、939、940日。预热和标签边界分别对账。
- 各指数的所有分位数阈值只用D段939日计算，之后固定，不在V1/V2重算，不搜索更好的周期或分位数。
- 这是原训练期内的探索及时间稳定性检查，不是全新的独立最终测试。三个指数高度相关，不合并为独立样本；已经看过的首轮测试期，本轮不重复使用。

### 8.3 分组和统计口径

- 走势使用首轮 `r5`：>0为近5日上涨，<0为近5日下跌，=0单列覆盖统计，不硬归入下跌。
- 主分组量额变量为 `a20=ln(当日成交额/此前20日成交额中位数)`。D段1/3分位数以下（含边界）为低活跃度，2/3分位数以上（含边界）为高活跃度，中间为普通活跃度。若上下阈值重合则停止，不任意分组。
- 分位数高/低是相对于历史活跃度分布，不必然等于金额比率>1/<1；报告同时给出阈值的金额倍数，避免把“相对高活跃度”误说成一定放量。
- 波动使用首轮 `sigma20`，以D段中位数为界，<=为低波动，>为高波动。三指数独立阈值。
- 得到“涨/跌 × 高/低成交活跃度 × 高/低波动”8个主组。普通活跃度及r5=0的行不进入8组，但必须保留行数、覆盖率与全部日期基线，不能静默删掉。
- `v20`成交量采用同样方法、单独固定D段阈值，输出相同8组作为诊断；不能在看成绩后从成交额和成交量中挑显著赢家。主要筛选只针对成交额。
- 每组列：样本数、覆盖率、次日上涨率、平均次日收益、平均绝对涨跌幅、平均下行损失 `mean(max(-r,0))`、下跌日数量与下跌日平均跌幅。后者仅对r<0的子样本，不能混用分母。
- 各阶段所有日期另列高/低当前波动的次日绝对涨跌幅，作为“波动自身持续性”的描述对照，不把它算成成交额的贡献。

### 8.4 不确定性、比较和筛选（运行前固定）

- 不只对组内日期独立抽样。对每指数每阶段完整日期序列按20交易日移动块重采样，然后按原组标签重算；10000次，种子20260908，固定阈值不在bootstrap内重估。
- 所有8组的上涨率、平均收益、平均绝对涨跌幅、平均下行损失给出描述性95%区间；这些组区间不经多重校正，不可用于逐格挑显著结果。
- 主比较是同指数、同走势、同波动内，“高成交活跃度−低成交活跃度”的差值。主结果上涨率、辅助结果平均绝对涨跌幅分别报告，3指数×4层=12个比较，分三阶段看差值方向和区间。
- 用中心化移动块bootstrap近似双侧p值：`(1 + count(abs(delta_boot-delta_observed)>=abs(delta_observed)))/(1+有效抽样次数)`。它不是精确检验；重采样中某一组缺失的次数必须记录，有效抽样不足99%时不作筛选。
- V1、V2两阶段 × 12比较 × 2结果，共48个预先指定的检验一起做Holm校正；缺样本或无法计算的检验保留在比较族中，按p=1处理，不能缩小比较族获取显著。
- “可继续研究的跨段候选”仅当：三个阶段高低组各至少50个样本，差值方向在D/V1/V2一致，且两个验证段各自Holm校正p<=0.05。方向和幅度候选分开，不称为已可交易或已验证的概率。
- 0个候选也如实交付。不能事后增加分组、改变阈值或删极端日。未通过门槛不等于效应为零。
- 这些仍是分层关联。组内具体波动水平、趋势幅度、市场制度等可能不同；没有严格证明量额的独立或因果贡献。即使发现幅度差异，也还不是一套经过评分检验的风险预测模型。

### 10.1 两个问题分别计算

方向主问题：r5>0为上涨组，r5<0为下跌组，比较次日上涨率差（上涨组−下跌组）。r5=0的日期单列；预测仍全覆盖，平盘使用D全段基线。次日平盘y=0。只用D段各组实际上涨比例作为后续固定预测概率，不平滑、不重训。基线是D全段上涨比例。

风险辅助问题：sigma20≤D段中位数为低波动组，>为高波动组；比较次日绝对收益均值差（高−低）。只用D段各组的次日绝对收益均值预测后续波幅；基线是D全段次日绝对收益均值。波幅为收盘到次日收盘绝对收益，不是日内振幅、VaR或下跌概率。

后两段的每一天，方向损失是`(p-y)^2`（Brier），风险损失是`(预测绝对收益-实际绝对收益)^2`（MSE）。改善均为基线损失减分组损失，正数更好。报告原始误差、相对改善率、方向准确率和各组实际表现。不能用“组均值不同”代替预测误差改善。

## 12. 第四轮冻结方案：挑战20日动态风险基线

2026-09-08用户批准继续§11.4。本节先于第四轮运行落盘，不改变第三轮模型，不追加周期搜索、分组或方向预测。

### 12.1 比较对象及时间

- 目标仍为下一交易日收盘到收盘的绝对收益`a_(t+1)=abs(close_(t+1)/close_t-1)`，不是日内振幅或上涨概率。
- 固定分组模型：直接使用第三轮D拟合值与sigma20中位数阈值，预测保持不变；D段重算仅作一致性核验，不能借此修改拟合值。
- 动态基线：`abs20_t = mean(abs(r1_(t-19)), ..., abs(r1_t))`，其中`r1_t=close_t/close_(t-1)-1`。包含当天已知收益，不含任何次日收益；必须有20个非空日收益，不能用不足20日的均值。
- 旧D常数均值保留作描述对照，不另择赢家。三种预测使用完全相同日期，D只作描述，正式比较仅V1/V2。
- 沿用三指数2010-01-04—2021-09-07源范围、原D/V1/V2切分及边界剔除。动态窗口在完整行情序列上计算后再切分，不能先剔除边界日再滚动；过去阶段行情可以进入后续窗口，不是未来泄漏。不读取原测试期。

### 12.2 统计与判定

主指标仍MSE，差值为`动态基线MSE−固定分组MSE`，正数代表固定分组更好。报告三种方法MSE和MAE，MAE仅辅助，不按其成绩改主指标；相对改善率为`1−固定分组MSE/动态MSE`。不涉及收益、交易成本或操作建议。

六项正式比较（3指数×V1/V2）共同Holm校正，alpha=.05；按每段完整日期作同日配对20日非循环移动块bootstrap，10000次、100次一批、种子20260908加指数/阶段固定偏移，沿用近似双侧中心化p。每段至少50日，95%区间用于描述。只对已知逐日损失差重采样，不把打乱后的价格拼接成新路径重新滚动。

每指数只有两验证段差值都为正且校正p均≤.05，才记“固定模型胜过动态基线”；若均为负且均通过，则记“动态基线更优”；其余记“未证明跨段优势”。即使胜出，也仅为反复使用旧训练期的内部比较，本轮校正不消除跨轮选择偏差，不能升级为独立预测能力证明。

### 13.1 结论：固定分组模型未通过动态基线挑战

三个指数均没有证明固定模型胜过20日动态基线；也没有证明动态基线在两个时段都有显著优势。不能把“固定模型未赢”写成“动态模型已经有效”。

### 13.2 这一轮改变了什么判断

第三轮风险正结果需要继续限缩：固定分组比“每天同一个旧历史均值”好，并不意味着它比简单的近期动态统计更好。数据说明二者的相对表现随时段变化，没有稳定赢家；当前不足以支持为这个固定分组模型增加产品复杂度。
